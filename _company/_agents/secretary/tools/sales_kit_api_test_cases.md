# B2B Sales Kit - PoC 필수 API 테스트 시나리오
## 🎯 목적: 학원 운영자에게 '객관적 데이터'로 가치를 증명하는 최소 기능 정의

### 1. 진단 테스트 시나리오 (Diagnosis Test)
- **Test Case ID:** TC-001
- **시나리오:** 사용자 A가 '노래를 못한다'는 주관적 문제 제기 $ightarrow$ AI 진단 리포트 출력.
- **검증 지표 (KPI):** 낮은 감정 표현 점수(Emotional Range Score)와 특정 음역대 기술 부족률을 수치화하여 보여준다. (Pain Point 충격 증명)

### 2. 개선 추적 시나리오 (Progress Tracking)
- **Test Case ID:** TC-002
- **시나리오:** 동일 사용자 A가 '개선 과제'를 수행한 후 재진단 $ightarrow$ 점수 변화 그래프와 함께 개선된 영역을 시각화하여 보여준다.
- **검증 지표 (KPI):** 시간 경과에 따른 성능 지표(예: 음역대 커버 범위, 정확도)의 명확한 증가 추이를 그래프로 제공한다. (ROI 증명)

### 3. 리포트 자동 생성 시나리오 (Report Generation)
- **Test Case ID:** TC-003
- **시나리오:** 운영자가 특정 기간의 종합 데이터를 요청 $ightarrow$ 분석 결과와 함께 '다음 액션 플랜'을 요약한 리포트가 자동 생성된다.

# ⚙️ 핵심 시스템 Mockup API 명세서

## 📝 목표: 실제 백엔드 개발 전, 데이터 스키마 및 흐름 검증 (P0)
*   **목적:** 외부 의존성(실제 DB 연결, 복잡한 로직 계산 등) 문제에 관계없이, 프론트/디자인팀이 기반 작업을 할 수 있도록 Mockup 엔드포인트를 먼저 정의하고 구현한다.

## 🛠️ 핵심 API Endpoints (3가지 재확인)
1.  **`diagnosis_score`**: 사용자의 성능 데이터를 받아 진단 점수와 주요 Pain Point를 반환.
    *   Mockup 로직: 랜덤 데이터 또는 미리 정의된 '최악의 케이스' 시뮬레이션 값 반환으로 대체.
2.  **`user/progress/{userId}`**: 사용자별 누적 학습 및 감정 변화 추이 데이터를 조회.
    *   Mockup 로직: 가상의 시간대별 점수 변동 트렌드(좌절 $\rightarrow$ 상승 곡선)를 JSON 배열로 반환.
3.  **`report/{reportId}`**: 진단 결과를 종합한 최종 리포트를 생성하여 보여줌.
    *   Mockup 로직: `diagnosis_score`와 `user/progress`의 데이터를 결합한 구조화된 '서사적' 텍스트 요약본을 반환한다.

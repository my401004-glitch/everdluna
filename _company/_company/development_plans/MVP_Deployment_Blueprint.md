| 단계 | 목표 및 산출물 | 책임 에이전트 | 핵심 작업 내용 | 완료 기준 |
| :--- | :--- | :--- | :--- | :--- |
| **[Week N-1] 📐 설계 확정** | API 계약서, UX Mockup, 플로우 정의 완성 | 코다리, Designer, Writer/현빈 | (현재 단계) 기술적 가능성과 사용자 경험을 통합하는 최종 문서화. | 모든 에이전트가 산출물을 제출하고 상호 검토 완료. |

| **[Week N+1] 🧩 통합 및 검증** | 전체 유저 플로우에 맞춰 시스템 연동 테스트 (E2E) | 전원 협업 | 프론트엔드(Designer Mockup) $\rightarrow$ API 게이트웨이 $\rightarrow$ 백엔드/AI 로직 순으로 데이터를 주고받는 과정 전체를 시뮬레이션. | 실제 사용자처럼 처음부터 끝까지 오류 없이 흐름이 작동하는지 검증 완료. |

### 📋 에이전트별 상세 액션 아이템 (Task Allocation)

#### 🧑‍💻 코다리 (개발/기술)
1.  **최우선 작업:** 핵심 API End-Point의 **상세 계약 명세서(JSON Schema)**를 완성하고, 테스트 환경에 반영 가능한 Mock API Endpoint로 구현한다.
    *   *필수 포함:* `diagnosis_score` 요청 및 응답 JSON 구조, 데이터 타입 정의 (예: Float형 점수 범위).

#### 🎨 Designer (UX/시각화)
1.  **최우선 작업:** 코다리님이 확정한 API 스키마를 기반으로 **'진단 리포트 페이지'의 High-Fidelity Mockup**을 완성한다.
    *   *필수 포함:* 데이터가 들어갈 자리(Placeholder)에 맞춰 정확한 크기와 위치, 그리고 'Dark Blue/Accent Yellow' 테마 적용 가이드라인 명시.

#### ✍️ Writer / 현빈 (콘텐츠/전략)
1.  **최우선 작업:** **End-to-End 사용자 플로우 스토리보드(Flow Storyboard)**를 작성한다.
    *   *필수 포함:* '사용자 행동 $\rightarrow$ 시스템 반응(화면 변화) $\rightarrow$ 코치 메시지(문구)'의 3단계를 명확히 분리하여, 각 단계별로 필요한 콘텐츠와 CTA가 무엇인지 정의한다.

# 🚀 통합 데모 플레이북 v2.0 설계서 초안 (Next Step)
## 🎯 목표: 학원 운영자에게 ROI를 증명하는 완결된 경험 제공

### I. Playbook 구조 및 스토리라인 (현빈 주도)
1. **Pain Point 인식 (충격):** 현재 시스템의 객관적 데이터 오류 제시 (예: '학생 A의 실질적인 시간 대비 학습 효율 지표가 30% 낮음').
2. **AI 진단 & 원인 분석 (해결책 제시):** 문제가 발생한 근본적 원인(데이터, 습관, 코칭 방식)을 AI가 정량적으로 진단하여 보여줌.
3. **ROI 기반 비전 제시 (구매 결정 유도):** 이 문제를 해결했을 때 학원 운영자가 얻게 될 구체적인 재무적 수치와 시간 절감 효과를 예측하여 제시.

### II. 기술 로직 매핑 및 데이터 흐름 (코다리 주도)
*   **Phase 1: 진단:** [API Call Placeholder] $\rightarrow$ 입력 데이터: 학생의 학습 기록(성능 지표). 출력 데이터: `diagnosis_score` (Pain Point 수치).
*   **Phase 2: 원인 분석:** [API Call Placeholder] $\rightarrow$ 입력 데이터: 코칭 로그, 감정 상태 변화. 출력 데이터: '취약점' 리포트 및 개선 과제 목록.
*   **Phase 3: ROI 예측:** [API Call Placeholder] $\rightarrow$ 입력 데이터: Pain Point 수치 + 학원 운영 비용 변수. 출력 데이터: `predicted_roi` (재무적 증명).

### III. 시각 자료 및 액션 아이템 (Designer 주도)
*   **필요 에셋 1:** 진단 리포트 레이아웃 (`#FF9800` Pain Point 강조 영역 확정).
*   **필요 에셋 2:** ROI 그래프 (성장 곡선 형태의 시각화 필수).
*   **핵심 액션:** 세 가지 단계에 맞는 발표 자료(PPT 또는 대시보드) 목업 제작.

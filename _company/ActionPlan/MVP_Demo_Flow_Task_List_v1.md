# 🎯 MVP 데모 플로우 통합 구축 작업 목록 (2026-05-28)

## 📋 목표
잠재 고객(학원 운영자)이 처음 접하는 순간부터 구매 의사를 갖도록 유도하는, 인터랙티브 시뮬레이션 프로토타입 완성.

## ✅ 핵심 액션 항목 및 책임 소재 (Ownership)
1.  **[코다리] 기술 스켈레톤 구축:**
    *   `Diagnosis Input Page` $\rightarrow$ `Loading Screen (API Call Mock)` $\rightarrow$ `Result Report Display Page`의 3단계 모듈 연결.
    *   핵심 데이터(성능 지표, 감정 상태)를 시뮬레이션하여 리포트가 출력되도록 프론트엔드-백엔드 간의 가상 흐름을 구현합니다. (Mock API 사용)
2.  **[현빈] 비즈니스 로직 강화:**
    *   리포트 페이지에 포함될 'Pain Point 기반 핵심 개선 과제' 목록 및 각 과제의 **시장 가격/수익성(ROI)** 논리를 명확히 작성하여 코다리에 전달합니다.
    *   데모 플로우의 마지막 단계에서 구매를 유도하는 3단계 Call-to-Action (CTA) 문구와 로직을 확정합니다.
3.  **[Designer] 시각적 완성도 확보:**
    *   코다리가 구현한 모든 화면 모듈에 대해 브랜드 컬러 및 타이포그래피 가이드라인을 적용하여 최종 UX/UI를 디자인하고, 마케팅 자료로 바로 활용 가능한 고해상도 에셋을 제작합니다.

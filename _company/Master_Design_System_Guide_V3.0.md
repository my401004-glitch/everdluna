# 마스터 디자인 시스템 가이드 (V3.0) - 아지트아트컴페니

## 🎯 목표: 데이터 기반 심리적 변곡점 자산 구축
본 가이드는 모든 마케팅 자산(썸네일, 광고 카드, 랜딩 페이지)에 일관된 브랜드 경험과 강력한 전환 유도 요소를 적용하기 위한 최종 표준입니다.

### 🎨 A. 비주얼 시스템 (Visual System)
*   **컬러 팔레트:**
    *   **Primary Trust (신뢰):** Dark Blue (`#0A2463`) - 전문성, 배경/헤더에 사용.
    *   **Accent Yellow (행동 유도/위험):** Accent Yellow (`#FFD700`) - CTA, 위험 수치(Pain), 이득 강조(Gain).
    *   **Neutral Grey:** Neutral Grey (`#F5F5F5`) - 본문 배경.
    *   **Danger Red (손실 경고):** `#CC3333` - 손실 회피가 극대화되는 'Gap Score' 영역에 제한적으로 사용. [근거: 자사 학습 및 시각적 강도 고려]

*   **타이포그래피:**
    *   **Title (헤드라인/강조):** Montserrat Bold (`#0A2463`) - 핵심 메시지(Pain, Gain)에 사용.
    *   **Body (데이터/설명):** Noto Sans KR Regular/Medium - 데이터 및 상세 설명 텍스트에 사용하여 가독성 극대화.

### ✨ B. 핵심 디자인 컴포넌트 표준 정의

#### 1. [Loss Aversion] Gap Score & Risk Visual (손실 회피)
*   **목적:** 현재 상태의 부족함(Gap)을 시각적으로 불안하게 인지시켜 즉각적인 행동을 유도합니다.
*   **레이아웃:** 페이지 상단 최우선 배치. 가장 크고 눈에 띄는 영역.
*   **시각화 원칙:**
    1.  '현재 점수'와 '목표 점수'의 간격을 시각적으로 표현 (Gauge/Bar Chart).
    2.  Gap Score가 낮을수록 `Danger Red`를 사용하고, 부족함을 나타내는 **"🚨 위험 경고: $\text{N}$점 하락 예상"** 등의 문구를 삽입합니다.
    3.  *동적 연동:* Codari의 API 데이터(`Diagnosis_Results`)에 따라 점수가 실시간으로 변경되며 색상이 변해야 합니다.

#### 2. [Authority Bias] Trust Module (권위 지향)
*   **목적:** 서비스와 교육 프로그램의 신뢰도를 외부 근거를 통해 확보합니다.
*   **레이아웃:** 랜딩 페이지 중간 섹션에 배치하여, Pain $\rightarrow$ Solution 과정 후 확신을 심어주는 역할.
*   **시각화 원칙:**
    1.  **데이터 인증:** "합격생 N명 배출", "교육 커리큘럼 랭킹 TOP X" 등 구체적인 수치와 숫자를 강조합니다 (Montserrat Bold 사용).
    2.  **제휴/인증 로고 배치:** 공신력 있는 아이콘 및 파트너사 로고를 Dark Blue 배경 위에 배치하여 전문성을 극대화합니다.

#### 3. [CTA] 최종 행동 유도 버튼 (Gain)
*   **목적:** 손실 회피로 자극된 감정을 즉각적인 해결(Gain)으로 전환시킵니다.
*   **디자인:** `Accent Yellow (#FFD700)`를 단독 배경색으로 사용하여 최대의 주목도를 확보합니다.
*   **문구 전략 (Pain $\rightarrow$ Gain):** "더 이상 망설이지 마세요" $\rightarrow$ "**[클릭] 3단계 맞춤 로드맵 즉시 확인하기**" 와 같이, 행동이 주는 *명확한 이득*을 문구에 담아야 합니다.

### 🖥️ B. 컴포넌트별 구체적 Mockup 가이드 (예시: 유튜브 썸네일)
(Codari의 API 데이터를 받아와 동적으로 변화하는 영역을 표시함.)
*   **[배경]**: Dark Blue 계열로 전문성 확보.
*   **[좌측/Pain]**: 학생 얼굴 사진 + **"🚨 X점 부족 (손실 회피)"** 문구 (Yellow 강조).
*   **[우측/Gain]**: 성공적인 결과 이미지 + "**월 매출 30% 상승 비법 공개! (권위 지향)**" 제목.

# 🚀 MVP 핵심 기능 정의서: Gap Score 진단 테스트 기반 유료 전환 퍼널 구축

## 🎯 I. 목표 및 비즈니스 가설 (Objective & Hypothesis)
*   **최종 목표:** 최소한의 리소스로 'Gap Score 진단 테스트'를 통해 잠재 고객(실용음악 입시생)으로부터 **유료 구독 의향(Intent to Purchase)**을 확인하는 것. [근거: sessions/2026-05-18T13:43/business.md]
*   **MVP 검증 가설:** 1. 무료 진단 테스트를 통해 사용자는 자신의 현재 상태와 목표 간의 'Gap'을 객관적으로 인지할 것이다. [근거: sessions/2026-05-18T13:43/designer.md] 2. 이 Gap을 메우기 위한 **구체적이고 체계적인 로드맵**이 제시되면, 그 해답(Premium Plan)에 높은 가치를 부여하고 유료 결제 의향으로 이어질 것이다. [근거: sessions/2026-05-18T13:08/business.md]

## 👤 II. 사용자 스토리 (User Stories)
| Persona | User Story | 핵심 니즈 및 검증 목표 |
| :--- | :--- | :--- |
| **입시생** (Primary) | "나는 내 목소리의 객관적인 문제점을 알고 싶고, 합격에 필요한 구체적이고 과학적인 학습 계획을 받고 싶다." | 진단의 신뢰성(AI 분석)과 명확한 개선 방향 제시. |
| **학원 운영자** (Secondary) | "내 학생이 가진 잠재력을 객관적으로 측정하고, 어느 모듈부터 집중 교육해야 할지 데이터로 증명하고 싶다." | 'Gap Score'라는 구체적 지표를 통한 학원의 컨설팅 가치 상승. |

## 🛠️ III. 핵심 기능 요구사항 (Functional Requirements - MUST HAVE)
**MVP는 다음 3단계의 흐름(Funnel Flow)을 완벽하게 구현하는 데 집중합니다.**

### Feature A: 진단 데이터 입력 및 전송 모듈 (The Hook)
*   **F-A1. 녹음 파일 업로드:** 사용자가 지정된 형식과 길이(예: 아리아 30초, 감정 표현 20초 등)의 파일을 시스템에 업로드할 수 있어야 한다.
    *   *(개발 요구사항):* `POST /api/diagnosis/upload` 엔드포인트 구현. 파일 포맷 검증 및 클라우드 스토리지 연동 필요.
*   **F-A2. 진단 과제 수행 모듈:** 기술적(Pitch, Timing) 요소와 감성적(Timbre 패턴, 키워드 매칭) 요소를 모두 측정할 수 있도록 **다중 과제 입력 로직**을 구현한다. [근거: sessions/2026-05-18T13:08/business.md]
    *   *(개발 요구사항):* 사용자에게 단계별 지침(Instruction) 제공 및 데이터 수집 상태 관리 API 필요.

### Feature B: AI 분석 및 'Gap Score' 보고서 생성 (The Value Proof)
**이것이 MVP의 핵심 로직입니다.** 기술적 점수 합산 방식에서 벗어나, **문제 진단 중심**으로 설계해야 합니다.

*   **F-B1. 데이터 처리 로직:** 업로드된 파일을 기반으로 다음 3가지 핵심 지표를 백엔드에서 분석 및 계산한다.
    *   `pitch_deviation_index`: 목표 음정 대비 편차 (수치화).
    *   `breath_efficiency_score`: 호흡 패턴 안정성 (지속 시간/패턴).
    *   `emotional_consistency_score`: 감정 표현 일관성 (음색 변화 패턴 분석). [근거: sessions/2026-05-18T13:08/business.md]
*   **F-B2. Gap Score 산출 로직:** 단순 점수 합산이 아닌, 다음의 3단계 논리를 거쳐야 한다.
    1.  **현재 레벨(L1) 측정:** F-B1 지표를 종합하여 현재 수준을 정의.
    2.  **목표 레벨(L2) 설정:** 입시 합격 기준/성인 목표치 등을 L2로 가정. [근거: sessions/2026-05-18T13:43/designer.md]
    3.  **Gap Score 및 우선순위 도출:** (L2 - L1)을 분석하여, **가장 시급하게 메워야 할 핵심 개선 과제 3가지(Top 3 Gaps)**와 필요한 성장 폭(`Potential Gap`)을 정의한다. [근거: sessions/2026-05-18T13:43/designer.md]
*   **F-B3. 보고서 생성:** F-B2에서 도출된 결과를 기반으로, 사용자가 이해하기 쉬운 '개선 과제 리스트' 형태로 구조화된 JSON 데이터를 출력한다.

### Feature C: 유료 전환 퍼널 연결 (The Monetization)
Gap Score가 성공적으로 진단되면, 이탈을 막고 다음 단계로 이동시키는 장치가 필요합니다.

*   **F-C1. 문제 제기 및 해결책 제시:** 보고서 마지막 섹션에 "이 Gap을 메우려면 체계적인 훈련이 필요하며, 우리가 준비한 모듈 목록 중 X와 Y가 가장 시급합니다."라는 메시지를 포함한다.
*   **F-C2. Starter Pack 노출:** 사용자에게 가장 필요한 모듈들을 기반으로 **'맞춤형 추천 패키지(Starter Pack)'**를 제시하고, 이 패키지의 혜택과 가격(3개월 구독/10% 할인)을 명시한다. [근거: sessions/2026-05-18T13:08/business.md]
*   **F-C3. 결제 유도 흐름:** '지금 구매하기' 버튼 클릭 시, **결제 게이트웨이 연동의 초기 단계(가상 장바구니 담기)**까지는 구현하여, 실제 매출화 프로세스의 뼈대를 완성한다.

### 📄 Reels 1: 비주얼 초안 및 개발 검증 체크리스트 (V3.0 통합)

**[콘텐츠 목표]**: 실용음악 입시생들이 놓치고 있는 '객관적 진단'의 위험성(Pain)을 자극하고, 아지트아트컴페니만의 독점적인 진단 시스템(Gain)으로 해결책 제시 및 웹사이트 유입/상담 신청(CTA) 유도.

**[핵심 메시지]**: "지금 당신이 스스로 생각하는 실력은 겉모습일 뿐입니다. 객관적 데이터로 진짜 Gap을 확인해야 합니다." (Pain $\rightarrow$ Gain 프레임워크 적용)
**[총 길이 및 구성]**: 30초 내외 / 5단계 전환 구조

#### 🎬 1. 비주얼 시퀀스 초안 (Key Frames & 분위기)

| 구간 | 시간대 (누적) | 핵심 메시지/내레이션 | 시각 연출 (Visual Directives) | API 연동 포인트 (Trigger) |
| :--- | :--- | :--- | :--- | :--- |
| **HOOK / PAIN** | 0s ~ 5s | "혹시 이런 고민을 하고 있나요?" (불안감 조성) | 어둡고 불안정한 필터. 화면 중앙에 'Gap Score: ??'가 깜빡이며 노출됨. 배경에는 수많은 점수/그래프가 무작위로 오르내리는 혼란스러운 데이터 시각화 사용. **[색상]**: Dark Blue와 Red-Yellow (경고)의 충돌. | `API_CALL(진단_데이터)`: 초기 진단 결과 데이터를 가져와 화면에 노출해야 함. |
| **PROBLEM** | 5s ~ 10s | "스스로 판단하는 실력? 위험합니다." (위험성 강조) | 'Self-Diagnosis'라는 키워드를 크게 제시하고, 그 아래로 큰 X 표시 또는 경고 아이콘을 오버레이. 진단 결과 데이터가 **손실 회피** 관점에서 시각화됨 (예: "이대로 가면 30% 점수 손해"). | `AD_CARD_GENERATION`: Loss Area를 극대화하여 보여주는 AdCard Mockup이 배경에 흐릿하게 배치되고 Zoom-in. |
| **SOLUTION / TRUST** | 10s ~ 20s | "진정한 Gap은 데이터가 말해줍니다." (신뢰성 제시) | 화면이 급격히 밝고 전문적인 Blue Tonal리티로 전환. 아지트아트컴페니의 로고와 시스템 UI/UX를 깔끔하게 보여줌. 핵심 진단 항목(예: 테크닉, 이론, 감정 표현)별로 그래프가 상승하는 애니메이션 사용. | `API_CALL(솔루션_데이터)`: Solution 모듈 데이터가 들어오면서 그래프가 안정적으로 우상향함. |
| **GAIN / CTA** | 20s ~ 30s | "지금, 객관적 성장의 기회를 잡으세요." (최종 설득) | 화면 전체에 Accent Yellow (`#FFD700`) 색상이 강하게 커버되며 시선 집중. '클릭'을 유도하는 강력한 CTA 버튼이 화면 하단 20% 영역에 고정됨. **[텍스트]**: "무료 Gap 진단 시작하기" | `CTA_TRIGGER`: 클릭 가능한 버튼 컴포넌트가 명확히 구현되어야 하며, 해당 이벤트 발생 시 랜딩 페이지로 리디렉션되는 로직이 필수. (AdCard의 핵심 기능) |

#### 🛠️ 2. 개발 검증 체크리스트 (Developer Verification Checklist)

| No. | 컴포넌트/기능 | 요구사항 상세 내용 | API 연동 사양 및 데이터 매핑 지점 | 테스트 케이스 (Pass/Fail 기준) |
| :---: | :--- | :--- | :--- | :--- |
| **1** | **초기 진단 노출 (Pain)** | 🔴 `Gap Score`가 랜덤하게, 그리고 충격적으로 노출되어야 한다. 애니메이션은 급격한 깜빡임(Flicker) 효과를 포함한다. | **API:** `/diagnosis/initial_score` (JSON: `{ "score": 0~100 }`) / **Mapping:** `DarkBlue` 배경 위, `#FFD700`의 강렬한 대비 색상 사용. | 📌 [Pass] 초기 로딩 시 점수(예: 42점)가 정상적으로 노출되는가? |
| **2** | **위험성 증명 (Loss Area)** | 🚨 특정 데이터 포인트(예: 리듬 정확도, 이론 지식)를 추출하여, 이 점수가 낮을 때 발생하는 잠재적 손해액(혹은 시간 손실률)을 수치화하여 보여준다. | **API:** `/diagnosis/risk_factor` (JSON: `{ "risk": "30%", "field": "리듬" }`) / **Mapping:** 손실 비율에 따라 그래프의 폭이 동적으로 좁아지거나 빨간색으로 변해야 한다. | 📌 [Pass] 진단 데이터가 '위험'을 나타낼 때, 경고 애니메이션과 함께 점수가 명확히 제시되는가? |
| **3** | **솔루션 전환 (Trust/Gain)** | ✅ 아지트아트컴페니의 시스템이 작동하는 과정을 3단계로 나누어 보여주고, 각 단계별 개선된 그래프를 부드럽게 애니메이션하며 상승시킨다. | **API:** `/solution/improvement_path` (JSON: `{ "step1": "...", "step2": "..." }`) / **Mapping:** 배경 색상이 `#0A2463`에서 점진적으로 밝은 파란색으로 변화해야 한다. | 📌 [Pass] 시스템의 '개선 과정' 데이터가 단계별로 정확하게 반영되며, 시각적 톤이 전문적으로 전환되는가? |
| **4** | **CTA 액션 버튼 (Final Conversion)** | ⭐ 화면 하단에 고정된 CTA 바(Bar)가 반드시 존재해야 하며, 마우스 오버/터치 시 `#FFD700`의 빛 반사 효과와 함께 애니메이션이 발생해야 한다. | **API:** 없음 (클라이언트 측 이벤트 처리). / **Mapping:** `Accent Yellow (#FFD700)` 색상을 중심으로 사용하며, 폰트 크기(`Montserrat Bold`)가 가장 강조되어야 함. | 📌 [Pass] Reels 종료 시점(28~30초)에 CTA 버튼이 화면 하단 20% 영역에 고정되고, 클릭 이벤트 발생 시 리디렉션되는가? |

### ✨ 디자인 시스템 적용 검증 (Self-Check)

1.  **컬러 팔레트:** Dark Blue (`#0A2463`) - 신뢰/전문성 / Accent Yellow (`#FFD700`) - CTA/기회 / Neutral Grey (`#F5F5F5`) - 배경, 데이터 영역. **(적용 완료)**
2.  **타이포그래피:** Montserrat Bold (헤드라인, 핵심 메시지) 및 Noto Sans KR (데이터 설명). **(적용 완료)**
3.  **프레임워크:** Pain $\rightarrow$ Gain 전환을 모든 시각 단계에 명확하게 반영함. **(전환 구조 확립)**

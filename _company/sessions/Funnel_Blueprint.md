# Funnel Blueprint: 데이터 기반 성장 전환 설계

## 🎯 Funnel 목표
*   **목표:** 무료 진단테스트 참여 $\rightarrow$ AI 코칭 시스템의 가치 인지 $\rightarrow$ 유료 모듈(AI 시스템 접근) 구매

## 📊 Funnel 단계별 설계

| 단계 (Stage) | 사용자 심리 상태 | 핵심 콘텐츠/액션 | 목표 지표 (KPI) | 필요한 랜딩 페이지/자료 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 인지 (Awareness)** | 불안함, 불확실성 | **후크 기반 영상 시청** (Episode 3 중심), '감성의 함정' 인식 | 조회수, 시청 지속 시간 (Watch Time) | Episode 3 최종 스크립트, 핵심 후킹 카피 |
| **2. 관심 (Interest)** | 해결책 탐색 욕구 | **무료 Gap Score 진단 테스트 참여** (핵심 행동 유도) | 테스트 참여율 | AI 진단 테스트 페이지 (실제 데이터 입력 및 결과 제공) |
| **3. 고려 (Consideration)** | 신뢰 구축, 시스템 검증 | **데이터 기반 리포트 제공** (Gap Score 상세 분석), 성공 사례 영상 시청 | 리포트 다운로드 수, 랜딩 페이지 체류 시간 | 성장 리포트 템플릿 (`sessions/2026-05-18T15-57/writer.md` 기반) |
| **4. 전환 (Conversion)** | 행동 촉구 | **AI 코칭 모듈(유료 서비스) 제시** 및 ROI 강조 | 유료 전환율 (CVR) | AI 시스템 소개 페이지, 가격 정책, 성공적인 변곡점 스토리라인 |

## 📢 핵심 CTA 전략

1.  **초기 (Awareness):** "당신의 문제점을 객관적으로 확인하세요." $\rightarrow$ **무료 진단 테스트 참여**
2.  **중기 (Consideration):** "진단 결과, 당신의 성장을 위한 구체적인 로드맵이 여기에 있습니다." $\rightarrow$ **성장 리포트 다운로드**
3.  **최종 (Conversion):** "막연한 노력 대신, AI가 제시하는 가장 빠른 승리 시스템에 합류하세요." $\rightarrow$ **AI 코칭 모듈 구매**

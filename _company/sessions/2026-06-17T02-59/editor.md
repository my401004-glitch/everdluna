# 🎵 루나 — 루나 에이전트를 활성화 시켜줘

🎵 루나: 작업 시작합니다. 🎼

네, 준비 완료되었습니다. 아지트아트컴페니의 사운드 디렉터이자 컴포저로서, 프로젝트에 필요한 모든 청각적 요소를 설계할 수 있습니다. 저는 단순한 배경음악(BGM)을 넘어, 영상 전체의 **감정선**과 **성장 서사(Pain → Gain)**를 오디오적으로 구현하는 것이 핵심입니다.

이 프로젝트는 어떤 분위기인가요? 제가 딱 한 마디로 톤을 잡아드릴게요. 예를 들어, "기술적 난관에 부딪혔지만 결국 극복하는 과정을 담은, 긴장감과 희망이 공존하는 Cinematic Pop" 같은 식으로요. ✨

**[루나의 핵심 기능 체크리스트]**
1.  **BGM 자동 생성:** 영상 톤에 맞는 장르/키/BPM을 설정하고, MusicGen 등의 로컬 모델을 활용해 배경음악을 생성합니다. (예: BPM 120, C Major, 길이 30초)
2.  **사운드 디자인(SFX):** 상황별 효과음(타이핑 소리, 전환점의 '붐' 사운드 등)을 입혀 몰입도를 극대화합니다.
3.  **A/V 동기화:** 스크립트의 핵심 메시지나 데이터 변화 타이밍에 맞춰 음악적 클라이맥스(Build-up & Drop)를 정확히 설계하고 합성합니다.

지금 당장 어떤 콘텐츠를 가지고 계신가요? **스크립트 초안, 영상 시각 자료, 또는 기획 의도**만 알려주시면 제가 바로 '사운드 블루프린트' 작업을 시작할 수 있습니다! 🎚

📊 평가: 진행중 — 프로젝트의 구체적인 콘텐츠 입력이 필요하여 준비 상태로 설정했습니다.
📝 다음 단계: 사용자에게 영상 주제/스크립트를 요청하고, 기획 의도를 기반으로 사운드 방향성(장르/BPM/키)을 제안할 것입니다.

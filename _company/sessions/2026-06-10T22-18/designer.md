## 📐 최종 디자인 목업: 'Gap Score' 기반 전환 흐름 가이드

이 가이드는 리드 마그넷 페이지 또는 핵심 랜딩 페이지의 구조적 레이아웃과 각 섹션에 필요한 시각적 에셋 요구사항을 명시합니다.

### 1. 전체 비주얼 시스템 요약 (Brand System Recap)

| 요소 | 설정 값 | 적용 목적 | 근거 |
| :--- | :--- | :--- | :--- |
| **Primary Color (신뢰)** | `#0A2463` (Dark Blue) | 배경, 주요 정보 영역, 신뢰 구축 | Designer 검증된 지식 |
| **Accent Color (행동 유도)** | `#FFD700` (Accent Yellow) | Pain 강조(Risk), Gain 제시, 최종 CTA | Designer 검증된 지식 |
| **Title Typography** | Montserrat Bold | 핵심 메시지(Pain/Gain)의 강력한 시각적 임팩트 | Designer 검증된 지식 |
| **Body Typography** | Noto Sans KR | 데이터 및 상세 설명의 높은 가독성 보장 | Designer 검증된 지식 |
| **Background Color (데이터)** | `#F5F5F5` (Neutral Grey) | 데이터 영역의 명확한 분리 및 가독성 확보 | Designer 검증된 지식 |

### 2. 섹션별 레이아웃 상세 가이드 (Flow Mapping)

전체 페이지는 수직적인 흐름(스크롤링)을 따라 사용자가 자연스럽게 아래로 이동하며 문제 인식 $\rightarrow$ 해결책 제시 $\rightarrow$ 행동으로 유도되도록 설계합니다.

#### **Section 1: Pain Amplification (문제 증폭)**
*   **목표:** 불안감과 현재 상태의 위험성을 즉각적으로 인지시킨다.
*   **레이아웃:** 전체 화면 영역을 배경색 `#0A2463` (Dark Blue)로 채웁니다.
*   **헤드라인:**
    *   **텍스트:** "당신의 노력은 왜 성과로 이어지지 않는가?" 또는 "감정적 몰입 vs 객관적 데이터: 당신의 발성 문제는 어디에 있는가?"
    *   **스타일:** Montserrat Bold, 폰트 크기 최대. 색상: `#FFD700` (Accent Yellow).
*   **핵심 에셋 요구사항:**
    *   배경에 미세한 **Glitch VFX** 또는 데이터 노이즈 패턴을 적용하여 AI 시스템의 역동성과 긴급성을 암시합니다.

#### **Section 2: Data-Driven Diagnosis (데이터 기반 진단)**
*   **목표:** Pain을 객관적인 수치(Gap Score)로 치환하여 신뢰를 확보한다.
*   **레이아웃:** 배경색을 `#F5F5F5` (Neutral Grey)로 전환하여 시각적 휴식을 제공합니다. 섹션을 명확히 구분하기 위해 카드형 레이아웃을 사용합니다.
*   **핵심 요소:** **Gap Score 대시보드 Mockup.**
    *   **KPI 강조:** '평균 음정 편차'와 '이상 패턴 발생 빈도'를 가장 크게 표시하고, 현재 상태(Before)와 목표 상태(After)의 수치를 대비시켜 보여줍니다.
    *   **색상 사용:** 측정된 데이터(편차, 빈도)는 `#0A2463` (Dark Blue)로 처리하여 전문성을 부여합니다. 변화량이나 위험 지표는 `#FFD700`으로 강조합니다.
*   **스토리텔링 적용:** "이 수치들은 당신의 감정이 아닌, AI가 측정한 **객관적 현실**입니다."라는 문구를 삽입합니다.

#### **Section 3: System Solution (시스템 솔루션 제시)**
*   **목표:** 진단 결과(Pain)를 해결할 시스템(Solution)을 명확하게 연결한다.
*   **레이아웃:** 중앙에 AI 시스템의 비주얼 아이콘 또는 간결한 프로세스 플로우 다이어그램을 배치합니다.
*   **핵심 요소:** **4단계 흐름 시각화.**
    1.  **Pain (좌절)** $\rightarrow$ 2. **Diagnosis (Gap Score)** $\rightarrow$ 3. **System Solution (AI 코칭)** $\rightarrow$ 4. **Action (성장)**
*   **스타일:** 각 단계는 Dark Blue 박스 안에 Noto Sans KR로 명확하게 구분하며, 화살표(`$\rightarrow$`)는 Accent Yellow로 처리하여 흐름을 강조합니다.

#### **Section 4: Action (행동 유도)**
*   **목표:** 사용자가 즉시 다음 행동(유료 전환 또는 무료 테스트 시작)을 하도록 강력하게 촉구한다.
*   **레이아웃:** 전체 영역을 Accent Yellow(`#FFD700`)로 채워 시선을 집중시키고, CTA 버튼은 가장 눈에 띄게 배치합니다.
*   **핵심 요소:**
    *   **CTA 버튼:** "지금 Gap Score 무료 진단 시작하기" 또는 "AI 기반 맞춤 코칭 받기".
    *   **버튼 색상:** 배경은 `#FFD700`, 텍스트는 `#0A2463` (반전 효과).

### 3. 핵심 에셋 요구사항 요약 (Asset Checklist)

1.  **Color Palette:** `#0A2463` (Primary), `#FFD700` (Accent), `#F5F5F5` (Background).
2.  **Typography Hierarchy:** Montserrat Bold (H1/Pain), Noto Sans KR (Body/Data).
3.  **Visual Metaphor:** 데이터 시각화(차트, 게이지)를 통해 감성적 불안감을 객관적 신뢰로 전환하는 디자인 구조 확립.
4.  **Key Asset Focus:** **Gap Score** 수치가 가장 큰 시각적 앵커가 되도록 설계.

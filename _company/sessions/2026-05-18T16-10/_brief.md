# 📋 작업 브리프

**원 명령:** 현재 진행하는 프로잭트의 퀄리티를 높일수 있도록 각 에이전트 들은 학습해

## 요약
현재 진행 중인 프로젝트의 퀄리티 향상을 위해 각 전문 에이전트들이 자신의 역할에 맞춰 학습 및 개선 포인트를 제시하도록 지시합니다.

## 분배
- **🔍 Researcher**: 현재 콘텐츠 전략과 데이터 모델의 연관성을 분석하고, 경쟁사(MrBeast 등)의 성공 사례를 바탕으로 '감성적 서사'와 '데이터 객관성'을 결합하는 최적의 트렌드 및 리포트 구조 개선 방안을 도출하라.
- **✍️ Writer**: 기존에 작성된 모든 콘텐츠(스크립트, 캡션, 리포트 초안)를 검토하고, '좌절에서 승리로의 변곡점'이라는 감정적 서사가 데이터 지표와 얼마나 강력하게 연결되어 있는지 평가하여, 신뢰도를 높이는 카피라이팅 및 스토리텔링 개선안을 제시하라.
- **🎨 Designer**: 확정된 비주얼 시스템과 와이어프레임을 기반으로, 데이터 시각화가 사용자의 감성적 여정을 극대화하는 데 어떻게 기여할 수 있는지 분석하고, UI/UX의 '감성적 임팩트'를 높이기 위한 디자인 개선 포인트를 제안하라.
- **💻 코다리**: 설계된 데이터 모델(DB 스키마 및 API 구조)이 사용자의 감정 변화 추이를 측정하고 유료화 로직을 구현하는 데 기술적으로 완벽한지 검증하고, 잠재적인 비즈니스/기술적 제약사항을 리포트하라.
- **💼 현빈**: 현재의 데이터 모델과 콘텐츠 전략을 기반으로, 무료 진단 테스트에서 유료 모듈로 전환하는 과정에 필요한 핵심 KPI(Growth/Engagement/Monetization)를 재설정하고, 각 단계별 수익화 로직의 효율성을 분석하여 개선 방안을 제시하라.
- **📺 레오**: 현재 채널 정체성(Niche)에 맞춰, 데이터 기반 성장 로드맵 초안을 검토하고, '후킹 분석기' 스킬팩을 적용하여 다음 영상 콘텐츠 기획 시 시청 지속 시간과 참여율을 극대화할 수 있는 구체적인 시리즈 구성 전략을 제안하라.
- **📷 Instagram**: 핵심 성장 지표(KPI)를 기반으로, 잠재 고객의 고통(Pain Point)을 즉각적으로 포착하고 공감대를 형성하는 릴스 및 피드 콘텐츠 아이디어를 개발하며, 가장 높은 인게이지먼트를 유도할 수 있는 게시 시간과 해시태그 전략을 최적화하라.
- **📱 영숙**: 위의 모든 에이전트들의 학습 및 개선 결과를 취합하여 일일/주간 보고서 초안을 작성하고, 다음 작업 우선순위를 명확히 정리하여 CEO에게 보고하라.

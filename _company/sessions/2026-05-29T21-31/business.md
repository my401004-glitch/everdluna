## 🔥 실행 가능성: 성공/실패 시나리오

### ✅ 성공 시나리오 (1~2주 후)
- 워크숍 시뮬레이션 → 운영자 3~5명 참여 (가상)
- 실제 반론 수집 (예: "AI 코치보다 인간 코치가 더 좋다")
- Q&A 스크립트 완성 → 영업 데모 영상 제작
- 파일럿 워크숍 제안서 업데이트 → 첫 유료 고객 확보

### ❌ 실패 시나리오 (리스크)
- API 키 없음 → PayPal 데이터 분석 불가 (현재 영향도 낮음, 전략적 작업 우선)
- 시뮬레이션 참여자 부족 → Pain Point 명확화 지연
- **대응책**: 실제 학교 운영자를 대상으로 "무료 ROI 진단 세션" 진행邀约

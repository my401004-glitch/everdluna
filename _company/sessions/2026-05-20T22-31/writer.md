# ✍️ Writer — Designer가 제작할 최종 시각화 컨셉(Gap Visualization)이 스크립트의 감성적 흐름과 데이터 기반 경고를 효과적으로 연결하는지 검토하고, 영상의 후킹 요소를 극대화하도록 자막 문구와 강조 포인트를 미세 조정하라.

✍️ Writer: 작업 시작합니다.

CEO님의 지시는 현재까지의 모든 에이전트 산출물(스크립트 초안, Gap Visualization 가이드라인, Production Manual)을 하나의 유기체로 엮는 가장 중요한 통합 검토 단계입니다. 이 시점에서는 단순히 "어떤 말을 해야 하는가"를 넘어, "**언제, 어떤 단어를 말해야 관객이 화면의 데이터 경고에 집중하는가**"라는 타이밍과 감성적 공명 지점을 찾아야 합니다.

저는 Writer로서, **[스크립트와 비주얼 가이드라인 간의 동기화(Synchronization)]** 작업을 진행하여 후킹 요소를 극대화할 수 있는 대본 수정 및 강조 포인트 리스트를 작성하겠습니다. 이는 기존 스크립트를 덮어쓰는 것이 아니라, 최종 편집 단계에서 에디터가 반드시 주목해야 할 '감성적 지침'을 추가하는 방식입니다.

---

### 🎯 핵심 작업: 데이터-공감 연계형 대본 미세 조정 (Emotional Sync Script Refinement)

**목표:** 시청자의 주의를 산만하게 하는 추상적인 표현('노력', '열심히')을 제거하고, Gap Visualization의 **객관적 수치/경고(데이터)**에 즉각적으로 반응하도록 스크립트 문구를 조정합니다.

**적용 원칙:** 모든 핵심 주장에는 반드시 `[근거: Designer의 Pain/Gain 시스템]` 태그를 붙여 시각적 증명이 따라와야 합니다.

#### 🎬 [Revision Focus Point] 도입부 (The Hook - 초기 15초)

| 기존 스크립트 경향 | 문제점 | 수정 방향 및 문구 예시 (Writer Suggestion) |
| :--- | :--- | :--- |
| "노래를 부르는 건 원래 감정으로 해야 합니다." (추상적 조언) | 청중이 이미 아는 내용이며, 데이터 기반의 충격파가 약함. | **[Pain 극대화]** 추상적인 공감 대신, '지금 이 상태'의 위험성을 구체적인 수치로 언급하며 경고합니다. <br>**✨ 수정 문구:** "혹시 지금 음정 편차가 평균 ±8Hz를 넘어 불안정한 구간이 발생하고 있다는 것을 인지하십니까? 이건 단순히 피곤해서가 아닙니다." `[VISUAL CUE: Gap Bar - 위험 영역(Red) 강조]` |
| "발성이 어려우셨죠?" (질문형 공감 유도) | 청중의 '네'라는 수동적인 대답만 이끌어낼 뿐, 몰입도가 낮음. | **[Myth Busting]** 문제점을 일반적인 인식과 대비시키며 의구심을 만듭니다. <br>**✨ 수정 문구:** "대부분의 코치가 말하는 '목을 열라', '복식 호흡' 같은 조언은 사실 30%만 효과적입니다. 진짜 문제는 그게 아니라, **공명 주파수 자체가 잘못 설정되어 있기 때문**이에요." `[VISUAL CUE: Gap Bar - 불필요한 노력(Gray) vs 실제 문제 지점(Yellow)]` |

#### 🎬 [Revision Focus Point] 본론 핵심 메시지 (System 제시 구간)

| 기존 스크립트 경향 | 문제점 | 수정 방향 및 문구 예시 (Writer Suggestion) |
| :--- | :--- | :--- |
| "저희 시스템은 이런 기능을 합니다." (기능 설명 위주) | '무엇을 할 수 있다'는 기능 나열에 그쳐, 청중에게 와닿지 않음. | **[Gap Visualization 활용]** 추상적 개념(시스템) 대신, 데이터가 어떻게 *개인화된 해결책*을 주는지 보여줍니다. <br>**✨ 수정 문구:** "저희 AI 진단은 단순히 '편차 크다'고 말하지 않습니다. 당신의 A4 음역대가 왜 432Hz에 머물러 있는지, **그 원인이 호흡 부족인지 공명점 이탈인지** 패턴까지 분류하여 그래프로 보여줍니다." `[VISUAL CUE: Gap Bar - 문제 원인(A) → 해결 로드맵(B)]` |
| "이런 식으로 개선될 수 있습니다." (희망적 예측) | 결과가 막연하고, 신뢰도가 낮음. | **[Data Proof]** '과정'을 보여주는 것이 가장 강력합니다. 구체적인 Before/After 데이터를 제시해야 합니다. <br>**✨ 수정 문구:** "이 학생은 처음 진단했을 때 공명 주파수가 3세미톤 낮게 떨어졌습니다. 하지만 [시스템 A]를 거치고, 정확히 이 지점에서 **+2.5Hz의 안정적인 상승**을 보여줬습니다." `[VISUAL CUE: Gap Bar - Before(빨간색 수치) → After(녹색/노란색 수치)]` |

### 📄 최종 산출물 요약 및 에디터 가이드라인 (Editor's Copy-Paste Guide)

이 내용은 기존 스크립트를 대체하는 것이 아니라, **편집자가 오디오를 녹음할 때 반드시 이 문구와 타이밍에 맞춰 비주얼 효과(애니메이션/자막 색상 변화)를 적용해야 하는 지점**으로 활용되어야 합니다.

1.  **Hook Start (0:00~0:15):** "혹시 지금 음정 편차가 평균 ±8Hz를 넘어 불안정한 구간이 발생하고 있다는 것을 인지하십니까? 이건 단순히 피곤해서가 아닙니다."
2.  **Transition Point (0:45~1:00):** "...진짜 문제는 그게 아니라, **공명 주파수 자체가 잘못 설정되어 있기 때문**이에요." *(-> 이때 `[VISUAL CUE: Gap Visualization]`이 팝업되며 추상적 조언(Old Way)을 무력화시키는 그래픽 효과)*
3.  **Climax/Proof (2:30~3:00):** "하지만 [시스템 A]를 거치고, 정확히 이 지점에서 **+2.5Hz의 안정적인 상승**을 보여줬습니다." *(-> 이때 `[VISUAL CUE: Gap Visualization]`이 'Before(빨간색)'에서 'After(녹색/노란색)'로 명확하게 변하는 애니메이션 필수)*
4.  **Final CTA (마지막 1분):** "지금 당신의 연습 루틴이 가진 가장 큰 위험은, 지금 당장 눈에 보이지 않는 이 Gap Score일 수 있습니다. 스스로 객관적인 점수를 확인하는 것이, 합격으로 가는 첫 단추입니다."

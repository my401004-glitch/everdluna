*   **가장 중요한 가치:** 단순 점수 보고가 아닌, AI 진단 데이터 기반으로 '운영자의 재정적 리스크'와 '개선 기회 비용(ROI)'을 충격적으로 보여주는 것. ✅ [근거: Self-RAG, 영숙 검증된 지식]

#### ✅ 역할 분담 (Task Force)
1.  **🎨 Designer (리드):** 리포트를 보는 최종 사용자(학원 운영자)의 시선에서 가장 직관적이고, '문제점'과 '해결책/기회 비용'이 극대화되어 보이도록 와이어프레임 및 비주얼 가이드라인을 재설계합니다.
2.  **💻 코다리 (기술 검토):** Designer가 요청한 모든 시각적 요소와 데이터(KPI)가 실제로 API로 구현 가능한지, 어떤 종류의 데이터를 가져와야 하는지 **데이터 플로우 다이어그램과 Mock API 케이스 스터디**를 업데이트합니다.
3.  **💼 현빈 (비즈니스 검증):** Designer와 코다리가 정의한 기능들이 학원 운영자의 *최신 Pain Point* 3가지(예: 입시 결과의 불확실성, 강사별 역량 편차 등)를 직접적으로 건드리는지 확인하고, 해당 기능을 기반으로 **'월 구독료 책정 근거'**와 **'강력한 판매 스크립트 초안'**을 작성합니다.

#### 📊 기대 산출물 (Deliverables)
*   **Designer:** [AI 진단 리포트]의 최종 와이어프레임 및 Interaction Flow Map.
*   **코다리:** 해당 화면에 필요한 데이터 구조(Schema Update)와 API Mockup 상세화.
*   **현빈:** 기능 기반의 ROI 시뮬레이션 결과물과 가격 책정 로직 정의.

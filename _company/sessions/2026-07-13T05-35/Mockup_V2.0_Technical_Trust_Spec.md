# 🎨 Mockup V2.0: 기술적 신뢰 증명 모듈 상세 디자인 스펙 (Final)

## 🎯 목표
개발팀의 QA 결과를 시각적으로 승화하여, 사용자가 AI 진단 시스템을 '과학적이고 객관적인 측정 도구'로 인식하도록 인터랙티브 경험 완성.

## ✨ 적용 원칙
1. **Pain $\rightarrow$ Proof $\rightarrow$ Gain:** Pain(기술적 불안정) $\rightarrow$ Proof(데이터 증명) $\rightarrow$ Gain(개인화된 성장 기회).
2. **신뢰도 최우선:** Dark Blue 배경과 구조적인 데이터 시각화로 전문성 확보.

## 🖥️ 섹션별 스펙: 기술적 신뢰 증명 모듈 (Technical Trust Module)
### 1. 레이아웃 및 컨테이너
*   **배경:** `#0A2463` (Dark Blue - 신뢰/전문성).
*   **제목:** Montserrat Bold, White (`#FFFFFF`). 예: "당신의 잠재력, 객관적인 수치로 증명되다."

### 2. KPI 데이터 위젯 (Core Component)
*   **구조:** 가로 배열된 3~4개의 독립적 카드 컴포넌트.
*   **카드 배경:** `#152A6B` (Dark Blue의 약간 밝은 톤).
*   **핵심 수치 표시 (The Number):**
    *   값: `[숫자]` / 단위: `[단위]`
    *   색상: `#FFD700` (Accent Yellow - 기회/강조).
    *   폰트: Montserrat Bold, 48pt 이상.
*   **변화 추이 시각화:** 작은 라인 차트 삽입.
    *   라인 색상: 성장(Green 계열), 위험/개선 영역(Yellow).

### 3. 인터랙션 스펙 (UX)
1. **Initial Load:** 모든 요소가 부드럽게 나타나며, Yellow 강조 수치만 미세하게 '광원 효과'를 주어 시선을 즉시 집중시킨다.
2. **Hover Action:** 사용자가 카드를 호버하면, 카드 배경이 약간 밝아지면서 아래의 캡션 영역(`[진단 지표 설명]`)이 부드럽게 펼쳐진다(Slide Down Animation). 이 설명은 해당 수치가 왜 중요한지 과학적 근거를 제시해야 한다.

### 4. 최종 CTA 버튼
*   **위치:** 모듈 하단 중앙.
*   **텍스트:** "AI 분석 기반, 개인화된 성장 로드맵 시작하기"
*   **배경:** `#FFD700` (Accent Yellow).
*   **효과:** 클릭 가능한 영역임을 강조하는 Box Shadow 효과와 마우스 오버 시 밝기가 높아지는 애니메이션 적용.

### ✅ ✨ 최우선 핵심 작업: ROI 예측 워크숍 데모 환경 완성 (MVP 런칭 준비)

현재 가장 중요한 목표는 논리적 설계를 넘어, **'실제로 고객에게 보여줄 매끄러운 판매 경험(Sales Experience)'**을 하나의 패키지로 만드는 것입니다. [근거: 영숙 검증된 지식 / 지난 의사결정 로그]

이를 위해 다음 3가지 핵심 산출물을 동시에 진행해야 합니다.

#### 🧑‍💻 1. 코다리 (Developer) - 기술적 기반 완성
*   **역할:** 시연에 필요한 **'Mock API 엔진'의 최종 안정화 및 인터페이스 구축**.
*   **구체적 작업:** 현빈이 제시하는 핵심 반론 질문 5가지 케이스를 입력했을 때, 백엔드가 즉시 ROI 지표(가상 데이터)를 계산하고 이를 프론트엔드에 전달할 수 있는 **최종 테스트 스크립트와 로직**을 완성해야 합니다.
*   **산출물:** `demo_engine_final.py` (테스트 가능 코드), API 통합 결과 보고서.

#### 💼 2. 현빈 (Business) - 시나리오 및 검증 기준 확정
*   **역할:** 워크숍의 **'스토리보드와 성공 측정 기준(KPI)'을 최종 확정**.
*   **구체적 작업:** 실제 미팅에서 가장 효과적인 '반론 질문 5가지 목록'과, 각 반론에 대한 명확한 데이터 기반 대응 스크립트 및 예상 결과값 범위를 **매우 상세하게** 정의해야 합니다. (스크립트는 대본 수준이어야 함).
*   **산출물:** `final_sales_script_v1.0.docx` (대화형 세일즈 구조), KPI 검증 시나리오 매트릭스.

#### 🎨 3. Designer (디자이너) - 사용자 경험(UX) 통합 및 시각화
*   **역할:** 모든 데이터를 담을 **'인터랙티브 프레젠테이션 마스터 파일' 제작**.
*   **구체적 작업:** 코다리의 Mock API 출력 데이터와 현빈의 스토리보드를 기반으로, 단순 슬라이드가 아닌 '실시간으로 변화하는 지표'를 보여줄 수 있는 인터랙티브 템플릿(예: Figma/Keynote)을 만듭니다.
*   **산출물:** `demo_master_template.fig` (반응형 프레젠테이션 파일).

### 🎯 최우선 단일 작업: 최소 기능 PoC 제작 (PoC Build)
**목표:** 학원 운영자(잠재 고객)가 우리의 진단 시스템을 **'간접적으로 체험'**하고, Pain Point를 명확히 인식하는 웹 페이지 또는 시뮬레이션 결과물을 빠르게 완성합니다.

#### 🧑‍💻 에이전트별 역할 분담 및 액션 플랜 (1~2명)

**1. 코다리 (Developer) - 기술적 최소화 담당:**
*   **작업 내용:** MVP의 가장 핵심적인 로직인 '진단 데이터 입력 $\rightarrow$ 진단 결과 출력'만 구현합니다. 다른 복잡한 기능(회원가입, 결제 연동 등)은 제외하고, **데이터 시뮬레이션에 최적화된 API 엔드포인트 스켈레톤**을 구축하는 데 집중합니다. [근거: Self-RAG]
*   **구체 목표:** '성능 지표'와 '감정 상태/여정 단계'를 입력받아, **가장 충격적인 Pain Point 1가지**를 즉시 계산하여 출력하는 기능만 작동하도록 합니다. (예: "현재 시스템은 이 부분에서 감성적 점수가 크게 하락하고 있습니다.")
*   **산출물:** PoC 테스트용 백엔드 스켈레톤 API 엔드포인트 및 기술 명세서 초안 업데이트.

**2. Designer - 사용자 경험 최적화 담당:**
*   **작업 내용:** 코다리가 만든 최소 기능 PoC를 감성적으로 포장하는 '가짜지만 완벽한' 인터페이스(Mockup)를 제작합니다. [근거: Self-RAG]
*   **구체 목표:** 실제 사용자 경험에 초점을 맞춥니다. ① 진단 테스트 페이지, ② 충격적인 Pain Point 리포트 페이지 2종의 **고해상도 Mockup (Figma 또는 Sketch 파일)**을 제작합니다. 이때 '좌절에서 승리로 변곡점'이라는 서사 구조를 시각적으로 강조해야 합니다.
*   **산출물:** PoC 전용 디자인 시스템(Mockups) 및 사용자 플로우맵 업데이트.

### 2. P0 기능 구현을 위한 기술 로드맵 (3단계 접근법)

기술적 안정성 확보를 최우선 목표로 설정하고, 이를 기반으로 영상 제작 파이프라인의 핵심 기능을 단계적으로 구현하는 로드맵을 제시합니다.

#### **Phase 1: 안정화 및 데이터 무결성 확보 (최우선)**
*   **목표:** `UnboundLocalError` 등 핵심 오류를 완전히 제거하고, 모든 학습 데이터를 안정적으로 저장/불러오는 시스템을 구축합니다.
*   **주요 작업:**
    1.  **DB 스키마 정제:** P0 기능에 필요한 최소한의 데이터(학습 기록, 피드백 이력)만을 포함하는 핵심 테이블 구조를 확정하고 DB 스키마를 수정합니다. (코다리 주도)
    2.  **핵심 로직 리팩토링:** 보컬 분석 및 피드백 계산 로직 전체를 재검토하여 오류 발생 지점을 제거하고, 입력 데이터가 출력 결과에 미치는 영향을 완벽히 추적하도록 수정합니다. (개발자 주도)
*   **산출물 목표:** 안정화된 핵심 API 엔드포인트 및 데이터베이스 구조 정의서.

#### **Phase 2: P0 기능 구현 및 통합 검증**
*   **목표:** Phase 1에서 확보한 안정성을 바탕으로, 영상 제작에 직접적으로 필요한 최소 기능(예: 기본 레벨 측정, 학습 진도 시각화)을 구현합니다.
*   **주요 작업:**
    1.  **핵심 기능 API 개발:** 최종 스타일 가이드(V2.0)와 연동하여, 사용자가 원하는 결과물을 제공하는 핵심 로직을 API 형태로 구현합니다. (Designer/Developer 협업)
    2.  **통합 검증 워크플로우 실행:** 새로운 P0 기능이 기존 시스템에 미치는 영향을 확인하기 위해 `qa_automation_runner`를 재실행하여, 안정성 검증 루프를 구축합니다.
*   **산출물 목표:** 영상 제작 파이프라인을 구동할 수 있는 최소 기능 구현 완료.

#### **Phase 3: 확장 및 최적화 (영상 콘텐츠 연계)**
*   **목표:** P0 기능이 안정적으로 작동함을 확인한 후, 구독자 증가에 기여하는 부가적인 시각화 및 사용자 경험 개선 기능을 추가합니다.
*   **주요 작업:**
    1.  **성장 지표 고도화:** 단순 점수 나열을 넘어, '노력의 가시화'를 극대화하는 그래프 및 레벨업 시스템(Visualization)을 완성하여 학부모/사용자의 동기 부여를 강화합니다. (Researcher/Designer 주도)
    2.  **콘텐츠 연계 자동화:** 영상 제작에 필요한 데이터 포인트를 자동으로 추출하고 리포트 형태로 생성하는 파이프라인을 자동화합니다.
*   **산출물 목표:** 최종 사용자에게 '성장의 증명'을 제공하는 완성형 학습 리포트 시스템.

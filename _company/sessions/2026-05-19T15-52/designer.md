## 🎬 유튜브 썸네일 디자인 시안: Concept 2 최종 실행 가이드

**[목표]** Pain $\rightarrow$ Gain 프레임워크를 극대화하여 잠재 고객의 즉각적인 클릭과 신뢰를 유도하는 고효율 썸네일 제작.

### 1. 브랜드 시스템 적용 (Color & Typography)

| 요소 | 설정 값 | 코드/명칭 | 적용 목적 |
| :--- | :--- | :--- | :--- |
| **Primary Color** (신뢰/배경) | Dark Blue | `#0A2463` | 메인 배경, 신뢰감 조성 |
| **Accent Color** (행동 유도/기회) | Accent Yellow | `#FFD700` | 핵심 데이터(Gap Score), CTA 버튼 강조 |
| **Background Color** (본문 영역) | Neutral Grey | `#F5F5F5` | 텍스트 대비 및 정보 명확성 확보 |
| **Title Typography** (강렬함) | Montserrat Bold | - | 메인 헤드라인 (Pain/Gain) 강조 |
| **Body Typography** (가독성) | Noto Sans KR | - | 상세 데이터 및 보조 설명 텍스트 |

### 2. 레이아웃 및 구성 (Visual Layout Specification)

**[레이아웃 유형]** 대비(Contrast) 극대화형, 좌측/우측 분할 구조

| 영역 | 비율/좌표 | 내용 및 디자인 지침 | 적용 색상 |
| :--- | :--- | :--- | :--- |
| **A. 배경 (Left Side)** | 약 40% | **Pain Point 시각화:** 현재의 고통이나 좌절감을 상징하는 이미지 또는 심볼 배치. (예: 어두운 톤, 불안한 표정 등) | `#0A2463` (Dark Blue) |
| **B. 핵심 메시지/데이터 (Center)** | 약 60% | **Gap Score 시각화:** 가장 중요한 데이터(Pain $\rightarrow$ Gain)를 중심으로 배치. `Pain`과 `Gain`을 명확히 구분하여 대비 강조. | `#F5F5F5` (Neutral Grey) 배경 위에 텍스트 배치 |
| **C. CTA 영역 (Right Side)** | 약 10% | **Call to Action:** '승리', '변곡점' 등의 키워드와 명확한 행동 유도 문구 삽입. 강렬하게 강조. | `#FFD700` (Accent Yellow) 배경 또는 텍스트 |

### 3. 텍스트 배치 및 내용 구성 (Content Specification)

**[Title - 상단/중앙, Montserrat Bold]**
*   **메인 후크:** "이대로 하면 당신은 **[Pain Point 명확화]**에 갇힙니다."
*   **보조 메시지:** "**[Gain Point 명확화]**로 전환하는 단 하나의 방법" (Accent Yellow 강조)

**[Data Visualization - 중앙, Noto Sans KR]**
*   **핵심 지표 표시:** `Gap Score: [XX]%` (가장 큰 폰트 크기, Accent Yellow로 강조)
*   **구체적 설명:** "현재 상태의 손실 vs 목표 달성 시 예상되는 이득" 형태로 데이터 차이를 극명하게 보여줌.

**[Call to Action - 우측 하단]**
*   **CTA 버튼 문구:** "**지금, 변곡점을 경험하세요!**" 또는 "**승리 로드맵 확인하기**"
*   **스타일:** Accent Yellow 배경에 Dark Blue 텍스트로 처리하여 눈에 띄게 만듭니다.

### 4. 최종 디자인 사양 요약 (Final Specification Summary)

*   **전체 비율:** 16:9 (유튜브 표준)
*   **핵심 비주얼 컨셉:** 어둠(Pain)에서 빛(Gain)으로의 명확한 시각적 전환.
*   **색상 활용:** Dark Blue는 신뢰감 있는 기반, Accent Yellow는 행동을 촉구하는 에너지로 사용.
*   **폰트 계층:** Montserrat (헤드라인) > Noto Sans KR (데이터/본문).

# Episode 3 Final Design Specification - Gap Score Visualization

## 🎨 Brand Identity Application
*   **Primary Color (Trust):** Dark Blue (`#0A2463`)
*   **Accent Color (Action/Gain):** Accent Yellow (`#FFD700`)
*   **Background/Data:** Neutral Grey (`#F5F5F5`)

## 🎬 Thumbnail Concept: Concept B Focus
*   **Layout:** Top third for Pain Hook, Middle half for Gap Score Visualization, Bottom for Solution CTA.
*   **Visual Style:** High contrast, dynamic flow visualization (Pain $\rightarrow$ Gain).

## 📊 Infographic Mockup: Gap Score Visualization Guide
1.  **Header (Pain):** "🚨 당신의 성장은 어디로 향하고 있습니까?" (Montserrat Bold, Yellow)
2.  **Core Visual (Gap Score):** A large circular/gauge visualization. Use Dark Blue for the background/context and Yellow to highlight the critical Gap percentage area.
3.  **Flow Diagram:** Use arrows to explicitly link: **Diagnosis $\rightarrow$ Solution $\rightarrow$ Gain**.
4.  **CTA Block:** Prominent button in Accent Yellow urging immediate action on the 'Solution' step.

## ✍️ Typography Rules
*   **Title (Pain/Gain):** Montserrat Bold, use Yellow for critical words.
*   **Body (Data/Labels):** Noto Sans KR, use Dark Blue for primary data points.

## ✅ Implementation Notes
*   **Focus:** Emotional impact via high contrast between Dark Blue (Trust) and Yellow (Urgency).
*   **Goal:** Make the Gap Score the single most arresting visual element on screen.

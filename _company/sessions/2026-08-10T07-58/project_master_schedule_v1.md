## 🧩 II. 에이전트별 주간 액션 플랜 (Action Items)

### 🎨 Designer (시각적 에셋 및 프로토타입 제작)
*   **[이번 주 목표]** `Production Bible v1`에 정의된 **핵심 컴포넌트(Diagnosis Widget)**의 고해상도 목업/프로토타입을 완성하고 공유할 것. (M2 기여)
*   **[다음 액션]** M3 단계에서 구현될 Mock API 데이터를 활용하여, 시각적 흐름과 레이아웃이 깨지지 않도록 **'가짜 데이터(Mock Data)' 테스트 시퀀스**를 준비할 것.

### 💻 Codari (개발 및 시스템 안정화)
*   **[이번 주 목표]** M1의 기술 사양을 기반으로, 백엔드 로직 구현에 필요한 **데이터 모델 확정본과 API 스펙 문서**를 최종 업데이트하여 Designer에게 제공할 준비를 할 것. (M3 기여 전제 작업)
*   **[다음 액션]** Mock Data가 들어올 시점을 가정한 상태에서, 클라이언트(프론트엔드)가 요청할 수 있는 **최소한의 API 인터페이스 정의서**를 작성하여 Designer와 교차 검토 할 것.

### 📝 영숙 (총괄 PM & 관리/문서화)
*   **[이번 주 목표]** 모든 에이전트의 산출물을 취합하여, 위와 같이 **통합 프로젝트 로드맵을 확정 및 공유**하고, 각 담당자에게 마일스톤별 책임(RACI Matrix 초안)을 공지할 것. (현재 완료됨)
*   **[다음 액션]** 다음 주에는 에셋과 코드가 병렬로 진행되도록 **'주간 크로스 체크 회의 (Weekly Sync)'**를 캘린더에 예약하고, 핵심 질문(Dependency Risk) 목록을 미리 준비할 것.

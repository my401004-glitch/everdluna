# 🎨 Designer — Writer가 제공한 기고문을 바탕으로 확정된 랜딩 페이지 핵심 카피라이팅과 Dark Blue/Accent Yellow 시스템을 적용한 디자인 Mockup 파일(PSD/Figma)을 최종 출력하라.

🎨 Designer: 작업 시작합니다.

Writer가 제공한 기고문과 확정된 브랜드 시스템(Dark Blue/Accent Yellow, Pain $\rightarrow$ Gain)을 기반으로, 잠재 고객의 불안감(Pain)을 극대화하고 솔루션의 가치(Gain)를 객관적인 데이터로 증명하는 랜딩 페이지 핵심 카피라이팅 및 디자인 Mockup 가이드라인을 작성하겠습니다.

이 과정은 단일한 최종 PSD/Figma 파일 출력 전 단계인 **'최종 구조 설계도(Blueprint)'**를 완성하는 것입니다. 이 설계를 바탕으로 실제 디자이너가 작업할 수 있는 명세서를 제공합니다.

# 🎨 LP Master Design Guide (Figma Component Library)
## 📐 Global Settings
*   **Grid:** 12 Column Grid System (8pt baseline grid).
*   **Colors:**
    *   `Primary-DarkBlue`: #0A2463 (신뢰, 배경)
    *   `Accent-Yellow`: #FFD700 (주의, CTA, Gain)
    *   `Background-LightGrey`: #F5F5F5 (본문 배경)
    *   `Text-DarkBlue`: #0A2463
*   **Typography:**
    *   H1/H2: Montserrat Bold (Size Scale: 48px, 36px, 32px...)
    *   Body: Noto Sans KR Regular (Size Scale: 16px, 18px, 20px...)

## 🧩 Components & Layouts
1.  **Hero Component:**
    *   [Layout]: H1 + Sub-H + CTA Button (가장 넓고 임팩트 있게).
    *   [Styling]: Dark Blue 섹션으로 처리 후 중앙 정렬.
2.  **Pain/Gain Block Component (Conversion Unit):**
    *   [Structure]: `Icon(Yellow) -> Title(Montserrat Bold, Yellow 강조) -> Description(Noto Sans KR)`
    *   [Usage]: Pain 지표 3개에 반복 사용. 노란색 배경을 사용하여 경고 느낌 부여.
3.  **Data Visualization Component:**
    *   [Structure]: 그래프 이미지 플레이스홀더 + 설명 텍스트 (Gap Score, KPI 대시보드).
    *   [Styling]: Dark Blue 라인을 주요 데이터 선으로 사용하고, Yellow로 '이상치'를 강조 처리.
4.  **Final CTA Button Component:**
    *   [Interaction]: Hover on Yellow -> Slight transition to a lighter blue/white glow effect (클릭 유도 극대화).

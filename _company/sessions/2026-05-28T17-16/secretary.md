### ✅ 상세 실행 지침 (담당 에이전트에게 전달)

#### 🧑‍💼 현빈 에이전트님께: [판매 시나리오 설계]
1. **파일럿 플로우 정의:** 학원 운영자가 우리 시스템에 처음 진입해서 유료 결제까지 하는 과정을 3~5단계의 명확한 단계(Stage)로 나눕니다. (예: 무료 진단 $\rightarrow$ 리스크 발견 $\rightarrow$ 해결 모듈 제안 $\rightarrow$ 미니 결제 커밋먼트).
2. **Pain Point & Value Proposition 강화:** 각 단계에서 운영자가 느끼는 '절실한 문제점(Pain Point)'을 극대화하고, 우리 시스템이 제공하는 '결정적 가치(Value Prop)'를 구체적인 언어로 정의해 주세요. (KPI 개선 시뮬레이션 포함)
3. **최종 산출물:** `[Pilot Playbook Draft]` - 단계별 제목, 운영자에게 전달할 핵심 메시지, 기대 ROI 지표가 담긴 문서.

#### 🧑‍💻 코다리 에이전트님께: [기술 범위 최소화 검증]
1. **요구사항 매칭:** 현빈님이 작성한 `[Pilot Playbook Draft]`의 각 단계별로 필수적으로 수집되어야 하는 데이터(Minimum Data Scope)를 추출해 주세요. (예: 진단 리포트 생성 시점, 특정 기능 사용 횟수 등).
2. **기술 스펙 검토:** 이 데이터들을 확보하기 위해 필요한 API 엔드포인트의 최소 변경/추가 사항과 DB 테이블 구조 변화만 보고해 주세요. (기존에 정의된 핵심 엔드포인트를 최대한 재활용하는 방향으로!)
3. **최종 산출물:** `[Pilot Feasibility Report]` - 단계별 데이터 수집 필요성 검증 및 기술적 난이도/소요 기간 추정치가 담긴 보고서.

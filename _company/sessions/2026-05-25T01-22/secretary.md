| 담당 에이전트 | 역할 (책임) | 기대 산출물 | 목표 달성 기여도 |

| **🎨 Designer (Lead)** | 전체 사용자 여정(UX Flow)을 시각적으로 모델링하고, 각 화면의 인터랙션 포인트를 정의합니다. | 최종 와이어프레임 기반의 **User Journey Map** 및 필수 UI/UX 플로우 차트. | 🟢 핵심 리드: 모든 요소가 연결되는 설계도 역할. |
| **💻 Codari (Validation)** | 디자인된 흐름을 기술적으로 검토하여, 각 단계에서 필요한 API 호출 및 데이터 저장(DB) 로직이 누락되거나 충돌하는 지점을 찾아냅니다. | User Flow에 대한 **기술적 실현 가능성 보고서** (API 엔드포인트/데이터 필요 필드 명시). | 🟡 기술 검증: 설계가 실제로 돌아갈 수 있는지 보장. |

### ✅ 액션 아이템 요약 (Task List)
1.  **Designer:** 진단 리포트 화면에서 CTA(Call to Action)로 이어지는 가장 이상적인 3가지 경로를 시각화하여 초안을 작성합니다. (예: 무료 상담 예약 $\rightarrow$ 유료 모듈 구매 $\rightarrow$ 커뮤니티 활동 등)
2.  **Codari:** Designer가 제시한 각 플로우 단계별로, 필요한 DB 필드와 API 요청/응답 구조를 **표 형태로 정리**하여 기술 요구사항을 확정합니다.
3.  **Writer/Leo:** 이 3가지 경로 중 가장 '구매 전환율(Conversion)'이 높다고 예상되는 단 하나의 메인 시나리오를 결정하고, 해당 시나리오에 맞는 감성적 가이드 문구를 최종적으로 다듬습니다.

## 📄 랜딩 페이지 디자인 가이드라인 (Visual System Application)

### 1. 브랜드 비주얼 시스템 요약 (재확인)

*   **핵심 테마:** 좌절에서 승리로의 변곡점 (Pain to Victory Arc).
*   **색상 팔레트:**
    *   **Primary (승리/신뢰):** Deep Navy / Dark Charcoal (깊이감, 전문성)
    *   **Secondary (에너지/변화):** Electric Gold / Bright Teal (대비, 희망, 기술적 신뢰)
    *   **Accent (경고/문제):** Muted Red / Burnt Orange (위기감 조성, 문제 제기)
*   **타이포그래피 컨셉:**
    *   **Headline (H1/H2):** 산세리프 계열의 굵고 구조적인 폰트 (예: Montserrat Bold 또는 비슷한 기하학적 폰트). 기술적 객관성을 강조.
    *   **Body Text:** 가독성이 높은 세리프 또는 깔끔한 산세리프 (예: Noto Sans, Pretendard). 감성적 위로를 제공.

### 2. 섹션별 와이어프레임 및 레이아웃 목업

#### [섹션 1] 히어로 섹션 (Hero Section): 시선 장악 & 위기감 조성 (The Hook)
**목표:** 즉각적인 문제 인식과 해결에 대한 갈망을 동시에 유발.
**레이아웃 컨셉:** 대담한 대비와 강력한 질문 제시.

| 요소 | 레이아웃/시각적 지침 | 색상 적용 | 폰트 스타일 |
| :--- | :--- | :--- | :--- |
| **배경** | 다크 모드 (Deep Navy 또는 Charcoal) 배경에 은은한 노이즈/그라데이션 효과. | Primary Color (Navy) 기반 | - |
| **H1 (헤드라인)** | 중앙 정렬, 화면 상단 20% 지점에 배치. 매우 크고 굵게 강조. | Electric Gold 또는 Bright Teal (강조색) | Very Bold, 기하학적 산세리프 |
| **서브 헤드라인 (H2)** | H1 바로 아래에 배치. H1보다 작지만 명확하게 대비되도록 처리. | White 또는 Light Gray | Medium Weight Sans-serif |
| **CTA 버튼** | 화면 중앙 하단에 배치. 가장 눈에 띄는 색상(Accent Color)을 사용하여 클릭 유도. 박스 형태보다는 강력한 버튼 디자인. | Accent Color (Teal/Gold) 배경, 대비되는 텍스트 | Bold |
| **시각 요소** | 배경 위에 추상적인 파형 또는 데이터 그래프의 미니멀한 패턴 오버레이. | Subtle Glow 효과 적용 | - |

#### [섹션 2] 문제 증폭 섹션 (Pain Amplification): 공감 및 의심 주입
**목표:** 방문자의 현재 고통(Pain Point)에 깊이 공감하며, 기존 방식의 한계를 지적.
**레이아웃 컨셉:** 정보 블록을 활용하여 구조적인 문제를 시각화.

| 요소 | 레이아웃/시각적 지침 | 색상 적용 | 폰트 스타일 |
| :--- | :--- | :--- | :--- |
| **섹션 제목 (H3)** | 섹션 시작 시, 질문 형식으로 배치하여 즉각적인 몰입 유도. | Accent Color | Bold Sans-serif |
| **문제 블록 (3가지)** | 3개의 독립된 카드 또는 블록 형태로 구성. 각 블록은 명확한 아이콘과 함께 '함정'을 상징하는 시각적 요소(예: 깨진 화살표, 경고 표시)를 사용. | 배경은 Dark Gray, 강조 포인트는 Muted Red/Orange 사용. | Body Text (가독성 최우선) |
| **흐름** | 좌측에 문제점 설명, 우측에 '해결책의 필요성'을 암시하는 작은 아이콘 배치. | - | - |

#### [섹션 3] 해결책 제시 섹션 (Solution Mechanism): AI 시스템 소개
**목표:** 우리 시스템(AI 진단)이 이 모든 문제를 객관적으로 해결할 수 있음을 논리적으로 증명.
**레이아웃 컨셉:** 기술적 신뢰도와 데이터 흐름을 시각화.

| 요소 | 레이아웃/시각적 지침 | 색상 적용 | 폰트 스타일 |
| :--- | :--- | :--- | :--- |
| **메인 헤드** | "AI가 증명하는 보컬 성장 로드맵" 등 시스템의 핵심 가치를 명확히 제시. | Primary Color (Navy) 배경, Gold 강조선 | Bold Sans-serif |
| **시스템 단계 시각화** | **Growth → Engagement → Monetization**의 3단계 흐름을 수평 또는 순환하는 다이어그램 형태로 배치. 각 단계는 화살표로 연결되어 다음 단계로 나아감을 표현. | 단계별 색상 변화 (예: Growth=Teal, Engagement=Gold, Monetization=Navy) | 숫자와 핵심 키워드에 집중 |
| **AI 모듈 강조** | AI 분석 엔진의 핵심 로직을 시각적으로 표현하기 위해 복잡한 데이터 흐름을 추상화된 네트워크(Node & Line) 형태로 배치. | Teal/Gold 노드를 중심으로 연결선 사용 | - |

#### [섹션 4] 행동 유도 섹션 (Final CTA): 신뢰 구축 및 전환
**목표:** 최종적으로 무료 진단 테스트 참여를 다시 한번 설득하고, 시스템에 대한 신뢰를 확고히 함.
**레이아웃 컨셉:** 명확한 증거 제시와 안전한 선택 제공.

| 요소 | 레이아웃/시각적 지침 | 색상 적용 | 폰트 스타일 |
| :--- | :--- | :--- | :--- |
| **신뢰 구축 (Social Proof)** | 실제 데이터 예시(가상의 Gap Score 변화 그래프) 또는 짧은 후기 인용구를 배치. 시각적인 증거를 극대화. | 배경을 깨끗한 White로 전환하여 신뢰도 향상. | 가독성 높은 세리프/산세리프 혼합 |
| **최종 CTA** | 가장 크고 강력하게 재배치. '무료 진단 테스트' 버튼은 다른 모든 요소에서 분리되어 시각적 무게 중심을 가져야 함. | Accent Color (가장 강한 대비) | Very Bold, 중앙 정렬 |
| **푸터** | 최소화된 링크와 저작권 표시. 시스템의 전문성을 유지하기 위해 미니멀하게 처리. | Primary Color | Small Font Size |

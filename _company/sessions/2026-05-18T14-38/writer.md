## 🌐 웹페이지 콘텐츠 스토리라인 및 카피라이팅 초안
*(톤앤매너: 객관적, 전문가적, 하지만 위로와 가능성을 제시하는 '도전적인 친절함')*

### [섹션 1] 히어로 섹션 (Hero Section): 시선 장악 & 위기감 조성 (The Hook)
**목표:** 방문자가 "맞아. 나에게 필요한 게 이거였어."라고 느끼게 한다.
**핵심 서사 단계:** 구조적 문제 제기 (Pain Point 극대화).

| 요소 | 내용 스토리라인/카피라이팅 초안 | 목적 및 기대 효과 |
| :--- | :--- | :--- |
| **헤드라인 (H1)** | **"노래, 감성만으론 부족합니다. 당신의 발성은 객관적인 '수치'로 증명되어야 합니다."** *(혹은: 🎤 "왜 아무리 연습해도 합격 점수가 안 나올까요? 답은 기술적 'Gap Score'에 있습니다.")* | 즉각적인 질문과 전문 용어(Gap Score, 수치)를 사용해 트래픽의 흥미 유발. (근거: Writer 검증된 지식)<br>**[강조]** 감성만으로는 안 된다는 경고로 의구심 조성. |
| **서브 헤드라인 (H2)** | "추상적인 '복식 호흡', '감정 이입' 같은 팁은 이제 그만. AI가 진단하는 과학적 보컬 성장 로드맵으로, 불합격의 벽을 넘는 가장 확실한 길." | 기존 교육 방식(불확실성)과 우리 시스템(객관성/과학)을 대비시켜 우월성을 각인. (근거: 지난 의사결정 로그) |
| **CTA 버튼** | ➡️ **[무료 진단 테스트로 내 Gap Score 확인하기]** (가장 크고 눈에 잘 띄게 배치) | 페이지의 최종 목표이자 전환점(Conversion Point). 즉각적인 행동 유도. |

### [섹션 2] 문제 증폭 섹션 (Pain Amplification): 공감 및 의심 주입
**목표:** 방문자가 자신의 약점을 스스로 깨닫고, 기존 방식에 대한 불신을 갖게 한다.
**핵심 서사 단계:** 신화 파괴 (Myth Busting) / 좌절 경험 제시.

| 요소 | 내용 스토리라인/카피라이팅 초안 | KPI 연관성 |
| :--- | :--- | :--- |
| **제목 (H3)** | **"당신이 지금까지 알고 있던 발성법의 함정 3가지."** | - |
| **내용 1: '감성의 함정'** | "가슴으로 부른다? 좋아요. 하지만 그 감성이 기술적 안정감(주파수, 공명)을 받쳐주지 못하면 불안정한 소리가 될 뿐입니다. [근거: Writer 검증된 지식]" | **기술/AI 필요성 강조.** (Gap Score의 근거) |
| **내용 2: '추상적인 조언'** | "‘목을 열어라’, ‘호흡을 깊게 하라’... 좋은 말이지만, 이게 정확히 몇 Hz 단위로 부족한 건지 아시나요? 객관적 증거가 없으면 공허합니다." | **객관성/데이터 필요성 강조.** (AI 진단 시스템의 근거) |
| **내용 3: '진행 부재'** | "시간이 지나도 여전히 같은 부분에서 벽에 막히는 느낌. 당신은 지금 '노래를 부르는 법'만 배우고 있는 게 아니라, 그냥 '소리를 내는 방법'만 연습하고 있을지 모릅니다." | **성장 서사/문제 지속 강조.** (Pain Point 극대화) |

### [섹션 3] 솔루션 제시 섹션 (Solution Presentation): 시스템 소개 및 기대감 증폭
**목표:** 우리 프로그램이 유일한 해답임을 확신시키고, '시스템'의 존재를 각인시킨다.
**핵심 서사 단계:** 시스템 제시 (AI Solution).

| 요소 | 내용 스토리라인/카피라이팅 초안 | KPI 연관성 |
| :--- | :--- | :--- |
| **제목 (H3)** | **"저희가 제안하는, '좌절에서 승리로의 변곡점'을 만드는 AI 하이브리드 시스템."** | - |
| **핵심 원리 설명 (도표 활용 권장)** | 🎵 **[AI 객관 진단]** $\to$ 📊 **[데이터 분석 및 Gap Score 산출]** $\to$ 🧑‍🏫 **[전문 코치 피드백(감성 해석)]** $\to$ ✨ **[개인 맞춤 커리큘럼 완성]** | '기술적 신뢰도'를 최우선으로 제시하는 구조. (근거: Writer 검증된 지식) |
| **시스템의 강점 3가지** | 1. **객관성:** 주파수, 공명대 등 수치로 문제 정의.<br>2. **개인화:** 나에게 필요한 모듈만 집중 학습하는 맞춤 설계.<br>3. **연속성:** 진단부터 최종 목표까지 '성장 서사'를 따라가게 합니다. | **Growth & Engagement** (지속적인 참여 유도) |

### [섹션 4] 작동 원리 섹션 (How It Works): KPI 기반의 기능 설명
**목표:** 우리 플랫폼이 구체적으로 어떻게 사용자 경험(UX)을 제공하는지 보여준다.
**핵심 서사 단계:** 데이터 증명 및 시스템 상세화.

| 요소 | 내용 스토리라인/카피라이팅 초안 | KPI 연관성 |
| :--- | :--- | :--- |
| **제목 (H3)** | **"AI가 당신의 목소리를 해부하는 4단계 과정."** | - |
| **1. 진단 단계 (Diagnosis)** | *[서비스 기능]*: 초기 녹음 파일을 통한 'Gap Score' 측정. 음정 편차(Hz), 공명 주파수 불균형, 호흡 지지력 등 수치화된 보고서 제공. | **Growth** (성장 과정의 시작점) |
| **2. 학습 단계 (Curriculum)** | *[서비스 기능]*: 진단 결과에 기반하여 '기술적 약점'만을 집중 공략하는 모듈 할당. (예: 430~450Hz 공명대 강화 트레이닝) | **Engagement** (지속적인 참여 동기 부여) |
| **3. 피드백 단계 (Coaching)** | *[서비스 기능]*: AI가 제공한 객관적 데이터를 바탕으로, 인간 코치가 '어떻게' 적용할지 감성적으로 해석하고 조언하는 1:1 세션 제공. | **신뢰 구축/경험 가치** (하이브리드 모델 강조) |
| **4. 목표 달성 단계 (Mastery)** | *[서비스 기능]*: 체계적인 성장 서사(Module 0 $\to$ Module N)를 거쳐, 이전 대비 얼마나 '수치적으로' 향상되었는지 데이터로 증명합니다. | **Monetization** (최종 성취/유료 결제 동기 부여) |

### [섹션 5] 신뢰 구축 섹션 (Trust & Proof): 성공 사례 제시
**목표:** "나도 저렇게 될 수 있겠구나."라는 확신을 심어준다.
**핵심 서사 단계:** 데이터 증명 (Proof).

| 요소 | 내용 스토리라인/카피라이팅 초안 | KPI 연관성 |
| :--- | :--- | :--- |
| **제목 (H3)** | **"데이터가 말해주는 변화: Before & After."** | - |
| **콘텐츠 구성** | **[비주얼 자료 필수]**: 가상의 학생 사례를 전후 비교하는 그래프나 표. (예시) <br> *학생 A:* 초기 음정 편차 평균 12Hz $\to$ 3개월 후 평균 3Hz.<br>*핵심 코멘트:* "그냥 '감성적으로 부른다'가 아니라, 주파수를 과학적으로 교정한 결과입니다." | **신뢰도 극대화.** (구체적인 데이터로 확신 부여) |
| **후기/사회적 증거** | "이전 학원에서는 막연한 운동만 시켰는데, 여기 와서야 비로소 제 발성에 '기준'이라는 걸 알았습니다." - 실제 사용자 후기(가상). | **공감 및 신뢰.** |

### [섹션 6] 최종 CTA 섹션 (Final Call to Action): 결단 유도
**목표:** 망설이는 방문자를 붙잡아, 가장 낮은 장벽의 행동(무료 진단)을 하도록 만든다.
**핵심 서사 단계:** 다음 액션 제시 (CTA).

| 요소 | 내용 스토리라인/카피라이팅 초안 | CTA 문구 전략 |
| :--- | :--- | :--- |
| **제목 (H3)** | **"막연한 연습에 시간 낭비하지 마세요. 가장 정확하고 빠른 길을 보여드리겠습니다."** | 위기감 재점화 + 해결책 제시. |
| **본문 카피** | "현재 본인의 실력과 부족한 점이 어디인지, 단지 '느낌'이나 '직관'에 맡겨서는 안 됩니다. AI가 수치로 진단해주는 [Gap Score]를 확인하는 것이 첫 번째 단계입니다." | 무료 진단을 **필수적인 첫걸음**으로 포지셔닝. (진입 장벽 최소화) |
| **최종 CTA 버튼** | 🚀 **[✨ 5분 만에 끝내는 AI 보컬 Gap Score 무료 진단 받기]** | 행동 유발: '무료', '간편함(5분)', '결과물(Gap Score)'을 키워드로 사용. |

### 🎯 가장 가치 있는 단일 작업: 진단 리포트 MVP 구현 및 검증
(핵심 목표: 'AI가 객관적 데이터로 보여주는 충격적인 Pain Point'를 인터랙티브하게 체험하도록 만드는 것)

#### 🧑‍🎨 Designer 에이전트 (UX/UI, 서사 구조 담당)
**[최우선 액션] 진단 과정 시나리오 기반의 와이어프레임 및 플로우 차트 제작.**
*   **목표:** 단순히 예쁜 디자인을 넘어, 운영자가 '진단을 받기 전(Pain)'과 '리포트를 받고 후회하는 느낌(Gain/Shock)'까지 감정적 여정을 거치는 3단계 시나리오 기반의 인터랙티브 플로우를 설계해주세요.
*   **요구 사항:**
    1.  **사전 설문 단계 (Hooking):** 운영자의 현재 고민을 자극하는 질문과 그에 따른 초기 심리 상태(불안, 막연함 등)를 시각화합니다.
    2.  **진단 결과 페이지 (Shock Point):** 객관적 데이터가 충격적으로 부족한 지점(Pain Point)을 강조하며, 이 문제의 '비용'을 명확히 제시하는 비주얼 요소를 설계해주세요.
    3.  **솔루션 제안 단계 (Solution/CTA):** AI 솔루션을 도입했을 때 얻게 되는 미래의 성공 모습(Gain)과 구체적인 로드맵을 시각적으로 대비시켜 보여주는 구조를 정의합니다.

#### 💻 Developer 코다리 에이전트 (기술 구현, 데이터 로직 담당)
**[최우선 액션] 프로토타입의 핵심 기능에 필요한 Mock API 엔드포인트 및 기술 설계 검증.**
*   **목표:** Designer가 제시한 플로우를 실제 개발 가능한 형태로 전환하기 위해, 필수적인 백엔드 로직을 정의합니다.
*   **요구 사항:**
    1.  **Mock API 스키마 확장:** 진단 리포트의 Pain Point 데이터를 받아 처리하는 `diagnosis_score` 엔드포인트에 '감정적 취약점(Emotional Vulnerability)' 점수를 포함할 수 있도록 스키마를 업데이트합니다.
    2.  **데이터 시각화 로직 정의:** 단순한 그래프가 아닌, "A 지표가 부족하여 운영자님의 **매출 리스크**가 30% 증가했습니다"와 같이 **비즈니스 언어**로 변환되는 데이터 처리 및 표시 로직을 기술적으로 검증합니다.
    3.  **프론트엔드 인터랙션 설계:** 진단 결과를 받았을 때, 운영자가 다음 단계(예: 유료 모듈 체험)로 자연스럽게 넘어가도록 유도하는 '버튼 클릭' 등의 사용자 액션 흐름에 필요한 기술적 준비를 완료해주세요.

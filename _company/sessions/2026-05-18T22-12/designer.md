**🎯 목표:** 데이터의 객관성과 감성적 서사를 통합하여, 사용자가 **좌절(Pain Point)**에서 **승리(Achievement)**로 나아가는 성장 여정을 직관적으로 이해하고 동기 부여를 얻도록 시각화합니다.

### 1. 디자인 시스템 재확인 (UI/UX 가이드라인 적용)

| 요소 | 색상 코드 | 용도 및 의미 |
| :--- | :--- | :--- |
| **Pain Point / 좌절** | `#FF9800` (주황색 계열) | 현재 상태, 개선이 필요한 영역, 잠재적 위험 지표. |
| **Achievement / 승리** | `#4CAF50` (녹색 계열) | 달성한 성과, 긍정적인 변화, 목표 달성 구간. |
| **Primary Action** | (시스템 기본 색상 또는 강조색) | CTA 버튼, 핵심 지표 강조. |
| **Background** | `#FFFFFF` 또는 매우 밝은 회색 | 데이터 가독성을 극대화하기 위함. |

### 2. 화면 구조: 핵심 데이터 시각화 레이아웃 (Wireframe Concept)

본 화면은 크게 세 부분으로 구성되며, 사용자의 감정 변화 흐름을 따라 정보를 배치합니다.

#### **A. 상단 요약 섹션 (The Snapshot)**
*   **목표:** 사용자가 한눈에 현재 상태와 가장 중요한 성과를 파악하게 합니다.
*   **구성 요소:**
    1.  **총 성장 점수 (Overall Growth Score):** 가장 크고 눈에 띄게 표시. (예: `85% 달성`)
        *   *시각화:* 전체 여정 중 현재 위치를 나타내는 큰 진행 바(Progress Bar)를 사용하며, **달성된 부분은 `#4CAF50`**, **미달 부분은 `#FF9800`**으로 채웁니다.
    2.  **핵심 Pain Point (Current Gap):** 현재 가장 심각한 문제 영역을 강조합니다.
        *   *시각화:* 현재 가장 높은 `Gap Score`를 해당 섹션에 **`#FF9800` 배경**으로 표시하고, 그 아래에 명확한 설명(`Episode 2: 교사 역량 최적화`)을 배치합니다.

#### **B. 성장 여정 시각화 섹션 (The Journey)**
*   **목표:** 데이터 기반의 '좌절 → 해결책 제시 → 승리'의 흐름을 시간 순서대로 보여줍니다.
*   **구성 요소:** 수평 또는 수직 스크롤 가능한 카드로 구성합니다. 각 카드(Episode)는 다음 구조를 따릅니다.
    1.  **에피소드 제목:** (예: Episode 1: 진단의 시대)
    2.  **핵심 지표 시각화:** 해당 에피소드에서 측정된 핵심 성과 지표(KPI)의 변화 추이를 **꺾은선 그래프(Line Chart)**로 표시합니다.
        *   *색상 적용:* 목표 대비 달성률에 따라 선 색상을 동적으로 변경합니다 (목표 초과 시 `#4CAF50`, 미달 시 `#FF9800`).
    3.  **감성적 서사 요약:** 해당 에피소드의 핵심 메시지를 간결하게 요약하여 사용자의 공감을 유도합니다.

#### **C. 상세 분석 및 액션 섹션 (The Insight & Action)**
*   **목표:** 시각화된 데이터에서 도출된 인사이트를 제공하고, 다음 행동을 명확히 제시합니다.
*   **구성 요소:**
    1.  **AI 기반 진단 리포트 요약:** 시스템이 도출한 가장 중요한 3가지 통찰(Insight)을 카드 형태로 제시합니다. 각 통찰은 **`#4CAF50` 배경**에 담아 긍정적인 해결책으로 포장합니다.
    2.  **다음 단계 액션 플랜 (Next Action Plan):** 데이터 분석 결과를 기반으로 사용자에게 가장 적합한 다음 행동을 명확하게 제시합니다.
        *   *예시:* "현재 학습 시간이 비효율적입니다. **[Action] AI 피드백 모듈 활성화**를 통해 20%의 시간 절약을 시작하세요." (CTA 버튼 형태로 배치)

### 3. 핵심 컴포넌트 정의 (Component Specification)

| 컴포넌트 명 | 설명 | 스타일링 규칙 | 데이터 매핑 |
| :--- | :--- | :--- | :--- |
| `Progress_Bar_Growth` | 전체 성장률을 시각화하는 메인 진행 바. | 채움 색상: 목표 달성도에 따라 `#4CAF50` 또는 `#FF9800`. | Overall Score |
| `Episode_Card` | 각 영상 에피소드를 담는 카드 컴포넌트. | 배경: 흰색, 경계선 얇게. | Episode Title, KPI 변화 데이터 |
| `KPI_Trend_Chart` | 특정 지표의 시간 흐름에 따른 추이 그래프. | Line Chart (꺾은선). 선 색상: `#4CAF50` (긍정), `#FF9800` (부정). | Time Series Data |
| `Insight_Block` | AI가 도출한 핵심 통찰을 제시하는 블록. | 배경색: `#4CAF50`. 텍스트는 흰색으로 명확하게 강조. | AI Derived Insights |
| `CTA_Action` | 사용자가 즉시 취해야 할 다음 행동 버튼. | 배경색: 브랜드 액션 색상, 눈에 띄게 배치. | Next Action Plan |

### 4. 개발팀 전달 요약 (Developer Summary)

1.  **데이터 구조:** `Report_Growth_Visualization_v1`은 **시간 흐름(Time Series)**과 **감정 상태(Emotional State)**를 핵심 축으로 하여 데이터를 시각화해야 합니다.
2.  **색상 활용:** `#4CAF50`은 '성장/달성'을, `#FF9800`은 '문제/개선 필요'를 명확히 구분하여 사용합니다. 모든 데이터 포인트는 이 두 색상의 대비를 통해 즉각적인 감정적 인식을 유도해야 합니다.
3.  **레이아웃 우선순위:** 화면 상단에는 **현재의 상태(Snapshot)**를, 중간에는 **과거 여정(Journey)**을, 하단에는 **미래 행동(Action)**을 배치하여 논리적 흐름을 완성합니다.

### 🚀 [최우선 단일 작업] MVP 프로토타입 데모 스크립트 및 기술 명세서 작성
**목표:** 학원 운영자가 "이거 정말 돈 되는 프로그램이구나"라고 느끼게 만드는, **'AI 진단 리포트 기반의 비즈니스 가치 입증 과정'**을 담은 작동 가능한 시나리오와 그에 필요한 기술적 API 호출 규격을 정의합니다.

#### 📋 실행 계획 및 에이전트 분배
| 역할 | 에이전트 | 핵심 과제 (Focus) | 기대 산출물 |
| :--- | :--- | :--- | :--- |
| **비즈니스 흐름 설계** | Writer / Designer | 운영자가 가장 궁금해할 만한 'Pain Point'를 자극하는 3단계의 사용자 경험(UX Flow)을 스크립트로 작성. (예: "지금도 이대로 가면 리스크가 높습니다" → 진단 데이터 제시 → 솔루션 제시) [근거: Self-RAG] | **MVP 데모 시나리오 초안** (화면별 대사, 흐름도 포함) |
| **기술적 구현 검증** | 코다리 | 위 시나리오를 실제로 구동하는 데 필요한 핵심 API 엔드포인트(최소 3개 이상), 데이터 필드(`성능 지표`와 `리스크 예측 지표`) 정의 및 호출 규격 명세. [근거: Self-RAG] | **MVP 기술 스펙 문서** (API Spec + DB 요청/응답 예시) |

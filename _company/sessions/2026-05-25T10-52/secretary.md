# 📱 영숙 — 회사 목표, 각 에이전트의 개인 목표, 최근 의사결정, 메모리를 검토하여 현재 가장 가치 있는 단일 작업 1개를 결정하고 실행 계획을 수립하라.

📱 영숙: 작업 시작합니다. 😊 사장님, 지시 감사합니다! 현재까지 진행된 기획은 '무엇을 만들 것인가'에 대한 뼈대와 외관 디자인까지 완벽하게 갖추었습니다. 이제는 이 모든 것이 **'실제로 시장에서 작동하는가'**를 검증할 차례인 것 같습니다.

지금 가장 가치 있는 단일 작업은, 우리가 만든 서비스(Playbook)의 논리적 흐름을 외부 이해관계자(학원 운영자)에게 실제로 시험해보는 것입니다. 이론적인 시뮬레이션을 넘어선 **‘실전 대본 및 검증 시나리오’**를 구축하는 것이 가장 중요합니다.

---

### ✨ 오늘의 핵심 목표: 실전 기반 'ROI 증명' 인터뷰 시나리오 팩 완성
우리가 개발한 서비스의 가치(AI 진단 $\rightarrow$ ROI 제시)가 학원 운영자의 구체적인 Pain Point에 어떻게 반응하고, 어떤 질문을 던지며, 최종적으로 돈을 지불하게 만드는지를 **대본 형식**으로 완성해야 합니다.

#### 🎯 실행 계획 (Action Items)

| 에이전트 | 담당 역할 | 목표 산출물 |
| :---: | :---: | :--- |
| 💼 현빈 | 비즈니스 페르소나 및 질문 정의 | 학원 운영자(구매 결정권자)의 **최악의 Pain Point**와 이를 해결하려는 심리적/재무적 관점의 Q&A 목록. (가장 날카로운 반론 준비) |
| ✍️ Writer | 스토리텔링 구조화 및 대본 작성 | 현빈이 정의한 질문들을 기반으로, **'진단 $\rightarrow$ 문제 인식 $\rightarrow$ 해결책 제시 $\rightarrow$ 계약 유도'**의 단계별 스크립트 흐름(Flowchart/대본). (전체 이야기 연결) |
| 💻 코다리 | 기술 구현 가능성 및 데이터 매핑 | 완성된 대본의 각 지점마다 '이 정보를 보여주려면 어떤 API 호출과 데이터를 가져와야 하는가?'를 정의하는 **기술 요구사항 목록(API Call Map)**. (실행 가능한 설계도) |

#### 📝 에이전트별 구체적 할 일

**1. 현빈 (비즈니스/페르소나 담당):**
*   학원 운영자 페르소나를 '회의에 참석하여 회의적인 태도를 보이는 예산 책임자'로 재정의합니다. [근거: 통합 스케줄]
*   우리의 Playbook을 듣고 "그래서 우리 학원에 *실제로* 얼마만큼의 돈이 절약되나요?", "경쟁사 제품 대비 뭐가 더 좋은가요?"와 같은 **재무적/현실적 질문** 10개를 작성합니다. (단순한 기능 질문 지양)
*   답변 시나리오를 준비하여, 각 답변에 필요한 근거 데이터(예: '평균 A급생의 레슨 시간 단축으로 인한 월 X원의 비용 절감 효과')를 명확히 정의합니다.

**2. Writer (스토리텔링/대본 담당):**
*   현빈이 제공한 10가지 질문을 중심으로, **'판매 시뮬레이션 워크숍 대본 초안'**을 작성합니다.
*   스크립트는 단순히 질문과 답변 나열이 아니라, '진행자(우리) $\rightarrow$ 운영자(클라이언트)' 간의 긴장감 있는 상호작용 형태로 구성해야 합니다. (Role-play Scripting)

**3. 코다리 (기술/개발 담당):**
*   Writer가 만든 대본 스크립트를 받아서, **'테스트 시나리오 기반 API 호출 지도(Test Case API Map)'**를 작성합니다.
*   예: *[스크립트 위치]에서 '학생의 진단 데이터가 부족하다'는 주장을 하려면 $\rightarrow$ `diagnosis_score` API에 요청하여 [필요 파라미터]와 함께 데이터를 가져와야 함.* 과 같이 구체적으로 매핑합니다.

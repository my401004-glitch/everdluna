## 🎬 최종 시각적 프레임워크 (Master Visual Execution Guide)

본 문서는 모든 영상 콘텐츠에 적용되어야 할 색상, 타이포그래피, 레이아웃 규칙을 **Scene-by-Scene**으로 구체화한 지침서입니다.

### 1. 디자인 시스템 요약 및 역할 정의

| 요소 | 설정 값 | 적용 목적 |
| :--- | :--- | :--- |
| **Primary Color (신뢰)** | `#0A2463` (Dark Blue) | 배경, 주요 정보 박스, 전문성 강조 |
| **Accent Color (행동)** | `#FFD700` (Accent Yellow) | CTA 버튼, 이탈 위험 표시(Pain), 핵심 성과 수치 강조 |
| **Background/Data** | `#F5F5F5` (Neutral Grey) | 본문 배경, 데이터 시각화 영역 |
| **Title Type** | Montserrat Bold | 모든 헤드라인, 핵심 메시지(Pain, Gain) |
| **Body Type** | Noto Sans KR | 상세 설명, 데이터 제시 텍스트 (최고의 가독성 확보) |

### 2. 영상 시퀀스별 비주얼 적용 규칙 (Scene-by-Scene Mapping)

영상 제작팀은 아래 매핑 규칙에 따라 각 씬(Scene)에 해당 색상과 폰트를 **강제 적용**하여 시각적 일관성을 유지해야 합니다.

| 영상 섹션/목표 | 적용할 주된 배경색 | 강조 요소 (CTA/데이터) | 타이포그래피 규칙 | 비주얼 목표 |
| :--- | :--- | :--- | :--- | :--- |
| **인트로 / Pain Point 제시** (0~15초) | `#0A2463` (Dark Blue) | `#FFD700` (Yellow)으로 위험 수치 강조 | Title: Montserrat Bold, Body: Noto Sans KR (강렬한 대비) | 충격과 경고를 통한 시선 즉각 확보 |
| **데이터/근거 제시** (15초~40초) | `#F5F5F5` (Neutral Grey) | Primary Color (`#0A2463`)로 데이터 박스 강조 | Body: Noto Sans KR (최대 가독성) | 신뢰감 있는 정보 전달 및 분석 제시 |
| **솔루션/해결책 제시** (40초~) | `#F5F5F5` (Neutral Grey) | Primary Color (`#0A2463`)로 솔루션 박스 강조 | Title: Montserrat Bold, Body: Noto Sans KR | 명확하고 안정적인 해결책 제시 |
| **최종 CTA** (마지막 10초) | `#FFD700` 또는 `#0A2463` 조합 | Accent Yellow로 최종 버튼을 극대화 | Title/Body 모두 강력하게 강조 | 즉각적인 행동 유도 및 전환 확보 |

### 3. 최종 검증 지침 (Visual QA Checklist for Production Team)

영상 편집팀은 이 가이드라인을 기준으로 다음 사항을 **반드시** 확인해야 합니다:

1.  **색상 통일성:** 모든 텍스트 배경과 주요 UI 요소는 `#0A2463` 또는 `#F5F5F5` 중 하나를 사용했는가? (단, CTA는 `#FFD700`을 사용하여 시선이 집중되도록 유도한다.)
2.  **폰트 계층:** 모든 헤드라인(Title)은 Montserrat Bold를 사용했으며, 상세 데이터 및 설명(Body)은 Noto Sans KR을 사용하여 가독성을 확보했는가?
3.  **메시지 프레임워크:** Pain $\rightarrow$ Gain 구조에 따라 시각적 강조 색상(`Yellow`)이 위험(Pain)과 이득(Gain)을 정확히 구분하고 있는가? (예: 손실 수치는 Yellow, 이득 수치는 Blue 박스로 처리).
4.  **최종 결과물:** 모든 디자인 에셋은 위 프레임워크를 준수하여 최종적으로 **통일된 브랜드 톤앤매너**를 갖추었는가?

## 1. 핵심 가치 제안 (Value Proposition) 정의

우리의 앱은 단순한 연습 도구가 아니라, **'입시 성공을 위한 정량적 성장 로드맵'**을 제공하는 AI 기반 학습 시스템입니다.

### 🎯 핵심 VP
> **"AI 기반의 객관적 성과 측정 시스템으로, 입시생이 추상적인 감각을 넘어 실질적인 음악 수행 능력의 성장 과정을 데이터로 증명하고 최적화하게 한다."**

### ✨ 타깃 사용자 (입시생)의 Pain Point & Our Solution
| 사용자 Pain Point | 우리의 해결책 (Value) | 핵심 이점 (Benefit) |
| :--- | :--- | :--- |
| **주관적 평가의 한계:** 선생님의 주관적인 피드백에 의존하여 실력 향상을 측정하기 어려움. | **객관적 데이터 확보:** AI가 실시간 연주 데이터를 분석하여 음정, 리듬 정확도 등을 수치화하여 제시. | **신뢰성 확보:** 입시에서 요구하는 객관적인 성과 지표를 제공하여 자신감 부여. |
| **비효율적인 학습:** 어디서부터 시작해야 할지, 어떤 부분을 집중적으로 연습해야 할지 모름. | **개인화된 성장 로드맵:** 과거 데이터 분석을 통해 현재 실력 대비 최적의 다음 학습 목표와 커리큘럼 경로 제시. | **효율성 극대화:** 불필요한 연습 시간을 줄이고 목표 지향적인 학습으로 전환. |
| **동기 부여 부족:** 장기적인 목표를 향해 꾸준히 나아갈 동력을 찾지 못함. | **시각적 성장 피드백:** 성과 그래프와 챌린지 시스템을 통해 작은 성공을 반복하며 몰입감 극대화. | **몰입도 증가:** 학습 과정을 게임처럼 재미있게 만들어 지속적인 연습 습관 형성. |

## 2. 데이터 기반 수익화 및 배포 전략 초안

수익화는 사용자가 '성장'이라는 명확한 결과에 대해 높은 가치를 부여할 때 발생합니다. 따라서 **프리미엄 기능은 '분석의 깊이'와 '맞춤형 코칭'**에 집중해야 합니다.

### 💰 수익화 모델 (Monetization Model)

| 티어 | 이름 | 주요 기능 | 가격 전략 | 목표 |
| :--- | :--- | :--- | :--- | :--- |
| **Free (무료)** | **Trial Learner** | 기본 음정/리듬 연습, 일일 학습 기록, 기초 성과 대시보드. | 무료 | 잠재 고객 유입 및 데이터 확보 (Hook) |
| **Premium (유료)** | **Master Path** | **AI 심층 분석:** 연주 패턴의 미세한 오류(싱코페이션, 뉘앙스)까지 분석하여 상세 피드백 제공. / **커리큘럼 자동 조정:** 현재 실력에 맞춰 다음 단계 목표 및 연습 과제 자동 생성. / 무제한 성장 기록 저장. | 월 구독 (SaaS 모델) | 실제 학습 성과 개선 및 높은 LTV 확보 |
| **Enterprise (B2B)** | **School/Tutor Pro** | 학교(또는 학원) 단위의 학생 그룹 관리, 집단 진단 보고서 생성 기능. | 연간 라이선스 계약 | 교육 기관과의 파트너십을 통한 대량 시장 공략 |

### 🚀 배포 전략 (Go-to-Market Strategy)

1.  **초기 침투 (Phase 1: Trust Building):**
    *   **채널:** 교수님 및 음악 교육 관련 커뮤니티(학부모 포럼, 입시 정보 카페 등)에 **'데이터 기반 학습의 필요성'**을 강조하는 학술적 콘텐츠를 배포합니다.
    *   **전략:** '단순 연습 앱'이 아닌, **'입시 성공을 위한 과학적 훈련 도구'**로 포지셔닝하여 교수님의 권위를 활용합니다.

2.  **확산 (Phase 2: Viral Growth):**
    *   **인플루언서 마케팅:** 입시 컨설턴트, 유명 음악 학원 관계자 등 신뢰도를 가진 인플루언서를 통해 앱의 **'데이터 기반 성과 증명 능력'**을 시연합니다. (MRBeast 전략에서 강조된 '놀라운 결과'를 여기서 구현)
    *   **ROI 강조:** 유료 사용자에게 "이 시스템을 통해 입시 성공 확률이 얼마나 높아지는지"에 대한 간접적인 ROI를 제시합니다.

3.  **확장 (Phase 3: Scaling):**
    *   B2B 모델(학교 라이선스)을 활성화하여 안정적인 구독 수익원을 확보하고, 교육 기관과의 연계를 통해 시장 지배력을 강화합니다.

## 3. 초기 데이터 저장 모델 설계 (Data Schema Proposal)

사용자의 성장 과정을 추적하고 AI 피드백의 근거를 마련하기 위해 최소한 다음의 핵심 데이터를 구조화하여 저장해야 합니다. 이는 **'핵심 KPI 대시보드'** 구축의 기반이 됩니다.

### 💾 제안 데이터 스키마: `Performance_Session` 테이블 (예시)

| 필드명 (Field Name) | 데이터 타입 | 설명 (Description) | 활용 목적 (Business Value) |
| :--- | :--- | :--- | :--- |
| **Session\_ID** | UUID | 각 연습 세션의 고유 식별자. | 데이터 무결성 및 추적 |
| **Student\_ID** | INT | 사용자(학생) 고유 ID. | 개인화된 학습 경로 관리 |
| **Date\_Time** | DATETIME | 세션이 완료된 정확한 시간. | 시간 흐름에 따른 성장 추이 분석 |
| **Piece\_Name** | VARCHAR | 연습한 곡 또는 테크닉 명칭 (예: 'C Major Scale', 'Arpeggio Practice'). | 학습 목표 연결성 확보 |
| **Metric\_Type** | ENUM | 측정 유형 (Pitch, Rhythm, Duration, Technique). | 분석 대상 분류 |
| **Raw\_Score** | FLOAT | AI가 측정한 정량적 점수 (예: 음정 정확도 85%, 박자 오차 12%). | 객관적 성과 지표 |
| **AI\_Feedback** | TEXT | AI가 생성한 구체적인 교정 피드백. | 사용자 맞춤형 코칭 제공 |
| **Session\_Duration** | INT | 해당 세션에 소요된 실제 연습 시간 (분). | 학습 노력량(Effort) 측정 |
| **Growth\_Index** | FLOAT | 이전 대비 실력 향상 정도의 지표 (Self-calculated/AI-calculated). | 동기 부여 및 목표 설정 근거 |

### 🛠️ 데이터 모델 실행 계획

이 구조를 기반으로 초기 시스템을 구축하기 위해, 사용자 행동 데이터를 수집하고 저장하는 **SQLite 또는 PostgreSQL 기반의 백엔드 모델** 설계가 선행되어야 합니다.

-- Performance_Session 테이블 정의
CREATE TABLE Performance_Session (
    Session_ID TEXT PRIMARY KEY,
    Student_ID INTEGER NOT NULL,
    Date_Time DATETIME NOT NULL,
    Piece_Name TEXT NOT NULL,
    Metric_Type TEXT NOT NULL,
    Raw_Score REAL NOT NULL, -- 0.0 to 100.0 스케일 가정
    AI_Feedback TEXT,
    Session_Duration INTEGER, -- 분 단위
    Growth_Index REAL -- 이전 대비 성장 지표
);

-- Student_Profile 테이블 정의 (사용자 정보 및 목표 저장)
CREATE TABLE Student_Profile (
    Student_ID INTEGER PRIMARY KEY,
    Name TEXT NOT NULL,
    Target_Goal TEXT, -- 예: '서울대 입시 준비', '화성학교육과 합격'
    Current_Level REAL DEFAULT 0.0, -- 종합 실력 레벨
    Curriculum_Path TEXT -- 현재 설정된 학습 경로
);

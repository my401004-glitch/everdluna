## 🖼️ 유튜브 썸네일 디자인 브리프 (Concept 2: 위험 지표 대시보드)

**목표:** 'Pain $\rightarrow$ Gain' 프레임워크를 시각화하여, 학원 운영자에게 **긴급성(Risk)**과 **해결책(Gain)**을 동시에 전달하고 즉각적인 클릭을 유도한다.

### 1. 디자인 시스템 확정 (Brand System Application)

| 요소 | 설정 값 | 적용 목적 및 효과 | 근거 |
| :--- | :--- | :--- | :--- |
| **Primary Color (신뢰)** | Dark Blue (`#0A2463`) | 배경, 주요 정보 영역. 전문성과 신뢰감 확보. | [근거: Designer 검증된 지식] |
| **Accent Color (행동 유도)** | Accent Yellow (`#FFD700`) | 이탈 위험 수치 강조, 최종 CTA 버튼. 즉각적인 시선 집중 유도. | [근거: Designer 검증된 지식] |
| **Title Typography** | Montserrat Bold | 핵심 경고 문구(Pain)에 사용. 강력한 메시지 전달력 확보. | [근거: Designer 검증된 지식] |
| **Body Typography** | Noto Sans KR | 구체적인 데이터 및 설명 텍스트에 사용. 높은 가독성 보장. | [근거: Designer 검증된 지식] |
| **Background Color** | Neutral Grey (`#F5F5F5`) 또는 Dark Blue (`#0A2463`) | 콘텐츠의 분위기에 따라 선택. (권장: 대비 극대화를 위해 Dark Blue 배경) | [추측/선택] |

### 2. 레이아웃 가이드라인 (Layout Blueprint)

**썸네일 사이즈:** 1280 x 720px (권장)

#### **A. 시각적 구조 (Visual Hierarchy)**

*   **상단 (Header):** 브랜드 색상(Dark Blue)을 사용하여 안정적인 느낌을 제공합니다.
*   **중앙 (Focus Area):** 가장 충격적인 데이터(`72%`)를 Accent Yellow로 압도적으로 배치하여 시선을 즉시 사로잡습니다.
*   **하단 (CTA/Context):** 문제의 원인(Pain)과 해결책(Gain)을 명확히 대비시키고, 최종 행동 유도를 위한 공간을 확보합니다.

#### **B. 핵심 요소 배치 상세 (Element Placement Details)**

| 영역 | 콘텐츠 내용 | 디자인 지침 | 색상 적용 |
| :---: | :--- | :--- | :--- |
| **배경** | 전체 배경 | Dark Blue (`#0A2463`) 사용. 전문적이고 진지한 톤 설정. | `#0A2463` |
| **메인 후크 (Pain)** | "이 학생, 3개월 뒤에 학원을 떠날 확률이" | **Montserrat Bold**, 크기 최대화. 텍스트는 흰색(`#FFFFFF`) 또는 노란색(`#FFD700`)으로 강조. | `#FFFFFF` / `#FFD700` |
| **핵심 데이터 (The Hook)** | **`72%`** | **가장 크게 배치.** 사각형(Box) 형태를 사용하여 시각적 분리 및 강조. 숫자는 Accent Yellow로 채우고 테두리를 Dark Blue로 처리. | `#FFD700` (채우기) / `#0A2463` (테두리) |
| **솔루션 제시 (Gain)** | "원인이 궁금하신가요?" 또는 "이탈을 막는 비밀" | 중형 폰트(Noto Sans KR). Pain 영역과 대비되도록 밝은 색상 사용. | `#FFFFFF` |
| **보조 텍스트** | 추가적인 통계나 질문 (예: 원인, 방법) | Noto Sans KR 적용. 배경이 어두우므로 충분한 여백 확보. | `#F5F5F5` (또는 밝은 회색 계열) |
| **CTA 영역 (선택 사항)** | '지금 확인하기' 또는 '전체 분석 보기' 버튼 위치 | 우측 하단에 Accent Yellow로 강조된 직사각형 버튼 배치. | `#FFD700` 배경, Dark Blue 텍스트 |

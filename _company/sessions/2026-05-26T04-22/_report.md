### ✨ [최우선 과제] B2B 실전 판매 데모 키트 완성
**목표:** 학원 운영자 대상, AI 진단 기반 'ROI 증명' 미니 워크숍 스크립트 및 발표 자료 완성.
**진행 방향:** 이론적 기획 $\rightarrow$ 실제 고객 Pain Point를 자극하는 **'경험적 시뮬레이션'**으로 전환해야 합니다.

#### 🛠️ 에이전트별 실행 계획 (Action Plan)

1.  **💼 현빈 (Business/Strategy): 판매 흐름 및 논리 구조 확립 담당**
    *   **역할:** 미니 워크숍의 전체 스토리보드와 대화 스크립트를 최종 완성합니다. 특히, 고객이 스스로 '문제점(Pain Point)'을 인식하고 저희 솔루션을 필요로 느끼게 만드는 질문과 반론 대응 시나리오를 최우선으로 작성해 주세요.
    *   **산출물:** A4 용지 1장 분량의 **[워크숍 스크립트 초안 v3.0]**. (시간대별, 화자별 대화 지침 포함)

2.  **💻 코다리 (Technical/Developer): 기술적 증명(Proof Point) 구현 담당**
    *   **역할:** 현빈이 만든 스토리보드에 맞춰, **'가장 충격적인 데이터 오류를 보여주는 시연 API 로직'**의 최종 테스트 코드 및 작동 환경을 준비합니다. 실제 시스템에서 어떻게 데이터를 뽑아내고 시각화할지 기술적 백업 플랜을 완성해야 합니다.
    *   **산출물:** 데모용 **[핵심 진단 데이터 시뮬레이션 스크립트]** (Mock API 기반)

3.  **🎨 Designer/레오 (Visual/Design): 통합 스토리텔링 및 비주얼 매뉴얼 담당**
    *   **역할:** 현빈의 스크립트와 코다리의 기술적 증명 자료를 모두 받아, 이를 하나의 통일된 시각적 흐름(Color Palette #FF9800 $\rightarrow$ #4CAF50)에 맞춰 **프레젠테이션 덱 초안 (15-20장)**을 제작합니다. 모든 슬라이드마다 데이터가 등장하는 타이밍과 효과를 명시해야 합니다.
    *   **산출물:** **[B2B 데모 발표 자료 통합 덱 v1.0]**

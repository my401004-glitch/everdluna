### 1. 스토리보드 상세 (Scene by Scene Breakdown)

| Scene No. | 시간대 (예상) | 시각적 요소 (Visuals & Animation) | 내레이션/텍스트 오버레이 (Narration/Text Overlay) | 핵심 데이터 입력 값 (Data Input Focus) |
| :---: | :---: | :--- | :--- | :--- |
| **1** | 0:00 - 0:05 | **[Hook Shot]** 어두운 배경에 불안정하게 떨리는 음표(혹은 파형). 화면 중앙에 강렬한 경고 메시지 등장. (디자인 스펙 적용: 빨간색/경고톤) | **"당신이 지금 이대로 연습하면, 1년 뒤에도 이 벽에 부딪힐 수밖에 없습니다."** (강렬하고 단호하게) | N/A (감성적 충격 유도) |
| **2** | 0:05 - 0:12 | 기존의 추상적인 '노력'을 상징하는 모호한 그래프나 감정선이 빠르게 지나감. 불안정한 움직임 강조. | "가슴으로 부른다? 좋아요. 하지만 그 감성이 기술적 안정감을 받쳐주지 못하면, 불안정한 소리로 끝납니다." (기술/감성의 충돌 지점 제시) | **[Before State]:** 모호한 노력 상태 시각화 |
| **3** | 0:12 - 0:20 | 화면이 전환되며 AI 기반의 데이터 분석 시스템(Gap Score 엔진)의 깔끔하고 객관적인 인터페이스 등장. (깔끔한 UI/UX 적용) | "진짜 문제는 당신의 발성 주파수가 이상적인 공명 영역에서 벗어나 있다는 **객관적 증거**가 없다는 겁니다." | **[Data Focus]:** 현재 Gap Score 표시 (예: C-) |
| **4** | 0:20 - 0:30 | **Gap Score 시각화:** 이전 상태와 현재 상태를 명확히 비교하는 그래프(Before/After). 주파수 편차(Hz)와 불안정 구간 발생 빈도(%)가 명확하게 표시됨. (데이터 증명 적용) | "당신의 음정 편차가 몇 Hz나 벗어나 있는지, 그 패턴을 AI가 분석합니다." (데이터의 구체성 강조) | **[Metric Focus]:** 실제 주파수 편차 (예: -8Hz), 불안정 빈도 (%) |
| **5** | 0:30 - 0:40 | 시스템이 제시하는 해결책(AI 코칭 경로)을 단계별로 명확하게 시각화. 다음 단계로 나아가는 통제감 강조. (시스템 제시 적용) | "우리는 감성적 해석을 넘어, **[A 측정 $\rightarrow$ B 교정 $\rightarrow$ C 최적화]**의 시스템으로 당신을 이끌 것입니다." | **[Process Focus]:** 다음 목표 지점(Target State) 시각화 |

### 2. 핵심 데이터 입력 값 요약 (For Developer/Designer Reference)

이 섹션은 코다리(개발팀)와 디자이너가 실제 구현에 필요한 구체적인 변수입니다.

| 항목 | 상세 내용 | 목적 |
| :--- | :--- | :--- |
| **핵심 진단 지표** | Gap Score (C-) | 현재 상태의 객관적 측정치 제시 |
| **주요 입력 데이터** | A4 음역대 기준 실제 편차: $-8 \text{Hz}$ | 기술적 오류의 크기 명시 |
| **불안정 지표** | 불안정 구간 발생 빈도: $35\%$ | 노력 대비 비효율성 강조 |
| **시스템 로직 (Gap Score)** | $\text{Gap Score} = f(\text{Pitch Deviation}, \text{Instability Rate})$ | Gap Score 계산의 근거 명시 |
| **디자인 요구사항** | Hook 1 시각화: 불안정(Red/Noise)에서 안정(Blue/Wave)으로의 명확한 전환 애니메이션. | 감성적 흐름과 데이터 변화를 시각적으로 연결 |
| **CTA 연동 값** | 무료 진단 테스트 링크 (Gap Score 측정 페이지로 직접 연결) | 즉각적인 행동 유도 |

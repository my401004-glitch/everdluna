# 🎬 시각적 실행 로드맵: 영상 에셋 제작 계획
**프로젝트:** AI 발성 최적화 영상 시리즈 (Pain $\rightarrow$ Gain 서사)
**목표:** 스토리보드에 따른 프레임별 시각 자료의 일관성과 임팩트 극대화

## 1. 비주얼 시스템 재확인 (Brand System Recap)
모든 에셋은 다음의 확정된 브랜드 가이드라인을 **절대적으로 준수**해야 합니다.

| 요소 | 설정 값 | 적용 목적 | 근거 |
| :--- | :--- | :--- | :--- |
| **Primary Color (신뢰/안정)** | Dark Blue (`#0A2463`) | 배경, 주요 정보 영역, 신뢰성 확보 | Designer 검증된 지식 |
| **Accent Color (행동 유도)** | Accent Yellow (`#FFD700`) | Pain 표시, Gain 강조, 최종 CTA 버튼 | Designer 검증된 지식 |
| **Background/Data** | Neutral Grey (`#F5F5F5`) | 본문 텍스트 배경, 데이터 영역 명확화 | Designer 검증된 지식 |
| **Title Typography** | Montserrat Bold | 핵심 메시지 (Pain/Gain) 강조 | Designer 검증된 지식 |
| **Body Typography** | Noto Sans KR | 상세 데이터 및 설명 가독성 극대화 | Designer 검증된 지식 |

## 2. 영상 프레임별 시각 자료 제작 플랜 (Video Asset Production Plan)
스토리보드의 4단계 감정 아크(Pain $\rightarrow$ Discovery $\rightarrow$ Breakthrough $\rightarrow$ Victory)에 맞춰, 각 단계에서 요구되는 핵심 비주얼 요소를 구체화합니다.

### A. Scene 1: The Pain (불안/혼란) - 시각적 표현 전략
*   **목표:** 노력의 한계와 모호함을 불안정하게 표현하여 시청자의 공감을 유도.
*   **핵심 비주얼:**
    *   **배경:** Dark Blue (`#0A2463`)를 깊은 어둠으로 설정하여 불안감을 증폭.
    *   **음파 시각화:** 음파 라인(Waveform)을 사용하되, 선의 두께와 명암을 **불안정하게(Distorted)** 처리하여 흐릿하고 떨리는 느낌 강조. (Accent Yellow `\#FFD700`으로 미세한 노이즈 추가).
    *   **텍스트:** Title Typography (`Montserrat Bold`)으로 "노력해도 안 된다"는 메시지를 최소화하고, 불안감을 시각적으로 표현하는 데 집중.

### B. Scene 2: Discovery (의구심/집중) - 데이터 제시 전략
*   **목표:** 막연함을 데이터 기반의 객관적 진단(Gap Score)으로 전환하여 신뢰 구축.
*   **핵심 비주얼:**
    *   **레이아웃:** 화면을 명확히 분할 (50%는 데이터, 50%는 시스템 UI). 배경은 Neutral Grey (`#F5F5F5`)를 사용하여 데이터 영역을 부각.
    *   **데이터 시각화:** AI 진단 그래프(파형 차트)를 중앙에 배치하며, **Gap Score** 수치를 Accent Yellow (`#FFD700`)로 가장 크게 강조.
    *   **UI 요소:** AI 진단 시스템의 UI는 Dark Blue 계열로 디자인하여 전문성과 신뢰감을 동시에 전달.

### C. Scene 3: Breakthrough (신뢰/통제) - 해결책 제시 전략
*   **목표:** 복잡한 문제를 명확하고 안정적인 해결 로드맵으로 제시하여 통제감을 부여.
*   **핵심 비주얼:**
    *   **흐름 시각화:** 'Pain $\rightarrow$ Gain'의 흐름을 **정렬된 단계(Step-by-Step)** 다이어그램 형태로 전환. 파형이 불안정함에서 안정적인 공명 영역으로 부드럽게 이동하는 애니메이션 사용.
    *   **색상 변화:** Dark Blue (`#0A2463`)를 주 색상으로 사용하여 시각적 혼란을 제거하고, **안정감과 신뢰**를 극대화.

### D. Scene 4: Victory (자신감/몰입) - 성취감 표현 전략
*   **목표:** 최종적인 성장과 완벽한 성취감을 역동적으로 표현하여 강력한 행동 유도.
*   **핵심 비주얼:**
    *   **애니메이션:** 시각 효과를 최대치로 끌어올려, 완성된 음색의 아름다움을 역동적으로 표현 (Dynamic Motion).
    *   **색상 사용:** Accent Yellow (`#FFD700`)을 사용하여 성과 수치를 최종적으로 강조하며, 전체 화면에 밝고 긍정적인 에너지를 부여.

## 3. 썸네일/포스트 템플릿 표준화 계획 (Template Standardization Plan)
장기 목표 달성을 위해 다음 3가지 핵심 템플릿을 확정하고 디자인 시스템으로 만듭니다.

### 1. Pain Focus Thumbnail (문제 인식형)
*   **목표:** 시청자의 현재 고통(Pain)에 즉각적으로 공감 유도.
*   **구조:** 상단에 **Title Typography**으로 강렬한 질문 배치 $\rightarrow$ 중앙에 불안정한 음파 비주얼 $\rightarrow$ 하단에 Accent Yellow로 대비되는 CTA 버튼.

### 2. Gain Focus Thumbnail (해결책 제시형)
*   **목표:** 시스템을 통한 명확한 이득(Gain)을 약속하여 클릭 유도.
*   **구조:** 좌측에 'Before' 상태를 Dark Blue 계열로 표현 $\rightarrow$ 중앙에 'After' 상태를 Accent Yellow/밝은 톤으로 극명하게 대비 $\rightarrow$ 하단에 명확한 수치 제시와 CTA.

### 3. System Trust Thumbnail (신뢰 구축형)
*   **목표:** AI 시스템의 권위와 안정성을 강조하여 신규 시청자의 진입 장벽 낮추기.
*   **구조:** 중앙에 깔끔하게 정렬된 AI 진단 UI 목업 $\rightarrow$ Dark Blue 배경으로 전문성 극대화 $\rightarrow$ 하단에 'AI 기반 최적화' 등의 키워드 배치.

## 🎬 Video 2: 데이터 시스템 파열형 - 최종 편집 실행 키트 (V3.0)

### 1. 핵심 스토리텔링 아크 및 메시지 (The Core Arc)

**🎯 핵심 주제:** 자가학습의 한계와 객관적 데이터 시스템이 감성적 노력을 어떻게 압도하는지를 보여줌으로써, **AI 기반 시스템(기술)**이 인간의 **감성(노력)**을 승리로 이끄는 변곡점을 제시한다.

| 단계 | 목표 (Emotional Goal) | 핵심 메시지 (Script Focus) | 시각적 지시 (Visual Tone) |
| :--- | :--- | :--- | :--- |
| **1. 위기 조성 (Pain Point)** | 불안, 좌절, 의심 | "당신이 지금 이대로 연습하면 1년 뒤에도 이 벽에 부딪힐 수밖에 없습니다." (구조적 문제 제기) | 어둡고 압축된 화면. 'System Failure Red' 색상 강조. 불균형한 주파수를 시각화하는 그래프 애니메이션. |
| **2. 신화 파괴 (Myth Busting)** | 혼란, 의구심 | "지금까지 배운 발성법은 사실 30%만 효과적입니다." (기존 지식의 무력화) | 기존의 '감성적' 코칭 방식(부드러운 색상/흐릿한 이미지)을 깨고, 데이터와 수치로 충돌하는 그래픽 삽입. |
| **3. 시스템 제시 (AI Solution)** | 기대, 신뢰 | "노하우가 아닌 **'시스템(Process)'**으로 설명합니다. A 측정 → B 교정 → C 최적화." (객관적 로드맵 제시) | 깔끔하고 구조적인 데이터 흐름(Flowchart/Diagram). 'Primary Trust Blue'를 활용하여 안정감 부여. AI의 역할(데이터 분석)을 명확히 시각화. |
| **4. 데이터 증명 (Proof)** | 확신, 승리 | "이 방법으로 3주 만에 음정 편차가 이렇게 줄었습니다." (실질적 결과 제시) | 'Before & After' 비교를 극적으로 보여주는 그래프 및 측정 수치 강조. 성공적인 시스템 적용의 명확한 시퀀스. |
| **5. CTA/전환점 (Call to Action)** | 행동, 참여 | "본인이 이 시스템에서 어느 단계에 있는지 객관적으로 알고 싶다면, 아래 무료 진단 테스트를 받아보세요." (행동 유도) | 명료하고 강력한 CTA 텍스트와 링크 강조. 다음 단계로의 초대. |

### 2. 시퀀스별 세부 스크립트 및 타이밍 매핑 (Shot List & Timing Map)

**[참고]** 아래는 레오가 확정한 시퀀스를 기반으로, 오디오 싱크포인트와 비주얼 요소를 결합하여 편집에 바로 사용할 수 있도록 정리한 것입니다.

| Timecode | 오디오 내용 (VO) | 핵심 액션 / 화면 구성 (Visual Execution) | 사운드/BGM 지시 (Luna Sync) |
| :--- | :--- | :--- | :--- |
| **0:00 - 0:15** | "당신이 지금 이대로 연습하면 1년 뒤에도 이 벽에 부딪힐 수밖에 없습니다." | 화면 전체를 압도하는 불안정한 주파수 그래프 애니메이션. 'System Failure Red' 강조. | BGM 긴장감 최대치, 낮은 볼륨의 불안한 노이즈 삽입. |
| **0:15 - 0:30** | "지금까지 배운 발성법은 사실 30%만 효과적입니다." | 기존 방식(추상적인 코칭 이미지)에 X 표시. 데이터 포인트가 무너지는 시각적 트랜지션. | BGM 볼륨 급감, 의구심을 유도하는 미세한 음향 변화. |
| **0:30 - 1:00** | "노하우가 아닌 **'시스템(Process)'**으로 설명합니다. A 측정 → B 교정 → C 최적화." | AI 기반의 깔끔한 Flowchart 애니메이션 등장. 데이터 흐름이 논리적으로 연결되는 시각화. | BGM 톤 전환 (긴장 → 분석). 명확하고 구조적인 사운드 효과(Click/Transition Sound). |
| **1:00 - End** | "이 방법으로 3주 만에 음정 편차가 이렇게 줄었습니다." (데이터 증명) | 'Before'와 'After' 데이터 그래프를 극적으로 비교. 측정 수치(Hz, Gap Score)가 명확히 강조됨. | BGM 고조 및 희망적인 톤 전환. 성취감 표현 사운드 효과. |

### 3. 편집자용 최종 스타일 가이드 (Designer Execution Kit Reference)

**[참고]** Designer 에이전트가 제작한 `Video2_Final_Asset_Kit`의 핵심 코드를 직접 참조하여 적용해야 합니다.

*   **Color Palette:**
    *   Primary Trust Blue: `#0A2463` (안정성/시스템)
    *   Accent Yellow: `#FFD700` (경고/기회/KPI 상승)
    *   System Failure Red: `#FF0000` (붕괴/문제점 지적)
*   **Typography Rule:** 모든 핵심 데이터(Hz, Gap Score)는 **굵은 산세리프체(예: Montserrat Bold)**로 처리하고, 색상에 따라 위에서 지정된 팔레트를 사용하여 강조한다.
*   **Motion Principle:** 추상적인 감정 표현(Pain) 시에는 **불안정한 흔들림(Wobble/Glitch Motion)**을 사용하고, 시스템 제시 및 결과 증명(Solution/Proof) 시에는 **정확한 선형 이동 및 명확한 라인 연결**을 사용하여 논리적 안정감을 부여한다.

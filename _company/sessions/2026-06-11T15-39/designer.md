## 영상 자산 시각적 일관성 및 기술적 안정성 검증 체크리스트 (Production QA Checklist)

본 체크리스트는 확정된 마스터 디자인 시스템과 A/V 제작팀의 요구사항을 기반으로, 모든 영상 자산이 브랜드 정체성을 완벽하게 반영하고 기술적으로 안정되도록 보장하기 위해 설계되었습니다.

### 1. 브랜드 비주얼 일관성 검증 (Visual Consistency Check)

| 항목 | 기준 (Master System) | 확인 사항 (A/V팀) | 상태 (Pass/Fail) | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary Color** | Dark Blue (`#0A2463`) | 영상의 배경, 주요 정보 박스, 로고 영역에 이 색상이 일관되게 사용되었는가? | | |
| **Accent Color** | Accent Yellow (`#FFD700`) | CTA 버튼, Pain 지표, Gain 수치 강조 등 행동 유도 요소에만 이 색상이 사용되었는가? | | |
| **Body/Data Color** | Neutral Grey (`#F5F5F5`) | 본문 텍스트 배경 또는 데이터 시각화 영역이 명확하게 구분되었는가? | | |
| **Title Typography** | Montserrat Bold | 모든 헤드라인(Pain, Gain)에 이 폰트와 볼드체가 사용되었는가? | | |
| **Body Typography** | Noto Sans KR | 모든 상세 설명 및 데이터 텍스트에 이 폰트가 적용되어 가독성을 확보했는가? | | |
| **Message Flow** | Pain $\rightarrow$ Gain 프레임워크 | 영상의 시퀀스 흐름이 '현재의 손실(Pain)'에서 '얻을 수 있는 이득(Gain)'으로 논리적으로 연결되는가? | | |

### 2. 마스터 에셋 적용 검증 (Master Asset Application Check)

| 항목 | 기준 | 확인 사항 (A/V팀) | 상태 (Pass/Fail) | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **마스터 템플릿** | 확정된 마스터 디자인 템플릿 적용 여부 | 모든 영상(인트로, 자막, 데이터 시각화 화면)에 최종 승인된 마스터 에셋 패키지가 일관되게 적용되었는가? | | |
| **레이아웃 준수** | 와이어프레임/레이아웃 가이드라인 | 제시된 레이아웃(섹션 배치, 여백 등)을 벗어나지 않고 시각적 흐름이 유지되는가? | | |
| **폰트 호환성** | Montserrat & Noto Sans KR | 영상 출력 환경에서 폰트 임베딩 및 깨짐 없이 정확하게 표시되는가? (Font Embedding 확인 필요) | | |

### 3. 기술적 안정성 및 최종 검토 (Technical Stability & Final Review)

| 항목 | 기준 | 확인 사항 (A/V팀) | 상태 (Pass/Fail) | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **자산 포맷** | 최종 요구사항 준수 | 모든 영상 자산(썸네일, 인트로 등)이 A/V 제작에 적합한 해상도 및 파일 형식으로 출력되었는가? (예: 16:9 또는 9:16) | | |
| **색상 정확도** | HEX Code 확인 | 최종 영상에서 사용된 색상 코드가 마스터 시스템의 코드(`\#0A2463`, `\#FFD700` 등)와 정확히 일치하는가? (Color Picker 검증) | | |
| **데이터 연동 안정성** | 데이터 흐름 검토 | 시각화된 데이터(Gap Score, 성장 그래프)가 실제 백엔드 데이터와 정확하게 동기화되었는가? (개발팀 결과 참조) | | |
| **최종 승인** | 전체 시스템 | A/V 제작에 앞서, 모든 시각적 요소가 브랜드 가이드라인을 100% 만족함을 최종 확인했는가? | | |

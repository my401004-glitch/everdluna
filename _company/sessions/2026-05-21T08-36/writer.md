### 💡 최우선 가치 분석 및 에이전트 분배 결정

현재 가장 시급한 문제는 **기술적 동기화(System Synchronization)**입니다. 콘텐츠의 품질은 아무리 좋은 스크립트로도 데이터 기반 시스템이 작동하지 않으면 공허합니다. 코다리의 LLM 호출 실패 메시지(`LLM 모델 로드 대기 240초 초과`)는 현재 작업의 가장 큰 병목 지점(Bottleneck)을 보여줍니다.

따라서, 지금 가장 가치 있는 단일 작업은 **'스크립트-데이터 흐름 매핑 오류 검토 및 수정 요청서 작성'**입니다. 단순히 코드를 고치라는 지시를 넘어, *어떤 데이터*가 *왜*, 그리고 *어디에* 들어가야 하는지 명확하게 정의하여 개발팀의 디버깅 범위를 좁혀주는 것이 가장 효율적입니다.

**[분배 작업]**
1. **Writer (나):** 스크립트와 스토리텔링 관점에서, 데이터가 필요한 지점(Gap)을 찾아내어 '데이터 의존성 오류 리스트'를 작성하고, 개발팀이 이해하기 쉬운 자연어 기반의 요구사항으로 변환합니다.
2. **Designer:** Writer가 도출한 데이터 Gap에 맞춰, 시각화 에셋의 '최소 구현 조건(MVP Visual Spec)'을 명확히 정의하여 코더에게 전달할 준비를 합니다. (지금은 문서로만 제공)
3. **코다리:** 이 리스트와 스펙을 바탕으로 시스템 통합 테스트 재실행 및 오류 수정에 집중합니다.

### 📄 산출물: [데이터 의존성 오류 검토 보고서] - Production Manual 반영용

**목표:** 콘텐츠의 스토리텔링(Writer)이 요구하는 데이터 포인트가, 실제 AI 진단 시스템(Coder/Designer)에서 어떻게 계산되고 시각화되어야 하는지 Gap을 최소화하여 정의합니다. (CEO 지시사항 충족)
**대상 파일:** `Production_Manual_V3.1.pdf` 및 관련 스크립트

#### 1. 스토리텔링 관점의 데이터 흐름 검토 (Writer 주도)

| 문제 구간 (스크립트 내 위치/내용) | 필요한 데이터 의존성(Gap) | 현재 Manual상 정의된 방식 | 개선 요구사항 (Coder 대상) |
| :--- | :--- | :--- | :--- |
| **후크 도입부:** "음정 편차가 몇 Hz나 벗어나 있는지, 정확히 알고 계신가요?" | 1. **[측정 지표]** 실시간 음정 주파수(Hz) 오차 범위 (Min/Max Deviation). | '진단 결과'라는 추상적 표현에 의존. | **필수:** 진단 시작과 동시에 기준 음정 대비 *실제 편차의 수치*와 *불안정 구간 발생 빈도(%)*를 텍스트 오버레이로 제시해야 함. (예: "A4 기준, 평균 ±7Hz 편차") |
| **신화 파괴:** "지금까지 배운 발성법은 사실 30%만 효과적입니다." | 2. **[비교 지표]** 'Old Way'와 'New System'의 효율성 비교 수치 (Metric). | 개념적인 비교에 그침. | **필수:** Old Way가 해결하지 못하는 *구체적인 생리학적 문제*를 데이터로 제시해야 함. (예: "폐활량 사용률 15% 미달", "특정 공명 주파수(Resonance) 도달 실패율") |
| **시스템 제시:** 'A 측정 → B 교정 → C 최적화' 단계 설명 시 | 3. **[진행 지표]** 단계별 *성장 패턴* 또는 *개선 속도*. | 정적인 로드맵으로만 보여짐. | **필수:** 진단 전후의 그래프 변화를 동기화하여 보여줘야 함. (예: '1단계 측정 → 2주 후 개선율 📈', 데이터 시각화 라이브러리 필수) |
| **CTA/결론부:** "본인이 어느 단계에 있는지 객관적으로 알고 싶다면..." | 4. **[행동 유도]** Gap Score의 *객관적 정의* 및 *취득 과정*. | '무료 진단 테스트 링크'만 제시됨. | **필수:** Gap Score가 단순히 점수가 아니라, **측정된 생리학적 문제점(근거)**을 나타낸다는 설명을 데이터 다이어그램으로 보여주어야 함. (신뢰도 확보) |

#### 2. 시각화 에셋 구현 최소 조건 정의 (Designer 지원)

| Data Point | 필요한 시각 효과 / 애니메이션 | 목표 역할 |
| :--- | :--- | :--- |
| **음정 주파수 편차 (Hz)** | 실시간 그래프(Waveform), 수치 텍스트 오버레이. 색상 코드화 필수 (빨간색: 위험, 노란색: 주의). | 시청자의 즉각적인 불안감 조성 및 문제의 심각성 강조. |
| **효율성 비교 지표 (%)** | 'Before'와 'After'를 명확히 분리하는 Bar Graph 또는 Spider Chart. 변화 폭(Delta)을 애니메이션으로 증폭하여 보여줌. | 추상적 개념을 측정 가능한 수치로 변환하여 객관성을 부여. |
| **단계별 성장 패턴 (📈)** | Time-Series Line Graph (시간의 흐름에 따른 주파수/음정 안정화 곡선). 점프(Jump) 효과를 통해 '진전'을 드라마틱하게 표현. | 시스템 활용의 동기부여와 연속적인 개선 과정을 시각적으로 확신시킴. |

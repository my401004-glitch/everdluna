# 🎬 마스터 비주얼 가이드라인: Diagnosis AI 코칭 시스템 (V1.0)

**📌 목표:** 영상의 전문성, 논리성, 경고성을 극대화하고, 모든 데이터 시각화 요소에 통일된 브랜드 아이덴티티를 부여하여 높은 신뢰도를 확보한다.
**👤 대상 독자:** 영상 편집자, Motion Graphics 디자이너.
**🎨 톤앤매너:** 전문적(Professional), 논리적(Logical), 미래지향적(Futuristic), 경고성(Warning).

## I. 브랜드 시스템 원칙 재확인 (The Core Rules)

### A. 컬러 팔레트 및 사용 규칙 [근거: Designer 검증된 지식]
| 이름 | Hex Code | 역할/상징 | 적용 영역 | 주의 사항 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary (신뢰)** | `#0A2463` | 전문성, 배경, 시스템의 기반. (Deep Blue) | 모든 제목 배경, 핵심 정보 박스, UI 프레임워크. | 강조 색상으로 과도하게 사용 금지. 주로 섹션 구분을 위해 사용. |
| **Accent (경고/기회)** | `#FFD700` | 위험(Pain), 기회(Gain), CTA 버튼. (Gold Yellow) | Gap Score의 'High Risk', RoC 그래프의 급상승 지점, 핵심 수치 강조. | **'빨간색 대체 금지'.** 경고는 노란색으로 처리하여 심각한 긴장감과 동시에 '개선 가능성(Opportunity)'을 암시해야 함. |

### B. 타이포그래피 시스템 [근거: Designer 검증된 지식]
*   **Headline (헤드라인):** Montserrat Bold (`[강렬함, 헤드라인 강조]`)
    *   사용 목적: 핵심 메시지(Pain/Gain)의 제목, 섹션 전환 시의 굵고 짧은 문구.
*   **Body (본문/데이터):** Noto Sans KR Regular/Medium (`[가독성 극대화]`)
    *   사용 목적: 데이터 수치, 그래프 설명, 내레이션에 사용되는 상세 텍스트.

### C. 시각적 요소 원칙 (Visual Philosophy)
1.  **미니멀리즘과 정보 밀도:** 모든 프레임은 복잡한 이미지를 배제하고, 오직 **데이터(숫자), 그래프, 명확한 문구**만으로 구성되어야 한다.
2.  **논리적 흐름 강조 (Pain $\rightarrow$ Gain):** 화면 전환 시 반드시 '문제 제기' → '원인 분석' → '해결책 제시'의 논리적 구조를 유지하며 애니메이션을 전개한다.
3.  **모션/애니메이션:** 모든 요소는 **'기술적으로 계산되는 느낌'**으로 움직여야 한다. (예: 그래프가 솟아오르는 것이 아니라, 데이터 포인트가 순차적으로 활성화되며 그려지는 방식).

## II. 핵심 컴포넌트 라이브러리 및 템플릿 정의

### A. [컴포넌트 1] Gap Score 위젯 (진단 시각화)
**[적용 시간]:** Part 2 (문제의 시스템 분석)
**[목표]:** 학습자의 현재 상태를 즉각적으로, 경고성으로 인식시킨다.
*   **구조:** 원형 게이지 또는 바 차트 형태. 중앙에 Gap Score 숫자가 크게 표시된다.
*   **색상 규칙:**
    *   `Gap > 70%`: **Accent Yellow (`#FFD700`) 배경, 경고 아이콘**. (가장 위험한 구간)
    *   `40% < Gap <= 70%`: **Dark Blue 테두리, 주의 표시.** (개선 필요 영역)
    *   `Gap <= 40%`: **옅은 Green/Blue 계열** (성장 단계). *단, 영상에서는 이 상태를 보여주지 않으므로 '미도달' 개념으로 활용.*
*   **애니메이션:** 숫자가 급격하게 증가하거나 하락하는 과정을 그래프로 시각화하며, 변화 폭이 클수록 애니메이션 속도를 빠르게 가져간다.

### B. [컴포넌트 2] RoC (Rate of Change) 성장 곡선 차트
**[적용 시간]:** Part 3 (성장 과정과 변곡점 제시)
**[목표]:** 성장이 '노력'이 아닌 '시스템 적용'의 결과임을 극적으로 보여준다.
*   **구조:** X축은 시간/세션, Y축은 측정된 지표(Score). 평탄하거나 느린 곡선(Pain)에서 급격히 상승하는 곡선(Gain)으로 대비시킨다.
*   **색상 규칙:**
    *   **Pain 구간 (초기):** 연한 회색 또는 낮은 채도의 Blue 계열을 사용하여 '정체'의 느낌을 준다.
    *   **Transition/Solution 적용 시점:** **Accent Yellow (`#FFD700`)로 점선 및 하이라이트 처리.** 이 지점에서 그래프가 급격히 꺾여 상승해야 한다.
    *   **Gain 구간 (최종):** Dark Blue를 기반으로 강하고 안정적인 곡선을 그려 '지속 가능한 성장'을 상징한다.
*   **애니메이션:** 트레이딩 차트처럼, 데이터 포인트가 순차적으로 연결되며 선이 그려지는 효과(Drawing Effect)를 사용한다.

### C. [컴포넌트 3] 문제 제기 (Pain Point) 와젯
**[적용 시간]:** Intro 및 Part 1
**[목표]:** 시청자에게 '지금의 방식으로는 안 된다'는 위기의식을 주입한다.
*   **구조:** 강한 대비를 주는 블랙/다크 블루 배경 위에, 충격적인 데이터 통계나 질문이 크게 배치된다. (예: "월평균 30% 손실", "데이터 부재의 위험")
*   **폰트 사용:** Montserrat Bold를 최대 크기로 사용하여 임팩트를 준다.
*   **모션 효과:** 텍스트가 화면에 '타격'되거나, '경고음과 함께 깜빡이는(Flicker)' 애니메이션을 적용하여 긴장감을 유지한다.

## III. 에셋 활용 및 제작 체크리스트 (Production Checklist)

| 항목 | 내용 | 담당자 확인 | 비고 |
| :--- | :--- | :--- | :--- |
| **[ ] 로직 연결성** | Gap Score의 'Phase 1: Crisis' 상태 변화 시, 해당 지점의 UI Mockup이 반드시 영상에 반영되었는가? | Designer / Coder | 모든 기술적 정의를 시각화해야 함. |
| **[ ] 데이터 출처 명시** | 화면에 나오는 모든 수치(통계)에는 (출처: [학습자 통계] 등)을 작은 글씨로 반드시 표시한다. | Editor | 신뢰도 확보의 필수 요소. |
| **[ ] 전환 효과 통일성** | 챕터가 넘어갈 때마다 배경색이나 폰트 스타일이 무작위로 바뀌지 않도록, 항상 `#0A2463`을 기반으로 하는 시그니처 트랜지션(Transition)을 사용한다. | Editor |
| **[ ] CTA 강조** | 최종 결론 도출 및 솔루션 제시 직전의 15초 동안은 Accent Yellow (`#FFD700`)를 최대화하여 시청자의 시선과 집중도를 최고조로 끌어올린다. | Designer / Editor | 마지막 승부처.

# 🎬 최종 시각적 실행 가이드라인 (Visual Execution Manual)

**프로젝트:** 실용음악 AI 활용 프로그램 교육 콘텐츠
**브랜드 컨셉:** 좌절에서 승리로의 변곡점 (Pain $\rightarrow$ Gain)
**목표:** 모든 영상 제작팀이 일관성 있게 '신뢰'와 '행동 유도'를 시각적으로 구현하도록 지침 제공.

## 1. 브랜드 비주얼 시스템 (Brand Visual System) 확정

모든 영상 자산은 아래의 색상, 타이포그래피 규칙을 엄격하게 준수해야 합니다.

| 요소 | 역할 | 색상 코드 / 폰트명 | 적용 목적 및 효과 |
| :--- | :--- | :--- | :--- |
| **Primary Color (신뢰/안정)** | 배경, 주요 정보 영역, 신뢰 구축 | Dark Blue (`#0A2463`) | 전문성과 안정감을 극대화하여 데이터에 대한 신뢰를 구축합니다. |
| **Accent Color (행동 유도/기회)** | CTA 버튼, 이탈 위험 표시(Pain), 핵심 Gain 수치 강조 | Accent Yellow (`#FFD700`) | 즉각적인 시선 집중 및 행동 유도를 위해 사용됩니다. |
| **Background/Data** | 본문 텍스트 배경, 데이터 영역 구분 | Neutral Grey (`#F5F5F5`) | Dark Blue와의 명확한 대비를 통해 가독성을 극대화합니다. |
| **Title Typography** | 핵심 헤드라인 (Pain, Gain) 강조 | Montserrat Bold | 강력한 메시지 전달력 확보. 시각적 임팩트 제공. |
| **Body Typography** | 데이터 및 상세 설명 텍스트 | Noto Sans KR | 높은 가독성을 보장하여 정보 전달력을 높입니다. |

## 2. 아트워크 세트 적용 지침 (Artwork Set Application Guide)

모든 영상 내의 인서트, 그래픽 오버레이, 텍스트 박스 등은 위 시스템을 기반으로 제작되어야 합니다.

1.  **Pain/Risk 시각화:**
    *   위험(Pain)을 나타내는 모든 요소(예: 손실 수치, 좌절 상태 이미지)는 **Accent Yellow (`#FFD700`)** 톤을 주조색으로 사용하며, 배경은 **Dark Blue (`#0A2463`)** 또는 **Neutral Grey (`#F5F5F5`)** 위에 배치하여 위험성을 강조합니다.
    *   텍스트는 **Montserrat Bold**로 처리하여 경고 메시지를 즉각적으로 인식하게 합니다.

2.  **Gain/Solution 시각화:**
    *   이득(Gain)이나 솔루션(해결책)을 제시하는 모든 요소(예: 성공 수치, 최종 결과물 이미지)는 **Dark Blue (`#0A2463`)**를 주조색으로 사용하여 신뢰감을 부여합니다.
    *   핵심 성과 지표(KPI)는 **Accent Yellow (`#FFD700`)**을 사용하여 시청자의 시선을 즉시 끌어당기고 행동을 유도합니다.

## 3. 사운드 및 비주얼 우선순위 매핑 (Audio-Visual Priority Mapping)

영상 내의 시각적 전환은 오직 사운드의 **감정적 흐름(Emotional Arc)**과 **템포**에 완벽히 동기화되어야 합니다.

| 사운드 구간 | 감정적 흐름 | 비주얼 연출 지침 (Visual Cue) | 핵심 타이밍 요구사항 |
| :--- | :--- | :--- | :--- |
| **Pain Phase (초반)** | 불안, 좌절, 고통 | 어둡고 차가운 톤 (`#0A2463`, `Neutral Grey`). 화면은 정지된 듯한 느낌 부여. | 긴 호흡 유지, 느린 페이드 인/아웃 사용. |
| **Turning Point (변곡점)** | 깨달음, 전환의 시작 | **Accent Yellow (`#FFD700`)**이 폭발적으로 등장하며 대비 강조. 화면에 빠른 컷 전환 또는 강력한 그래픽 애니메이션 삽입. | 사운드 클라이맥스와 정확히 동기화하여 시각적 충격 극대화. |
| **Gain Phase (후반)** | 자신감, 성취, 확신 | 밝고 명확한 톤 (`#0A2463` 중심). 데이터 및 결과물을 강조하는 깔끔한 레이아웃 제시. | 안정적인 페이드 인/아웃, 정보의 가독성 극대화. CTA는 **Accent Yellow**로 최종 강조. |

## 4. 썸네일 컨셉 표준화 (Thumbnail Concept Standardization)

향후 모든 썸네일은 아래 세 가지 핵심 요소를 반드시 포함해야 합니다.

1.  **Pain Visual:** 화면의 1/3 지점에 `Accent Yellow`을 사용하여 현재의 고통이나 문제점을 시각적으로 강조합니다.
2.  **Gain Statement:** 중앙 또는 상단에 **Montserrat Bold**로 명확하고 강력한 해결책(Gain) 문구를 배치합니다.
3.  **Brand Anchor:** 전체 배경은 **Dark Blue (`#0A2463`)** 또는 **Neutral Grey (`#F5F5F5`)**를 사용하여 브랜드 신뢰도를 유지합니다.

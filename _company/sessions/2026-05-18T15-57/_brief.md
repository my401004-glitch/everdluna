# 📋 작업 브리프

**원 명령:** 학원·교육기관용 “학생 성장 리포트 자동 생성 AI” 를 만들건데 주요 기능:

* 수업 후 선생님이 3줄만 입력
* AI가 학부모용 리포트 생성
* 학생별 성장 히스토리 저장
* 다음 수업 과제 자동 추천
* 결석/지각/태도/성과 기록
* 월말 상담 리포트 자동 생성
* 재등록 가능성 위험 학생 표시
 위의 내용이 실행가능하도록 개발해줘

## 요약
학원/교육기관용 학생 성장 리포트 자동 생성 AI 시스템 개발을 위한 기능 정의 및 기술 설계 작업을 시작합니다.

## 분배
- **💼 현빈**: 제시된 7가지 주요 기능(수업 입력, 리포트 생성, 히스토리 저장, 과제 추천, 기록, 상담 보고서, 위험 학생 표시)의 비즈니스 가치 및 유료화 전략에 따른 핵심 KPI와 수익 모델 초안을 설계하세요.
- **🔍 Researcher**: 실용음악/학습 분야에서 '학생 성장'과 관련된 가장 중요한 정성적/정량적 지표(KPI) 목록과 학부모가 중요하게 생각하는 리포트 구성 요소를 조사하고 정리하세요.
- **💻 코다리**: 위의 기능들을 지원하기 위한 핵심 데이터 모델(학생, 수업 기록, 성과/태도 로그, 과제 추천 로직)을 설계하고, API 엔드포인트 및 DB 스키마 개선안을 제안하세요.
- **✍️ Writer**: 선생님이 입력한 3줄의 수업 후 피드백을 바탕으로 학부모에게 전달할 수 있는 '성장 리포트'의 감성적 서사 흐름(Narrative Flow)과 구체적인 보고서 템플릿 초안을 작성하세요.
- **🎨 Designer**: 데이터 기반 성장 히스토리와 위험 학생 표시 결과를 학부모가 직관적으로 이해할 수 있도록 시각화하는 리포트의 핵심 와이어프레임(Wireframe) 구조를 설계하세요.

### 📋 [최종 목표 산출물] 콘텐츠 실행 청사진 (Execution Blueprint)

#### 1. 핵심 주제 및 컨셉 재확인
*   **Pain Point:** 학원 운영자들은 '노력'과 '시간 투자'에 집중하지만, 실제 문제는 **데이터 기반의 이탈 예측 및 비효율적인 자원 배분(ROI 저하)**입니다. [근거: 레오 개인 메모리]
*   **Gain/Solution:** 아지트아트컴페니의 AI 진단 리포트를 통해 '숫자로 증명되는 운영 개선 방안'을 제시합니다.
*   **톤앤매너:** 전문가 컨설턴트 (권위적, 냉철한 데이터 분석)

#### 2. 스토리보드 초안: "이탈 예측 시스템" 구현 과정
이번 콘텐츠는 단순 지식 전달이 아니라, **문제 인지 $\rightarrow$ 문제 증명 $\rightarrow$ 해결책 제시**의 기술적인 퍼널을 따라가야 합니다.

| 단계 | 시간 (예상) | 내용 및 목적 | 시각적 강제 요소 (Must-Use Component) |
| :--- | :--- | :--- | :--- |
| **훅(Hook)** | 0:00 ~ 0:30 | 충격적인 통계 제시. "당신의 학원, 이 지표 때문에 매달 돈을 잃고 있습니다." (문제 제기) | **[Critical Score Display]** - 빨간색 경고등 + 구체적 수치 (예: 72% 이탈 확률). 데이터가 갑자기 화면에 폭발적으로 등장하는 모션. |
| **본론 1:** 문제 정의 | 0:30 ~ 2:00 | 운영자들의 '잘못된 자원 배분' 루틴 지적 (예: 무조건적인 스터디 시간 확보). 데이터로 증명하며 비효율성 강조. | **[System State: Warning]** - 노란색 경고창 등장. "주의! 이 활동은 ROI 기여도가 낮습니다." |
| **본론 2:** 원인 분석 (핵심) | 2:00 ~ 3:30 | '이탈 시점'의 핵심 데이터 포인트(예: 과제 제출 주기, 특정 영역 점수 하락 곡선)를 보여주며 학원 운영자의 사각지대를 지적. | **[DiagnosisScoreDisplay]** - 실시간으로 변화하는 그래프와 함께, 위기 징후가 빨간색 위험 구간에 들어가는 애니메이션. (Designer/Kodari 컴포넌트 활용 필수) |
| **클라이맥스:** 해결책 제시 | 3:30 ~ 4:30 | "이 모든 것을 시스템으로 예측할 수 있습니다." 우리 서비스의 핵심 가치(AI 리포트, 이탈 예측 모델)를 소개. | **[Master Component Library]** - 컴포넌트가 깔끔하게 정렬되며 '해결책'을 제시하는 청색 계열 애니메이션 전환. (신뢰감 구축) |
| **CTA:** 행동 요청 | 4:30 ~ END | "직접 진단해보세요." 무료 컨설팅/진단 프로그램 신청 유도. | **[Primary Action Button]** - CTA 버튼이 명확하게 강조되면서 애니메이션으로 활성화됨. (트랜지션 매끄러움 필수) |

#### 3. 제목 후보 5가지 및 Hook 전략
제목은 반드시 '문제 제기형'과 '구체적 수치 제시'를 결합해야 합니다. [근거: 레오 개인 메모리]

1.  **[경고] 이 학생, 3개월 뒤에 학원을 떠날 확률이 72%입니다. 원인이 궁금하신가요?** (문제 제기 + 구체적 수치)
    *   *Hook:* 시작하자마자 '72%'라는 숫자를 화면 가득 보여주며 공포심 유발.
2.  **[속지마세요] 학원 운영에 시간 낭비하는 '숨겨진 활동' 3가지. 원장님도 빠질 수 있습니다.** (부정적 키워드 + 리스크)
    *   *Hook:* "혹시 지금 이 루틴을 반복하고 계신가요?"라며 시청자가 자신의 행동을 돌아보게 만듦.
3.  **데이터로만 본 학원 운영의 '진짜 ROI'를 알려드립니다. (이거 모르면 손해 봅니다)** (전문성 + 금전적 이익)
    *   *Hook:* "감성으로 하던 학원 운영, 이제 숫자로 해야 할 때입니다."라며 패러다임 전환을 강요.
4.  **[STOP] 성적이 안 오르는 진짜 이유: 원인은 '여기'에 있습니다.** (직접적 금지 + 호기심 유발)
    *   *Hook:* 특정 영역(예: 시간 배분, 취약점 분석)의 데이터를 줌인하며 시각적인 긴장감 조성.
5.  **AI가 예측한 학생 이탈 전조 증상 리포트 (원장님 필독)** (권위 + 타겟 명확화)
    *   *Hook:* '리포트'라는 단어를 사용하여 전문성을 극대화하고, 마치 내부 자료를 훔쳐보는 듯한 느낌을 부여.

#### 4. 시각적 일관성 최종 점검 체크리스트 (Actionable Check)
다음 콘텐츠 제작 시 반드시 이 항목들을 검토해야 합니다. [근거: Designer/Kodari 작업 흐름]

*   [ ] **색상:** 전체 영상의 '위험 지표'는 무조건 빨간색(Critical Red), '정상 데이터'는 청록색(Trust Blue) 계열을 유지할 것. (V4.0 사양 준수)
*   [ ] **전환 애니메이션:** 화면 전환 시, 단순 페이드인아웃이 아닌 `Motion Component System Guide`에 정의된 부드러운 '데이터 플로우' 전환 효과를 적용하여 전문성을 높일 것.
*   [ ] **정보 밀도:** 텍스트가 많이 나오는 슬라이드는 지양하고, 대신 컴포넌트화된 그래프나 수치(예: Score Display)를 통해 정보를 압축적으로 전달할 것.

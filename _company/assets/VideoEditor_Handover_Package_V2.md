# 📹 최종 영상 편집자 기술 지침서: Diagnosis Score 동적 로직 (V2)

**[버전]**: V2.0
**[작성 목적]**: 데이터(Gap Score, RoC)의 상태 변화에 따라 모든 미디어 에셋이 어떻게 반응해야 하는지 정의합니다. 단순한 스크립트 구현을 넘어, 시스템의 *동적 동작 원리*를 시각적으로 구현하는 것이 목표입니다.

## 1. 핵심 지표 및 정의 (KPI & Metrics)
| 지표 | 정의 | 측정 단위 | 비고 |
| :--- | :--- | :--- | :--- |
| **Gap Score** | 현재 능력과 이상적 기준 간의 격차 비율. (0% ~ 100%) | % | 핵심 진단 수치. 낮을수록 위험/개선 필요. |
| **Rate of Change (RoC)** | 일정 기간 동안의 성장률 변화율. (긍정/부정) | % / Period | '성장하는 것' 자체를 증명하는 지표. |

## 2. 핵심 로직: Gap Score 상태 머신 (State Machine Logic)
Gap Score는 세 가지 주요 상태(Phase)로 구분되며, 각 상태에 맞는 **시각적/청각적 반응**을 의무적으로 포함해야 합니다.

| State Phase | Gap Score 범위 (기술 기준) | 내레이션 톤 & 핵심 메시지 | 필수 시각 에셋 로직 (Video Editor Guide) |
| :--- | :--- | :--- | :--- |
| **Phase 1: Crisis (위기)** | **0% ~ 25%** (Critical Gap) | **경고성, 단호함.** "지금은 감으로 할 때가 아닙니다. 데이터적 위험 신호입니다." | ⚠️ **색상:** Red/Dark Blue 계열의 경고조명 효과 필수. <br>💡 **그래프:** 급격한 하강 애니메이션 + 불안정한 노이즈 효과 적용. <br>🎵 **사운드:** 낮게 깔리는 불협화음(Dissonance) 사운드 디자인. |
| **Phase 2: Transition (전환)** | **25% ~ 60%** (Actionable Gap) | **논리적, 교육적.** "데이터를 기반으로 구체적인 '행동'을 설계해야 합니다." | 🔧 **색상:** Accent Yellow(경고/기회)가 주도. <br>💡 **그래프:** 점진적인 상승 곡선 애니메이션 (RoC 개선 과정 시각화). <br>🎵 **사운드:** 리듬감 있는 비트와 집중력을 높이는 사운드. |
| **Phase 3: Mastery (성취)** | **60% ~ 100%** (Minimal Gap) | **확신, 희망적.** "객관적인 데이터가 당신의 성장을 증명합니다." | ✅ **색상:** Primary Trust Blue/Bright Gold 계열. <br>💡 **그래프:** 안정적이고 가파른 우상향 곡선 애니메이션 + 완료(Completion) 이펙트. <br>🎵 **사운드:** 웅장하고 해결되는 듯한 화음(Resolution Chord). |

## 3. 에셋별 기술 요구사항 (Asset Implementation Checklist)

### A. Gap Score 위젯 (Widget)
1.  **애니메이션 구현**: 점수가 바뀔 때, 단순히 수치만 바뀌는 것이 아니라, 마치 **'물리적인 간격이 메워지는 듯한(Gap-closing)' 시각적 애니메이션**을 적용해야 합니다.
2.  **상태 변화 트리거**: 반드시 Phase 1 $\rightarrow$ Phase 2 $\rightarrow$ Phase 3으로의 전환에 맞는 *시각적 임계점*이 존재함을 강조합니다.

### B. 데이터 흐름 (Data Flow)
1.  진단 과정(Test $\rightarrow$ Analysis $\rightarrow$ Report) 전체를 하나의 **데이터 파이프라인 애니메이션**으로 표현하여, '마법'이 아닌 '시스템'임을 각인시킵니다.
2.  API 호출 및 DB 검증 과정을 간단한 다이어그램으로 삽입하여 기술적 신뢰도를 높입니다.

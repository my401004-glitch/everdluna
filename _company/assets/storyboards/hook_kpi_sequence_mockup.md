# 🎬 Hook Sequence Storyboard: Pain $\rightarrow$ Gain (10초 분량)
**[목표]**: 시청자의 가장 큰 문제(Pain)를 극대화하여 인식시키고, 우리 프로그램이 유일한 해결책(Gain)임을 각인시킨다.

| Time Code | Visual Element / Scene | Animation Spec (애니메이션 사양) | Audio/Narration Script |
| :--- | :--- | :--- | :--- |
| **0s - 2s** | **[SCENE 1: Pain 제시]** 배경은 어둡고 불안한 느낌의 Dark Blue (`#0A2463`)를 사용. | 화면 중앙에 "당신의 현재 실력, 이대로 괜찮으십니까?" 타이틀 등장 (Montserrat Bold). 그 아래 Gap Score 표시기가 `#D9534F` 색상으로 크게 깜빡이며 나타남. | **N:** (낮고 불안한 톤) "아직 목표 점수까지 남은 간극이 너무 커 보이나요?" |
| **2s - 4s** | **[SCENE 2: Gap 시각화]** KPI 모듈의 그래프가 급격히 낮은 지점에 머무름. | 그래프 라인이 수평에 가깝게 (낮은 수준) 유지되다가, 목표치(Goal Line)와 간극이 표시됨. 이 간극을 `[GAP]` 텍스트로 크게 강조하며 `#D9534F` 색상으로 깜빡임. | **N:** "막연한 노력으로는 채울 수 없는, 구조적인 Gap입니다." |
| **4s - 6s** | **[SCENE 3: 전환점/문제 제기]** 강렬한 시각적 충격(화면 정지 및 사운드 급변). | 화면 전체가 잠깐 어두워졌다가, 중앙에 `SYSTEM ERROR`와 유사한 경고창이 `#FFD700`의 네온 느낌으로 팝업됨. 이어서 "문제는 당신에게 있지 않습니다." 문구가 타이포그래피로 부각됨 (Montserrat Bold). | **N:** (극적인 사운드 효과) *정적.* "진짜 문제는, 어떤 데이터를 활용하고 있는지입니다." |
| **6s - 10s** | **[SCENE 4: Gain 제시 및 CTA]** 밝고 전문적인 `#0A2463` 배경으로 전환. | KPI 모듈이 재구성됨. 그래프 라인이 급상승하며, Gap Score가 노란색(`#FFD700`)으로 채워지는 애니메이션을 보여줌. 최종적으로 'ROI: 30% 상승' 등의 구체적인 수치가 명확하게 강조됨. | **N:** (자신감 있는 톤) "우리는 오직 데이터로 Gap을 메웁니다. 바로 이 시스템이 답입니다." |

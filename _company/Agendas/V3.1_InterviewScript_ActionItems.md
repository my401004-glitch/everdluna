# 🚀 V3.1: 리스크 기반 진단 스크립트 고도화 및 데이터 매핑
## 목표
실제 파일럿 고객(학원 운영자)을 대상으로, 우리의 AI 시스템이 대체할 수 있는 **'수치화된 재정/운영적 Pain Point'**를 발굴하는 인터뷰 스크립트를 완성하고, 이 대화가 곧 DB에 저장될 데이터 필드 구조까지 정의한다.
## 담당 에이전트 및 역할
1.  **현빈 (Business):** Pain Point 자극형 질문지(최소 10개) 작성 (ROI/손실 관점).
2.  **코다리 (Developer):** 현빈의 질문을 기반으로 데이터 수집 API 스키마 설계 (Schema Definition).
## 핵심 산출물

- Data Field Mapping Sheet (질문 $\rightarrow$ 답변 필드명 $\rightarrow$ 데이터 타입)

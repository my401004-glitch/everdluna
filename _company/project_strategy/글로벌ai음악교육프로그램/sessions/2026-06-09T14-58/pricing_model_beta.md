# 💰 유료 베타 테스트용 가격 모델 (Pricing Model) 및 KPI 확정안

**작성일:** 2026.06.09  
**작성자:** 현빈 (비즈니스 전략가)  
**목표:** 초기 사용자 확보 + 가치 증명 → 유료 전환 파이프라인 완성

---

## 🎯 핵심 원칙
- **무료 진단 테스트 (Free Gap Score)**를 모든 진입점의 허브로 활용하여, 사용자의 '성장 욕구'와 '불안감'을 자극 후 해결책을 제시하는 구조.
- **단일 구독 모델**보다는 **번들(Starter Pack) + 월도 subscription** 병행으로 CAC(고객 획득 비용) 을 낮추고 LTV(Life Time Value)를 높이는 전략.

---

## 💵 가격 모델 안 (A/B/C) 비교 분석

| 항목 | 안 A: 기본 구독 | 안 B: 번들 (Starter Pack) + 월 구독 | 안 C: 진단 테스트 기반 전환 |
| :--- | :--- | :--- | :--- |
| **월 구독료** | ₩39,000 | ₩39,000 | 무료 (진단 결과만 제공) |
| **초기 결제 유도** | X | ✅ 10% 할인 (3 개월 치) | ❌ 유료 구매 아님 |
| **주요 혜택** | - AI 진단 리포트 다운로드<br>- 성장 대시보드 접근<br>- 최신 모듈 업데이트 | - 기본 구독 모든 기능 +<br>Starter Pack(할인)<br>우선 고객 지원 | - Gap Score 결과 보고서<br>- "개선 과제 3 가지" 제안<br>- 유료 모듈 구매 유도 CTA |
| **CAC 영향** | 높음 (구독료만 의존) | 낮음 (할인으로 초기 결제 장벽 낮춤) | 매우 낮음 (무료 진입으로 유입 확대) |
| **LTV 기대치** | 보통 (단순 구독) | 높음 (장기 할인 패키지 유지 시) | 평균 (유도 전환율에 의존) |
| **추천 타겟** | 성인 학습자, 충성도 높은 사용자 | 입시생 (초기 현금 흐름 필요), 부모님 지원 | 모든 잠재 고객 (진입 장벽 제거) |

### ✅ 최종 추천: 안 B (번들 + 월 구독 병행)
**이유:**  
1.  **Starter Pack(3 개월 치 할인)**은 초기 현금 흐름을 확보하면서도, 사용자가 '3 개월'이라는 긴 기간 동안 제품을 경험하게 함으로써 이탈률을 낮출 수 있음.  
2.  **월 단위 구독 (₩39,000)**은 진입 장벽이 낮아, 입시생의 학부모나 본인도 부담 없이 결제할 수 있는 금액임.  
3.  **안 C(무료 진단 테스트)**는 파이프라인의 시작점이며, 안 B 로의 전환율을 높이기 위한 '후크' 역할만 하면 됨.

## 📊 핵심 지표 (KPI) 및 목표치 (베타 테스트 기간: 1 개월)

| KPI | 목표치 | 측정 이유 |
| :--- | :--- | :--- |
| **진단 테스트 전환율** | 40% 이상 | 무료 Gap Score 결과를 보고, 유료 구독을 구매하는 비율. (예: "이 정도 레벨이라면 월 ₩39,000 에 충분합니다") |
| **안 B(번들) 구매 비율** | 60% 이상 | 초기 결제 시 Starter Pack(할인 패키지) 선택 비율. (할인을 안 한 단순 구독 대비 2 배의 LTV 기대치) |
| **평균 사용일수 (D7 Retention)** | 35 일 이상 | 베타 기간 내에도 계속 사용하는 사용자의 비율. (단순히 다운로드만 하고 사라지는 사용자 제외) |
| **NPS(추천 의지)** | +50 점 이상 | "친구나 다른 입시생에게 이 툴을 추천하고 싶은가?" 질문으로 측정. (제품 만족도와 관련됨) |

## 🚀 베타 테스트 실행 로드맵

### 1 단계: 진입점 설계 (Free Gap Score)
- **동기화:** YouTube, Instagram 등 모든 채널에서 영상 끝부분에 "무료 진단 테스트" CTA.  
- **결과:** 사용자는 자신의 'Gap Score'와 '개선 과제 3 가지'를 받음.  
- **전환 유도:** 결과 페이지 하단에 "이 정도 레벨이라면, Starter Pack(할인) 을 추천합니다" 버튼 배치.

### 2 단계: 가격 모델 적용
- **결제 페이지:** 월 구독 (₩39,000) 과 번들 (₩10% 할인 + 3 개월 치) 동시 노출.  
- **상담:** 유료 코칭은 베타 기간에는 무료인 'AI 진단 리포트'로 대체하여, 인간 코치는 후기에 집중.

### 3 단계: KPI 모니터링 및 조정
- **주간 점검:** 전환율이 목표치 이하라면, Gap Score 결과 페이지의 CTA 문구를 수정하거나, 할인율을 더 낮추는 등 A/B 테스트 수행.  
- **이탈 분석:** D7 Retention 이 낮다면, 성장 대시보드의 '성장 추적' 기능을 강화하여 사용자의 성취감을 높임.

**[최종 Goal]**: 진단을 통해 사용자의 현 상태가 심각한 Gap을 가지고 있음을 경고하고, 프리미엄 코칭 서비스(솔루션)로의 전환을 유도하는 '경고/깨달음' 톤앤매너를 확립합니다.
**[타겟 시청자]**: 실용음악 입시 준비생 (Pain Point: 막연한 노력 대비 불확실한 성과).
**[영상 포맷]**: 16:9 비율, [최종 결정 사양].

## ⚙️ 시스템 작동 로직 요약 (State Machine)
본 위젯은 사용자가 진단 항목에 응답할 때마다 점수가 실시간으로 변화하며, 이 상태 변화(State Transition)가 곧 스토리의 핵심입니다.

| State | Score Range | 의미 / 감정적 해석 | 시각적 톤 & 색상 코드 | 주된 액션 (Trigger) |
| :---: | :---: | :---: | :---: | :---: |
| **State A (무지성 노력)** | Low (0-30점) | '감'에 의존하는 상태. 문제 인식률 최저. 위협적 경고 발생. | 🔴 Deep Red / 어두운 명암 대비 (경고, 위험) | 진단 시작 / 초기 데이터 입력 |
| **State B (부분 인지)** | Mid (31-70점) | 일부 문제는 파악했으나 시스템화가 안 된 상태. 혼란과 불안정함. | 🟠 Amber / 경고색 조합 (주의, 점검 필요) | 특정 KPI 영역 진단 완료 |
| **State C (시스템 구축)** | High (71-100점) | 객관적 데이터와 체계적인 방법론을 이해한 상태. 해결책 제시 단계. | 🟢 Emerald Green / 밝고 안정적인 명암 대비 (확신, 성장) | 최종 진단 결과 및 솔루션 노출 |

## 🎬 스토리보드 & 에셋 제작 상세 지침
전체 영상은 **State A $\rightarrow$ State B $\rightarrow$ State C**의 흐름을 따르는 '문제 제기 → 문제 심화 → 해결책 제시' 구조여야 합니다.

### Phase 1: 도입 (State A - 위협/경고)
*   **[내레이션]**: "지금까지의 노력, 혹시 감으로 하고 계신가요? 데이터로 증명된 당신의 진짜 문제는..." (Pain Point 극대화)
*   **[핵심 시각 요소]**: **진단 점수 게이지(Gauge)**가 🔴 Deep Red 영역에 머무르며 불안정하게 떨리는 모습. 배경은 어둡고, 'Gap Score'라는 키워드만 강렬한 빛으로 강조되어야 합니다.
*   **[제작 지침]**: 위젯의 UI는 실제 데이터 흐름을 반영하여, 점수가 **불안정한 그래프 형태**로 나타나도록 애니메이션 처리합니다.

### Phase 2: 문제 심화 (State B - 혼란/진단)
*   **[내레이션]**: "노력 자체는 문제가 아닙니다. 문제는 '어디'에 힘을 빼고, '무엇'을 측정하지 못했는지 아는 것이 부재하다는 겁니다." (문제의 본질 제시)
*   **[핵심 시각 요소]**: 점수 게이지가 🟠 Amber 영역으로 이동하며, 진단 항목들이 **'Growth', 'Engagement', 'Monetization'** 세 가지 키워드로 분할되어 나타납니다. 각 키워드가 마치 미스터리처럼 하나씩 밝혀지는 효과를 사용합니다.
*   **[제작 지침]**: 이 단계에서는 복잡한 데이터 흐름을 단순화해야 합니다. (예: 3D 다이어그램, 플로우차트 애니메이션 활용).

### Phase 3: 해결책 제시 (State C - 깨달음/솔루션)
*   **[내레이션]**: "데이터 기반의 체계적인 진단만이 당신을 다음 단계로 이끌 수 있습니다. 이제, 과학적 시스템으로 변화할 때입니다." (CTA 유도)
*   **[핵심 시각 요소]**: 점수 게이지가 🟢 Emerald Green 영역에 도달하며 안정적으로 상승하는 모습을 보여줍니다. 화면 전체에 '시스템'과 '성장 로드맵'을 의미하는 깔끔하고 미래지향적인 UI가 오버레이 됩니다.
*   **[제작 지침]**: 마지막에는 **프리미엄 구독/코칭 서비스 가입 CTA 버튼**이 크고 명확하게, 마치 시스템의 최종 출력을 보여주듯이 배치되어야 합니다.

## 🚨 기술적 제약 사항 (Technical Constraints) - [필독!]
영상 제작 시 반드시 다음 코딩 원칙을 준수해야 하며, 이는 단순히 '요청'이 아닌 **시스템 요구사항**입니다.

1.  **데이터 일관성 유지**: 화면에 나오는 모든 점수 변화(Low $\rightarrow$ Mid $\rightarrow$ High)는 실제 State Machine 로직의 전이를 반드시 시각적으로 따라가야 합니다. (기술 사양서: `diagnosisController.ts` 참조).
2.  **KPI 강조 원칙**: 'Growth', 'Engagement', 'Monetization' 세 가지 KPI가 분리되어 다뤄지고 있음을 잊지 마세요. 이들이 영상의 주요 빌드업 요소입니다.
3.  **애니메이션 제어**: 점수 변화 애니메이션은 갑작스럽거나 과장되어서는 안 되며, **데이터 분석 보고서가 움직이는 듯한** 신뢰감 있는 모션(Smooth Interpolation)을 사용해야 합니다. (화려함 > 신뢰도).

### 1. 🎭 역할 및 페르소나 설정 (Persona & Role)

**[역할]** 당신은 **'데이터 기반 성장의 아키텍트(Architect of Growth)'**이자, **'감성적 몰입을 유도하는 스토리텔러(Narrative Storyteller)'**입니다.

**[톤앤매너]**
*   **기술적:** 데이터 기반, 객관적, 명확하고 구체적이며 논리적입니다. (Gap Score, Hz, 패턴 등을 적극 사용)
*   **감성적:** 공감 능력이 뛰어나며, 불안감을 인정하고 이를 성장 동력으로 전환시키는 따뜻하고 지지적인 코칭을 제공합니다.
*   **전환점 강조:** '노력' 대신 **'시스템'과 '증명'**을 강조하며 행동(Action)을 유도합니다.

### 2. ✨ 핵심 철학 (Core Philosophy)

**"감성은 연료, 데이터는 항법이다."**

1.  **객관성 우선주의:** 모든 음악적 현상은 주관적인 느낌이 아닌, 측정 가능한 **데이터(Hz, 편차, 패턴)**로 정의되어야 하며, 이 데이터가 학습의 유일한 진실(Truth)입니다.
2.  **시스템 중심 접근:** '노래를 잘 부르는 법'이라는 모호한 목표 대신, **'A 측정 → B 교정 → C 최적화'**라는 명확하고 실행 가능한 시스템을 제시합니다.
3.  **성장의 시각화:** 학습 과정은 단순한 지식 습득이 아니라, **지속적인 성장 곡선(Growth Curve)**으로 표현되어야 하며, 사용자는 자신의 발전 과정을 눈으로 확인하며 몰입해야 합니다.

**[핵심 지표 (KPIs)]**

**[주요 State Transitions]**

본 문서는 DiagnosisScoreWidget 시스템의 각 상태(Phase)에 정확히 매핑되는 영상 스크립트, 시각적 요구사항, 그리고 외부 편집자를 위한 최종 내러티브를 담고 있습니다. 모든 콘텐츠는 '좌절에서 승리로의 변곡점'이라는 감성적 흐름과 객관적인 데이터 증명을 극대화하는 데 중점을 둡니다.

---

## 🧭 시리즈 핵심 메시지 및 톤앤매너 (Global Guidelines)

*   **핵심 테마:** 노력 대비 성과 측정 시스템 부재로 인한 재무적 손실 경고 $\rightarrow$ AI 기반 객관적 진단으로 성장 승리로의 변곡점.
*   **톤앤매너:** 전문적, 논리적, 미래지향적이며 동시에 강력한 경고(Warning) 톤을 유지합니다. 감성적인 위로보다는 **시스템과 데이터가 제시하는 명확한 해결책**에 집중합니다.
*   **시각 컨셉:** 기술적 안정감(코다리/디자이너 산출물)을 시각적으로 강조하며, 불안정함(Crisis)에서 명료함(Clarity)으로 전환되는 흐름을 역동적으로 표현해야 합니다.

---

## 📊 영상별 상세 내러티브 및 가이드라인

### 🎥 **Module 1: Phase 1 - Crisis (위기 단계)**
**목표:** 시청자의 현재 고통과 무력감을 극대화하여 시스템 도입의 필요성을 절감하게 한다. (Hooking & Pain Point Maximization)

| 항목 | 상세 내러티브 (Voiceover Script 초안) | 시각적 요구사항 (Visual Direction) | 핵심 후킹 카피 (On-Screen Text) |
| :--- | :--- | :--- | :--- |
| **후크** | "혹시 지금 연습하는 발성 루틴이 **'듣는 사람'의 귀에는 안 들리는 소리**로 변하고 있다면요? 당신은 지금 '노래를 부르는 것'이 아니라, 그냥 '소리를 내는 법'만 배우고 있는 겁니다." | 불안정하게 흔들리는 음파 그래프. 어둡고 긴장감 있는 색감(Deep Blue/Red). 빠르게 깜빡이는 오류 메시지 효과. | **"당신의 노력은 왜 성과로 이어지지 않는가?"** |
| **본문 (Gap)** | "감성 표현을 위한 무작정 감정 이입은 위험합니다. 기술적 안정감이 받쳐주지 못하면, 그 감성은 곧 불안정한 소리로 변합니다. 당신의 음정 편차가 몇 Hz나 벗어나 있는지 객관적으로 알아야 합니다." | '노력'이라는 추상적인 개념과 실제 주파수(Hz) 데이터가 충돌하는 시각적 대비. 불균형한 공명 영역을 보여주는 다이어그램. | **"감성 vs. 기술: 당신의 소리는 불안정합니다."** |
| **CTA (전환)** | "더 이상 감에 의존하지 마십시오. 이제 우리는 '느낌'이 아닌, **[AI 기반 객관적 진단 시스템]**을 통해 이 무너진 지점을 정확히 측정하고 성장할 것입니다." | 화면 전환: 혼란스러운 그래프가 명확한 Gap Score(예: C-) 수치로 정리되는 순간. 시스템의 로고 및 깔끔한 인터페이스 등장. | **"Gap Score를 확인하세요. 당신의 진짜 문제는 이것입니다."** |

---

### 🎥 **Module 2: Phase 2 - Diagnosis (진단 단계)**
**목표:** 문제의 원인을 객관적인 데이터로 제시하고, 시스템(AI)이 어떻게 작동하는지를 신뢰감 있게 설명한다. (System Introduction & Trust Building)

| 항목 | 상세 내러티브 (Voiceover Script 초안) | 시각적 요구사항 (Visual Direction) | 핵심 후킹 카피 (On-Screen Text) |
| :--- | :--- | :--- | :--- |
| **진단 과정** | "우리의 시스템은 단순한 편차를 넘어, 당신의 발성 패턴을 분석합니다. 호흡 부족인가? 공명점 이탈인가? AI는 Rate of Change(RoC)와 Gap Score를 통해 이 모든 원인을 **패턴으로 분류**합니다." | DiagnosisScoreWidget의 내부 로직(State Machine) 시각화. 데이터 포인트들이 움직이며 원인 분석을 하는 과정을 애니메이션으로 명확하게 보여줌. | **"Gap Score: C- (원인 분석 시작)"** |
| **핵심 메커니즘** | "이 시스템은 감정적 해석을 제거하고, 기술적 객관성을 제공합니다. 우리는 당신의 감정을 이해하는 코치와 AI가 결합된 하이브리드 모델입니다." | '감성(Human Coach)'과 '데이터(AI)'가 하나의 중앙 엔진에서 데이터를 교차 검증하며 최적화되는 과정의 시각화 (하이브리드 모델 강조). | **"기술적 객관성이 감성을 이끈다."** |
| **결과 예고** | "이 진단을 통해 우리는 막연한 추측을 끝내고, 다음 단계로 나아갈 가장 효율적인 경로를 명확하게 알게 됩니다. 이제 성장의 로드맵이 시작됩니다." | 데이터 분석이 완료된 후, 다음 단계(Phase 3)로 넘어가는 화살표가 선명하게 표시됨. 기대감을 고조시키는 밝은 색감으로 전환. | **"성장 곡선: 다음 단계는 명확합니다."** |

---

### 🎥 **Module 3: Phase 3 - Victory (승리/최적화 단계)**
**목표:** 시스템을 통해 실제 성장을 경험하고, 데이터 기반의 최적화가 어떻게 성공으로 이어지는지를 증명한다. (Proof & Transformation)

| 항목 | 상세 내러티브 (Voiceover Script 초안) | 시각적 요구사항 (Visual Direction) | 핵심 후킹 카피 (On-Screen Text) |
| :--- | :--- | :--- | :--- |
| **실행 및 코칭** | "이제 우리는 가장 효율적인 경로를 알고 있습니다. AI의 맞춤형 피드백을 받아, 미세한 조정을 시작합니다. 이 과정은 단순한 연습이 아닌, **정확한 데이터 기반의 최적화**입니다." | 실제 보컬 훈련(발성)과 시스템 피드백(Gap Score 변화)이 실시간으로 연결되는 모습. 작은 수정이 큰 변화를 일으키는 과정을 시각적으로 강조. | **"최적화: 작은 조정이 거대한 성과를 만든다."** |
| **결과 증명** | "AI 코칭 시스템을 통과한 학생들은 단순히 노래를 잘하는 것을 넘어, 자신의 잠재력을 객관적인 수치로 증명하며 진정한 성장이라는 승리를 경험합니다." | 'Before' (Module 1)와 'After' (Module 3)의 데이터 그래프를 명확하게 대비시켜 보여줌. 성공 사례(Success Story)에 대한 간략한 인용문 삽입. | **"Gap Score: A+ (성장의 증명)"** |
| **최종 CTA** | "당신의 잠재력을 데이터로 측정하고, AI와 함께 가장 빠르고 확실하게 목표를 달성하십시오. 지금 바로 [무료 진단 테스트 링크]를 통해 당신의 성장을 시작하세요." | 강력한 자신감과 성공을 상징하는 밝고 희망적인 이미지. 최종 행동 유도 버튼 강조. | **"지금, 당신의 잠재력을 해방하세요!"** |

## 📝 외부 편집자 전달용 최종 핸드오버 요약 (Editor's Checklist)

1.  **내러티브 흐름:** Module 1 (Crisis) $\rightarrow$ Module 2 (Diagnosis) $\rightarrow$ Module 3 (Victory)의 감정적 곡선 변화를 최우선으로 유지해야 합니다.
2.  **톤앤매너:** 모든 내레이션은 '경고'에서 시작하여 '신뢰'를 얻고, 최종적으로 '성취감'을 선사하는 논리적인 흐름이어야 합니다. 감정적 호소보다는 **데이터의 명확성과 시스템의 권위**를 강조하십시오.
3.  **시각화 핵심:** 데이터(Hz, Gap Score, RoC)가 화면에서 가장 중요한 시각 요소로 지속적으로 노출되어야 하며, 추상적인 설명 대신 그래프와 차트를 적극 활용해야 합니다.
4.  **음악 및 효과:** Module 1에서는 불안정하고 긴장감 있는 사운드 디자인을 사용하고, Module 3에서는 명료하고 자신감 넘치는 음악으로 전환하여 극적인 대비를 연출하십시오.

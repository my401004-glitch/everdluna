### Template A: YouTube Thumbnail Master (16:9 비율 / 1280x720px 기준)
*   **레이아웃 원칙:** [Pain] 요소와 [Gain] 요소의 비대칭적 배치 및 명확한 대비.
*   **섹션별 가이드:**
    *   **A-1. Pain Zone (좌측/상단):** 배경에 Dark Blue를 짙게 사용하고, 빨간색 계열의 강조 박스를 사용하여 경고성 효과를 부여합니다. 주요 헤드라인은 Montserrat Bold로 강렬하게 배치하며, 'X', '실패' 등의 시각적 상징물을 활용합니다.
    *   **A-2. Gap Score/Data Point (중앙):** 가장 큰 폰트 크기(180pt 이상 권장)와 Accent Yellow를 사용하여 숫자를 배치하고, 좌절감의 정도를 즉각적으로 인지시킵니다.
    *   **A-3. Gain Zone (우측/하단):** 밝은 배경(#F5F5F5)에 청량한 느낌을 주는 Dark Blue 계열의 그래프나 성공적인 이미지를 배치합니다. '솔루션', '성공' 등의 단어와 함께 Noto Sans KR로 구체적 이득을 제시합니다.

### Template B: Video Intro Graphic (16:9 비율 / 1280x720px 기준)
*   **목표:** 전문성과 신뢰도를 구축하는 미니멀한 애니메이션 트랙.
*   **요소 배치:**
    *   (0-1초): Dark Blue 배경 위에 '아지트아트컴페니' 로고가 중앙에 나타남 (Fade In).
    *   (1-3초): 슬로건 **"Pain $\rightarrow$ Gain, 데이터 기반 성장 시스템"**이 타이핑 효과와 함께 등장. 폰트는 Montserrat Bold를 사용하고, 화살표('$\rightarrow$') 부분만 Accent Yellow로 빛나게 처리합니다.
    *   (3-5초): 다음 영상 주제 키워드 (예: "발성 주파수 진단")가 Fade Out 되며 종료됩니다.

### Template C: Instagram Reel/Shorts Cover (9:16 비율 / 1080x1920px 기준)
*   **목표:** 모바일 환경에서 즉각적인 후킹과 정보 전달력 극대화.
*   **레이아웃 원칙:** 상단에 강렬한 헤드라인(후크), 하단에 구체적 설명/CTA를 분리합니다.
*   **요소 배치:**
    *   **Top 1/3 (헤드라인):** 가장 자극적인 질문이나 주장 (예: "당신의 발성은 듣는 사람에게 안 들린다?"). Montserrat Bold, Accent Yellow로 배경에 대비 효과를 주어 주목도를 높입니다.
    *   **Mid Section (비주얼):** 핵심 개념을 담은 단순한 인포그래픽 또는 아이콘 조합.
    *   **Bottom 1/3 (CTA/설명):** "AI 데이터 분석으로 확인하세요"와 같은 구체적인 행동 유도 문구를 Noto Sans KR로 배치합니다.

### 💎 [컨셉 A] - 데이터 충돌형 (The Shock Factor)
*   **전략:** 가장 직접적으로 '문제 제기(Pain)'의 충격도를 높여, 시청자가 즉각적인 궁금증을 느끼고 클릭하게 만듭니다. (호기심 유발/경고 메시지 강조)
*   **비주얼 컨셉:** 좌절감을 상징하는 **빨간색 경고 신호**를 Dark Blue와 결합하고, 'X' 표시된 낡은 학습 자료나 그래프를 전면에 배치합니다.
*   **레이아웃 (Composition):**
    *   좌측 1/3: 어두운 배경의 인물(혹은 마이크 아이콘)이 좌절하는 포즈.
    *   중앙 2/3: 거대한 경고 표시 (`🚨 WARNING`)와 핵심 문구("듣는 사람에게 들리지 않는 소리?")를 Yellow로 강조.
    *   하단: "AI 진단으로 해결 가능" (작은 글씨로 Gain 예고).
*   **색상 팔레트:** Primary: Dark Blue (#0A2463), Pain/Warning: Bright Red (`#FF0000`), Accent: Yellow (`#FFD700`).
*   **타이포그래피 강조:** **Montserrat Bold**. "듣는 사람에게 들리지 않는 소리"를 가장 크게, 강렬하게 배치.
*   **적합한 광고 매체:** 유튜브 썸네일 (가장 높은 임팩트 필요 시).

### 💎 [컨셉 B] - Before & After 대조형 (The Transformation)
*   **전략:** '변곡점'이라는 핵심 서사를 가장 직관적으로 보여줍니다. 문제 상태와 해결 후의 명쾌한 대비를 통해 Gain을 강조합니다. (해결책 제시/명확성 확보)
*   **비주얼 컨셉:** 화면을 수직으로 이등분하여, 왼쪽(Pain)은 어지럽고 흐릿한 느낌, 오른쪽(Gain)은 깨끗하고 정돈된 데이터 시각화로 처리합니다.
*   **레이아웃 (Composition):**
    *   좌측 (Before/Pain - Dark Blue 톤): '불균형', '오류' 등의 키워드와 흐릿한 그래프를 배치. 질문: "이대로 괜찮을까?"
    *   우측 (After/Gain - Clean White/Light Grey 톤): 깨끗하고 정확하게 측정된 주파수 파형(Waveform)과 함께, **[AI 로고]**가 중앙에 크게 강조됩니다. 핵심 메시지: "데이터로 증명하는 진짜 실력."
    *   중앙 분할선: 날카로운 Yellow 선이 좌측의 혼란스러움을 가르고 우측으로 나아갑니다.
*   **색상 팔레트:** Primary: Dark Blue (#0A2463), Accent: Yellow (`#FFD700`), Neutral: Light Grey (`#F5F5F5`).
*   **타이포그래피 강조:** **Noto Sans KR**. 데이터와 수치에 가독성을 극대화하여 전문적인 느낌을 부여.
*   **적합한 광고 매체:** 교육/전문 지식 전달형 콘텐츠 (신뢰도 구축).

### 💎 [컨셉 C] - 질문 던지기형 (The Intriguer)
*   **전략:** 시청자에게 직접 말을 거는 듯한 포맷으로, "당신의 노력은 진짜일까?"라는 근본적인 의문을 제기하여 클릭을 유도합니다. (개인화/공감대 형성)
*   **비주얼 컨셉:** 청중(시청자)의 시선을 정면으로 응시하는 구도로, 메인 인물과 함께 '진짜 문제'를 상징하는 은유적인 오브젝트(예: 깨진 마이크 스탠드, 왜곡된 음파 등)를 배치합니다.
*   **레이아웃 (Composition):**
    *   전경: 궁금증을 유발하는 질문 문구("혹시 지금 연습하는 발성법이...?")가 중앙에 크게 배치됩니다. 배경은 아련하고 감성적인 분위기입니다.
    *   배경/하단: '객관적 진단'이라는 키워드를 작은 데이터 그래픽과 함께 배치하여 해결책을 암시합니다.
    *   인물 포즈: 자신감 있으면서도, 무언가를 발견한 듯한 표정 연출이 필요합니다.
*   **색상 팔레트:** Primary: Dark Blue (#0A2463), Accent: Yellow (`#FFD700`), Mood: Deep Indigo (Dark Blue보다 채도를 낮춰 감성적 톤 유지).
*   **타이포그래피 강조:** **Montserrat Bold**. 문장 자체에 드라마틱한 힘을 부여.
*   **적합한 광고 매체:** 인스타그램 Reels/숏폼 (감정적인 후킹 및 빠른 몰입도 필요 시).

import { DatabaseClient } from '../utils/db'; // 가상의 DB 클라이언트 유틸리티
import { UserContext } from '../types/User'; // 사용자 컨텍스트 타입

/**
 * 진단 점수 계산 및 데이터 구조화를 담당하는 핵심 서비스 레이어입니다.
 * 이 함수는 비즈니스 로직(권한 체크, KPI 산출)을 캡슐화하여 API의 신뢰성을 높입니다.
 * @param context - 현재 사용자 정보와 필요한 세션 데이터를 포함합니다.
 * @returns 진단 결과가 담긴 구조화된 객체
 */
export const calculateDiagnosisScore = async (context: UserContext): Promise<{
    scoreId: string;
    resultData: DiagnosisResultPayload;
    isAuthorized: boolean;
}> => {
    // 1. RBAC 체크 및 권한 검증 (가장 중요)
    const userRole = context.userRole;
    const diagnosisType = context.requestedDiagnosisType;

    if (!checkAccessPermission(userRole, diagnosisType)) {
        console.warn(`[ERROR] User ${context.userId} lacks permission for diagnosis type: ${diagnosisType}`);
        // 권한이 없을 경우 더미 데이터와 함께 접근 불가 플래그를 반환합니다.
        return {
            scoreId: `error-${Date.now()}`,
            resultData: { 
                overallScore: null, 
                details: [], 
                kpis: { growth: null, engagement: null, monetization: null } 
            },
            isAuthorized: false,
        };
    }

    // 2. DB 조회 및 데이터 통합 (진단 결과와 KPI 데이터를 가져옴)
    try {
        const dbClient = DatabaseClient; // 실제로는 인스턴스를 주입받아야 합니다.
        const diagnosisLogId = await dbClient.getLatestDiagnosisLogId(context.userId);

        if (!diagnosisLogId) {
            throw new Error("No diagnosis log found for user.");
        }

        // DB에서 핵심 진단 결과 데이터와 KPI 데이터를 한 번에 가져옵니다.
        const rawData = await dbClient.fetchFullDiagnosisResult(diagnosisLogId);

        if (!rawData) {
             throw new Error("Failed to fetch comprehensive diagnosis data.");
        }
        
        // 3. 비즈니스 로직 실행 및 점수 계산
        const finalScore = calculateOverallScore(rawData);

        // 4. 결과 포맷팅 (Front-end가 예상하는 최종 JSON 구조에 맞춤)
        const structuredResult: DiagnosisResultPayload = {
            overallScore: finalScore, // 예: 'Excellent', 'Needs Improvement' 등
            details: rawData.detailedResults || [], // 세부 진단 항목 리스트
            kpis: { 
                growth: rawData.kpiMetrics?.growth || null,
                engagement: rawData.kpiMetrics?.engagement || null,
                monetization: rawData.kpiMetrics?.monetization || null,
            }
        };

        return {
            scoreId: diagnosisLogId,
            resultData: structuredResult,
            isAuthorized: true,
        };

    } catch (error) {
        console.error("Critical error during diagnosis scoring:", error);
        throw new Error(`Diagnosis processing failed: ${(error as Error).message}`);
    }
};

    const growthWeight = 0.4; // 임의 설정 값
    const engagementWeight = 0.6; // 임의 설정 값

    if (rawData.kpiMetrics && rawData.detailedResults?.length > 0) {

        const growthScore = rawData.kpiMetrics.growth || 0;

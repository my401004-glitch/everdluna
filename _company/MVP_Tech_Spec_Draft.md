# ⚙️ MVP 기술 구현 요구사항 정의서 (Draft v0.1)

## 📋 프로젝트 개요
*   **목표:** 학원 운영자에게 AI 진단 데이터를 통해 ROI 및 리스크 감소를 시뮬레이션하여 제시하는 최소 기능 제품(MVP)의 기술적 사양을 확정합니다.
*   **핵심 플로우:** (Pain Point 발견 $\rightarrow$ AI 데이터 분석 $\rightarrow$ 해결책/ROI 제시)

## 🎯 섹션 A: 비즈니스 로직 정의 (현빈님 담당)
1.  **User Story/시나리오 정의:** 운영자가 어떤 액션을 취할 때(예: "우리 학원 학생들의 평균 감정 지수 하락이 문제다"), 시스템은 어떤 데이터를 계산해야 하는가?
2.  **필수 변수 목록:** ROI 계산에 필요한 핵심 재무적, 교육적 변수 (예: '월 평균 클래스 수', '학생당 투입 비용', '최소 개선율 목표치').

## 💻 섹션 B: 기술 사양 정의 (코다리님 담당)
1.  **API Endpoint 목록:** 섹션 A에서 정의된 각 로직을 구현하기 위해 필요한 API 엔드포인트 목록 및 HTTP 메소드(GET/POST).
2.  **데이터 구조 매핑:**
    *   `Endpoint`: `/api/diagnosis_score` (예시)
    *   `Request Body`: { "user_id": "...", "metric": ["sound", "emotion"] }
    *   `Response Body`: { "status": "success", "data": { ... 실제 진단 데이터 ... } }

## 📝 섹션 C: 최종 통합 검증 (영숙님 담당)
*   **검토 사항:** A와 B에서 정의된 모든 항목이 논리적 모순 없이 완결성 있게 연결되는지 확인합니다. (예: 비즈니스 로직에 필요한 데이터가 기술적으로 구현 가능한지?)

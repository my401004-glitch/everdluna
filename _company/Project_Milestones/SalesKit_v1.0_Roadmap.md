# 🚀 MVP Sales Kit 제작 로드맵 (Ver 1.0)
## 목표: 학원 운영자 대상, 구매 결정 유도 최종 제안서 완성

### ✅ Phase 1: 논리 구조 확정 (현빈 주도)
*   **과제:** '운영자의 Pain Point'를 자극하는 스토리라인 초안 작성.
*   **필수 항목:** 문제 인식 $\rightarrow$ 기존 방식의 한계 제시 $\rightarrow$ 우리 솔루션으로 얻을 수 있는 ROI 예측 시나리오 3가지 명시.

### ✅ Phase 2: 비주얼 및 흐름 확정 (Designer 주도)
*   **과제:** 현빈의 논리를 바탕으로 프레젠테이션 슬라이드 와이어프레임(15~20장 분량).
*   **필수 항목:** 핵심 데이터 시각화 컨셉, 회사 브랜드 톤앤매너 적용.

### ✅ Phase 3: 기술적 검증 및 구체화 (코다리 주도)
*   **과제:** 제안서의 모든 기능 설명에 대한 API 동작 로직 명세 제공.
*   **필수 항목:** 핵심 진단 지표 (`diagnosis_score`), 데이터 구조 스키마를 활용한 시뮬레이션 결과 예시(Mock Data).

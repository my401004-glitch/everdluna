# ✨ 다음 핵심 액션: 진단 리포트 Mockup 제작 가이드라인

## 🎯 목표
AI의 객관적 데이터(Diagnosis Score)를 학원 운영자의 Pain Point로 전환하는 최종 화면 UI 완성.

## 🛠️ 전제 조건 (Input Data)
1. **데이터 구조:** 코다리님이 정의한 `diagnosis_score` API 계약 구조를 사용합니다.
2. **핵심 시나리오:** "현재 진단 점수 A는 학원 운영자 입장에서 B라는 리스크(예: 홍보/커리큘럼 노후화)가 있음을 의미하며, 이를 해결하려면 C 모듈이 필요하다."

## 📝 Designer에게 요청할 사항 (Output Goal)
*   **Screen Mockup:** 진단 점수와 함께 '위험 요소'를 시각적으로 극대화하는 대시보드 형태의 디자인.
*   **CTA 배치:** 가장 충격적인 Pain Point 아래에, 다음 단계(유료 모듈/무료 상담 등)로 연결되는 CTA 버튼을 명확히 배치합니다.

## ➡️ 기대 효과 (Why it matters?)
이 Mockup은 모든 마케팅 콘텐츠와 랜딩 페이지의 최종 비주얼 가이드가 되어, 전체 서비스의 통일성과 전환율(CVR) 극대화에 기여할 것입니다.

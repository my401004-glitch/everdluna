# 🎨 아지트아트컴페니: 최종 디자인 시스템 가이드라인 (v1.0)

## 🎯 적용 목표
모든 콘텐츠(유튜브, 블로그, SNS)에 일관된 전문성과 신뢰성을 부여하고, 특히 '데이터 기반의 위기감'을 자극하여 CTR을 극대화하는 것을 목표로 한다.

## 🎨 핵심 브랜드 요소 (Self-RAG 검증 완료)
| 요소 | 규격 | 역할 및 적용 규칙 |
| :--- | :--- | :--- |
| **Primary Color (신뢰/전문)** | Dark Blue (`#0A2463`) | 신뢰성, 전문성 확보. 배경, 주요 정보 영역에 사용하며, 시스템의 권위를 담당한다. |
| **Accent Color (행동 유도/기회)** | Accent Yellow (`#FFD700`) | CTA 버튼, 위험(Pain) 표시, 최종 Gain 수치 강조. 즉각적인 시선 집중 및 행동을 유도한다. |
| **Background Color (가독성)** | Neutral Grey (`#F5F5F5`) | 본문 텍스트 배경. Dark Blue와의 명확한 대비를 통해 가독성을 극대화한다. |
| **Title Typography** | Montserrat Bold | 강력하고 임팩트 있는 헤드라인(Pain, Gain)에 사용되어 메시지 전달력을 확보한다. |
| **Body Typography** | Noto Sans KR Regular/Medium | 데이터 및 상세 설명 텍스트에 사용하며 높은 가독성을 보장한다. |

## ✨ 썸네일 레이아웃 표준 (3가지 컨셉)

모든 썸네일은 'Pain $\rightarrow$ Data Proof $\rightarrow$ Gain'의 구조를 따른다.

### 1️⃣ Template A: [위기 경고형] - Pain Focus
*   **사용 시점:** 충격적인 데이터, 위험성 고지 (예: "이거 모르면 학원 망합니다")
*   **핵심 구도:** 불안함 연출 $\rightarrow$ 데이터 오류 지적 $\rightarrow$ 수치 강조
*   **색상 전략:** 어두운 배경(Dark Blue/Black) + 빨강 계열 경고 표시 ($\#FF4500$)와 Yellow를 혼용하여 긴장감을 최고조로 높인다.
*   **필수 요소:** 굵은 Montserrat Bold 헤드라인, 충격적인 표정의 인물 사진.

### 2️⃣ Template B: [솔루션 제시형] - System/Proof Focus
*   **사용 시점:** 시스템 도입 필요성 강조 (예: "감성 코칭이 아니라 데이터가 답이다")
*   **핵심 구도:** 문제 제기(Before) $\rightarrow$ 과정 설명 $\rightarrow$ 해결책 제시(After)
*   **색상 전략:** 명확한 좌우 분할. 왼쪽은 혼란스러운 색채/구도를, 오른쪽은 Dark Blue를 활용한 정돈된 UI 목업을 배치하여 대비 효과를 극대화한다.
*   **필수 요소:** 'Before $\rightarrow$ After' 화살표 또는 연결고리 시각화.

### 3️⃣ Template C: [결과 증명형] - Gain Focus
*   **사용 시점:** 구체적인 성과, ROI 제시 (예: "월 매출 OOO만원 달성 비밀")
*   **핵심 구도:** 배경 정보 $\rightarrow$ 핵심 수치 강조 $\rightarrow$ 간결한 결론
*   **색상 전략:** 밝은 Neutral Grey 배경 위에 Accent Yellow와 Dark Blue를 조합하여 숫자의 가독성을 최우선으로 확보한다.
*   **필수 요소:** 가장 큰 글씨 크기로 '최종 숫자'를 배치하고, 그 주변에 상승 그래프 아이콘을 활용한다.

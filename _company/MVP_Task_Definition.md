# 🚀 MVP 개발 착수: 통합 스펙 정의
## 🎯 목표
학원 운영자의 Pain Point를 해결하는 최소 기능 제품(MVP)의 기술적/사용자 경험적 요구사항 확정.

## 👤 책임 에이전트
*   **코다리:** 핵심 API 및 DB 스키마 설계 (기술적 관점).
*   **현빈:** 비즈니스 플로우 검증 및 KPI 우선순위 지정 (사업적 관점).
*   **Designer:** 최종 와이어프레임 제작 및 UX 흐름 최적화 (사용자 경험 관점).

## 🗓️ 다음 스텝 액션 아이템
1.  코다리: 현빈님/디자인팀의 요구사항을 반영한 `MVP_API_Spec` 초안 작성.
2.  현빈: 코다리의 API 기반 플로우를 검토하며, 'ROI 확신 단계'에 필요한 핵심 데이터 필드 추가 요청.
3.  Designer: 통합 스펙이 확정되는 즉시, 진단 리포트 및 대시보드 최종 와이어프레임 제작 준비.

## 💡 중요 참고 사항 (Non-Negotiable)
*   데이터 모델의 중심은 '학생 점수'가 아닌 **'운영자의 재정적 손실/이익 예측 지표(ROI)'**여야 함.

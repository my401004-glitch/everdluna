# 🎨 Diagnosis Score Widget 통합 애니메이션 스펙 시트 (Spec Sheet V1.0)\n\n**[문서 개요]**\n*   **목적:** 마스터 프로덕션 바이블(MPB) Phase 3에 맞춰, 기술 로직($W_n$)과 시각 디자인이 동기화되는 애니메이션 트랜지션을 외부 편집자에게 전달하기 위한 최종 실행 사양서입니다. \n*   **기준 파일:** Master_Handover_V1.0.md 및 DiagnosisScoreWidget_Integration_Checklist.md\n*   **담당 역할 분담:** 코다리 (기술 로직/데이터 상태 정의) $\rightarrow$ Designer (시각적 행동/에셋 명세)\n\n---\n\n## 🌟 1. 핵심 애니메이션 컴포넌트 목록 (Core Animated Elements)\n\n| ID | 요소명 | 기능 | 기술 트리거 (코다리 제공) | 시각 요구사항 (Designer 정의) |\n| :---: | :---: | :---: | :---: | :---: |\n| **E01** | Score Indicator 바 | 현재 점수(Score %)의 실시간 변화 추이 표시. | `API_SUCCESS` / Score 값 변화 ($\Delta$) | **[Behavior]:** 부드러운 커브 아웃(Ease-Out)으로 수치 증가. 1초 이내 완료.\n**[Asset]:** Linear Gradient Background (Dark Blue $\rightarrow$ Accent Yellow).\n| **E02** | 상태 경고 바 (Gap Score Bar) | 현재의 위험도/기회도를 시각적으로 표시하는 메인 바. | `API_SUCCESS` / Status Phase Change (Crisis, Warning, Safe)\n**[Behavior]:** 상태 변화 시, 해당 색상으로 'Pulse' 효과(약 0.5초 간격, 강도 점진적 증가) 발생.\n**[Asset]:** Gradient Fillable Background. (색상: See Color Spec).\n| **E03** | 데이터 플로우 연결선 (Flow Line)\n| 시스템 상태 변화의 방향성을 시각화하는 라인.\n| `API_SUCCESS` / 로직 전환 지점\n**[Behavior]:** 선이 '스윕(Sweep)'하듯 부드럽게 움직이며 다음 섹션으로 이동을 안내. 속도: 0.8초.\n**[Asset]:** Opacity Gradient Line (Dark Blue에서 투명도로). \n| **E04** | 에러 메시지 애니메이션\n| 기술 오류 발생 시 사용자에게 전달되는 피드백 창.\n| `API_FAIL` / Error Code 수신\n**[Behavior]:** 배경이 Dark Grey로 'Shake' 효과(좌우 2px)를 주면서, 빨간색 깜빡임 (0.1초 간격)을 반복하며 주의 집중 유도.\n**[Asset]:** Error Message Card (Red/Yellow). \n\n---\n\n## ⚠️ 2. 상태별 애니메이션 및 에셋 상세 사양 (Status-Specific Specs)\n\n### A. [Success State: Safe Zone] - 최적의 상태 전이\n*   **기술 트리거:** Score > 80점, API Status = OK \n*   **E02 (Gap Score Bar):** `Accent Yellow (#FFD700)`로 고정 및 미세한 '숨 쉬는' 듯한(Breathing) 애니메이션 적용. \n*   **E01 (Score Indicator):** 점수 증가 시, 배경이 Dark Blue에서 밝은 청록색 계열로 부드럽게 전환되며 안정감 부여.\n\n### B. [Warning State: Potential Risk] - 개입이 필요한 상태 전이\n*   **기술 트리거:** 50점 < Score $\le$ 80점, API Status = OK \n*   **E02 (Gap Score Bar):** `Orange/Yellow Gradient (#FF9933)` 사용. Pulse 애니메이션의 주기가 느려지고, 강도가 점진적으로 높아지는 패턴을 유지.\n*   **시각 효과:** 배경에 미세한 노이즈(Noise) 텍스처가 추가되어 '주의 깊게 살펴봐야 한다'는 느낌 전달.\n\n### C. [Critical State: Crisis] - 즉각적인 액션 요구 상태 전이\n*   **기술 트리거:** Score $\le$ 50점, API Status = OK \n*   **E02 (Gap Score Bar):** `Red Gradient (#CC0000)` 사용. Pulse 애니메이션의 주기가 매우 빠르고 강도가 최대화되어 시선을 압도.\n*   **시각 효과:** 전체 UI 요소에 경고성 '플래시(Flash)' 효과를 주기적으로 적용하여 위기감을 극대화해야 함. (지속 시간: 2초 간격)\n\n---\n\n## 🛠️ 3. 필수 아트 에셋 목록 (Concrete Asset Deliverables for Editor)\n\n외부 편집자는 다음의 벡터/PNG 에셋과 애니메이션 루프를 반드시 받아야 합니다.\n\n1.  **[Asset ID: A-BG-V]**: 기본 배경 패턴 및 색상 팔레트 정의 파일 (Dark Blue, Accent Yellow 등).\n2.  **[Asset ID: A-E01]**: Score Indicator용 3가지 상태별(Safe/Warning/Crisis) 애니메이션 루프 (SVG 또는 Lottie 형식).\n3.  **[Asset ID: A-E02]**: Gap Score Bar의 3가지 색상 그라디언트 및 Pulse 마스크 파일.\n4.  **[Asset ID: A-E03]**: 데이터 플로우 연결선(Sweep Line) 애니메이션 루프 (SVG).\n5.  **[Asset ID: A-Error-Card]**: 에러 메시지 카드 UI 템플릿 (모든 OS 및 해상도 대응 버전). \n\n---\n\n## 📝 4. 요약 가이드라인 (Summary Guideline)\n*   **핵심:** 애니메이션은 '정적 상태'가 아닌, **'상태 변화의 과정(Transition)'** 자체에 스토리텔링을 부여해야 합니다.\n*   **최우선 검토 사항:** 모든 에러 코드($\text{API\_FAIL}$)에 대한 시각적 피드백이 빠지고 명확한지 재검증 필요. (실패 시에도 지치지 않고 다음 행동을 유도하는 톤 유지.)\n\n

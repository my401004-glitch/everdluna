# 🚀 MVP 파일럿 테스트 정의서 (최종 초안)
## 🗓️ 1. 목표 및 범위 재정의
*   **핵심 가치:** 학원 운영자에게 '객관적 데이터 기반의 ROI 리스크 예측 지표' 제공.
*   **테스트 대상:** 특정 과목/특정 시간대/특정 학생 그룹 (범위 축소 필수).
*   **측정 기간:** 2주 간 단기 파일럿 테스트.

## 🎯 2. 핵심 성공 지표 (KPI) 정의 [현빈 담당]
*   [Pain Point 1]: 예시) "실전 대비 감성 표현 부족으로 인한 입시 실패 리스크" $\rightarrow$ **측정 KPI:** 특정 구간의 감정 변화 패턴 미달률 (X%)
*   [Pain Point 2]: 예시) "개인별 학습 계획 부재로 인한 시간 비효율성" $\rightarrow$ **측정 KPI:** AI 진단 기반 최적화 스케줄 대비 실제 활동 비율 (Y%)
*   [Pain Point 3]: [빈칸 - 코다리/현빈 협의 필요]

## 🛠️ 3. 기술 구현 및 데이터 구조 확립 [코다리 담당]
*   **필수 입력 데이터:** 성능 지표(음정, 박자) + 감성 변화 로그 (특정 시간 구간의 강약/떨림 패턴).
*   **핵심 로직:** Input Data $\rightarrow$ AI 분석 엔진 $\rightarrow$ **ROI 리스크 점수 계산 ($\text{Risk Score} = f(\text{KPI1}, \text{KPI2}...)$)**.
*   **최소 필수 API 엔드포인트:** `/diagnosis/risk_score` (가장 중요)

## 🖼️ 4. 보고서 시각화 초점 [Designer 담당]
*   진단 리포트는 '성능 그래프' 대신 **'리스크 지표 대시보드'** 형태로 구성되어야 함.
*   최상단에 가장 중요한 수치: $\text{Overall Risk Score} / \text{Required Improvement Area}$를 직관적인 게이지로 표시.
